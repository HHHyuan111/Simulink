# SMO＋PLL实施节点与验收契约（待确认）

日期：2026-10-16。本文件补充《SMO_PLL科学实施方案_待确认.md》，明确实施前的测试、适配和节点同步规则。当前仅生成方案；尚未建立sensorless工作区或接入算法。

## 1. “复现成功”的含义

目标是在当前本地PMSM模型上实现可解释、符合既定精度、可独立复跑的SMO＋PLL旁路观测。不是复制参考SLX、复刻参考电机或追求与参考截图相同的波形。

成功须同时满足：数学实现正确、数据来源与时序正确、基础性能达标、独立进程复跑一致、接入/退出不改变原闭环，以及参数和观测能在本地既有方式中使用。单纯运行结束或某张图好看不算成功。

## 2. 先冻结，再实现

N0生成版本化 `acceptance_v1.json` 和 `test_plan_v1.json`，写入本文件全部阈值、场景、窗口、种子、时间戳、日志清单和版本指纹，再开始算法实现。冻结文件的SHA写入每次运行记录。

N0以当前实际SLX、固定参考及相关脚本为准核对参数和速率，记录有效网格，不沿用历史文档中的旧哈希。记录MATLAB/Simulink版本、求解器、初态、输入、噪声发生方式、种子和数据类型。基线会话若有未保存自定义配置，先保留且不覆盖。

优化可以修改算法参数，但正式验收使用的参数组必须先锁定再运行。失败不得通过改变统计窗口、删去不良样本、平滑曲线或放宽阈值改成通过。确需改变范围或指标时，单独提出原因，建立v2契约并保留v1失败结果。

## 4. 预先规定的测试标准

### 4.1 组件正确性（N1，必选）

- 参数计算独立核对：RL离散系数、极对数/机械速度/电速度换算、PLL增益及滤波系数，与独立公式比较，绝对误差≤1e-12＋相对误差1e-10。零值、非有限数、非法采样周期、Ld/Lq不符合首版SPMSM条件应明确拒绝。
- 隐式SMO用独立数值求根对照分段解，覆盖正负内外边界、零误差、复位和连续多拍；方程残差按A计≤1e-10＋1e-9×该案例电流尺度。多拍测试使用独立状态递推和解析/数值积分信号，不能仅把同一函数调用两遍当作正确性证据。
- PLL单测：Ts=50µs；电频率±83.333333/±166.666667/±250Hz；同一方向矢量输入幅值0.5/1/2；初相差±30°/±120°；时长300ms，固定评价200—300ms。无噪声下相位RMS≤0.1°、速度均值相对误差≤0.1%，并在150ms内进入且连续20ms保持|相位误差|≤1°。不得按估计相位对齐输入来消除误差。
- 滤波/相位校正独立比较离散频率响应，区分输出的物理时间戳和数据索引，不用固定1.5拍替代推导。完整SMO＋滤波链的稳态幅相必须另用合成信号检查，不仅测试独立低通。
- PLL速度饱和期间积分不继续向同方向无界累积；复位后状态满足声明值；无效输入不能产生NaN/Inf。此处检查离散实现与状态语义，不宣称全局收敛证明。

### 4.2 本地接入正确性（N2，必选）

- SMO输入来自控制器实际收到的电流；上一采样区间电压由已生效CCR与可用母线重构，保留请求/生效序号和区间起止时间。实际端电压只用于诊断对照，正式输入不依赖电机真值角度/速度。
- 核对至少启动后的首20个周期和末20个周期，并对全程序号、区间长度和输入日志作自动检查。UEV跨区间时分段处理，不以“上一拍请求”替代实际生效历史。
- 观测器只在20kHz任务边界执行；滤波、PLL、状态机采用声明的同拍顺序。比较实际整数事件格点，不通过插值改变来源时刻。
- 新算法旁路关闭与旧参考，旁路开启与同配置旧参考，分别比较N0冻结的原有控制/电机日志：原始Time/Data逐元素相同。新增观测不得改变控制源、求解设置或原控制任务速率。若结构接入导致结果改变，必须查明并修复，不能改用宽松容差。
- 退出后原结构、参数、位置快照及主SLX和固定参考文件SHA不变。开发产物和本地扩展独立保存。

### 4.3 主模型基础性能（N3，必选）

固定使用当前主电机标称参数、24V母线、原PI和8A给定限制；基础组使用同一理想功率桥、理想测量、电压重构正式输入，其他附加误差关闭。启动按当前参考路径，SMO仅旁路运行。

稳态组为+1000/+2000/+3000rpm，负载0.207N·m，各运行0.8s，评价窗口固定0.5—0.8s。先核对窗口含至少20个真实电周期、真实速度均值偏差≤1%目标且速度线性拟合斜率绝对值≤50rpm/s。若不满足，场景未建立，不能挪窗或把它算作SMO精度通过。

三个稳态案例逐个要求：校正后电角误差RMS≤3°、最大绝对误差≤8°；机械速度均值误差≤1%给定值、速度误差RMS≤2%给定值；窗口有效标志占比≥99%。所有指标按完整固定窗口统计，不能只统计valid=true样本。

角度误差采用atan2(sin差,cos差)，真实角度只供离线验收。未经相位校正的结果也保存，禁止用真值计算最佳常数偏移再回填估计输出。

固定动态组：0—0.3s为2000rpm，0.3s变3000rpm，0.6s负载从0.207增至0.25N·m，结束0.9s；真实任务边界为实际发生时刻。要求实际场景成立，且每次事件后150ms内进入并连续20ms满足|角误差|≤8°、|速误差|≤3%当前给定、valid=true；所有状态有限，无持续积分/速度饱和。全程动态峰值单独报告，不用稳态误差阈值掩盖启动不可观测阶段。

### 4.4 有效性规则和边界组（N3）

首版有效性阈值预先规定：滤后反电动势矢量幅值≥2V、αβ电流估计残差向量RMS≤0.5A、归一化PLL相位误差RMS≤0.15（后两项用过去10ms窗口）、无PLL速度饱和，连续满足20ms才发布valid=true。低幅值<1.5V持续5ms或残差/鉴相/饱和条件连续失效5ms则撤销；无效采样立即撤销，恢复后重新满足完整锁定时间。准备历史不足时无效。阈值如未通过场景验证，须按v1失败处理而非悄悄修改。

必选安全语义检查：采样无效时不把保持样本当成新观测校正，按预先声明的模型预测规则推进并标无效；复位优先级最高；重新获取有效采样不能瞬间跳过20ms准备。方向为试验声明输入，不能从真值获得；零方向无效。

固定边界组：-1000/-3000rpm；Rs分别±20%、L分别±20%且仅改变观测器参数；三相独立零均值噪声0.02A RMS、固定发生方式与种子20261016；同一详细桥零死区/2µs死区；1000rpm降到200rpm再停转；固定连续5拍无效采样。具体事件时刻和窗口在N0 JSON写明。

边界组必须运行并复跑，核对方向、有限性、无效撤销和恢复，完整报告角度/速度误差及有效比例；本版不要求所有边界仍满足基础组3°精度，也不以低速“必须有效”为目标。低速/死区若存在虚假锁定，标记已知边界，不能宣称已具备闭环接管条件。

### 4.5 独立复现（N4，必选）

所有最终必选案例在同一软件版本/同一机器的全新MATLAB进程，用同一已冻结配置、初态、种子和源码重跑。比较共同原始日志的Time/Data逐元素相同，包括传感器输入、重构电压、SMO状态、滤后EMF、PLL积分/角度/速度、相位修正、valid及原闭环信号。

MAT容器文件哈希不要求相同，原始数值要求相同；另用文件哈希证明数据包未被改动。跨软件版本或不同数值平台不是本版逐位复现承诺。仅重复绘图不算独立复现，初次仿真完成不算验收通过。

## 5. 本地参数格式适配

沿用当前参数设置的中文标签、单位、来源和校准状态。独立命名空间 `sensorless`，不复用Pn等可能有功率/极对数歧义的名字，不覆盖原PI或电机参数。

参数分为三类：

- 电机/任务：观测器Rs、L、极对数、磁链、实际Ts；从当前本地模型读取标称初值，Plant参数与估计参数分开存档。
- 设计：Kslide[V]、phi[A]、EMF滤波fc[Hz]、PLL自然频率fn[Hz]、阻尼比、有效性阈值、方向和复位策略。
- 计算结果（只读）：a、b、预计反电动势、滤波系数、PLL Kp/Ki、离散极点/约束及相位校正定义。

每项元数据包括key、中文名、单位、值、来源、状态、允许范围；设计值不标成实测值。参数应用前统一校验，运行时不热修改；每次运行封存完整配置。暂不增加不存在的接管或无感启动开关。

## 6. 本地观测格式适配

首版采用一个原生Scope、两页主题，复用已有观测入口和菜单方式，不堆叠新面板：

| 页面 | 固定内容 |
| --- | --- |
| 角度与速度，2×2 | 电角度真值/估计、环绕角误差、机械速度真值/估计、有效与锁定状态 |
| 观测器内部，3×2 | α轴电流测量/估计、β轴电流测量/估计、αβ反电动势、PLL鉴相误差、积分与速度限幅状态、相位校正角 |

沿用白底、灰虚线真值/基准、蓝色估计主线、红色误差或重点对照；同一报告含义固定，线型辅助区分。内部记录rad，展示电角度°；速度rpm；电流A；电压V；时间ms，事件放大µs。图内只写主题、坐标、单位和必要图例，参数、结论和边界写正文。

原始日志前缀 `obs_sless_*`；每路固定字段、单位、采样率和时间戳定义，控制信号与真值评价信号分开。统一记录原始/校正角度、速度、电流、注入、滤后EMF、PLL状态、有效性和输入来源。MAT保存原始timeseries，JSON保存配置/指标/状态/指纹，CSV保存逐案例指标。

当前Scope显示本次仿真，归档报告明确显示运行ID和配置来源，不能把旧报告当作当前参数的结果。绘图不能修改科学原始数据。
