# SMO＋PLL 科学实施方案（待用户确认）

2026-10-16。当前仅制定方案，不建立 sensorless 工作区，不修改主模型。确认后建议实施位置为 `modern/sensorless/`，沿用当前主模型被控对象与20kHz控制事件。

## 一、对参考模型的判断

`Chensha_FOC_SMOPLL_Final.slx` 包含至少两种实现，必须区分：

1. 顶层 `SMO+PLL`：内部包含αβ连续电流积分、误差饱和、增益K、一阶低通、PLL乘法鉴相以及两个连续积分环节。电机及PLL参数由Mask变量传入，结构适合带读。
2. 顶层 `SMOPLL2`：MATLAB Function，对应提取的 `chart_98`。参数写死，内部Tsc=1µs；PLL积分计算后没有写回 `integral_pll_old`。这个问题不能外推为连续模块版本也存在同一错误。

结论：参考的基本思路清楚，足以作为算法来源和连续行为对照；尚不足以直接成为主模型的20kHz工程实现。参数单位、采样时刻、滤波相位、方向、复位和有效性需要明确。

原结构用低通后的滑模注入反馈电流观测方程。其边界层内是电流误差与滤波状态构成的二阶闭环，并不是“理想反电动势串一个低通”。因此不能直接套一个 atan(ω/wc) 补角就认定全部相位误差已经消除。

## 二、实施范围

首批交付：SMO＋PLL旁路观测、参数计算、统一Scope和固定验收场景。原有角度/速度来源、PI与执行链继续控制电机；新增估计输出不接管。

首版支持主模型现有Ld=Lq的SPMSM假设，以1000—3000rpm正转为主验收区，另做负转工作点及低速失效边界。过零反转、零速定位、独立无感启动、反馈接管另行开发。

结构分为五段：

`测量电流/施加电压重构 → 离散电流SMO → 反电动势滤波及相位校正 → 归一化PLL → 有效性/观测`

每段都保留端口、单位和可观察中间量；局部函数实现状态更新，避免把所有计算重新放入一个大函数。使用普通Simulink块和MATLAB Function，不增加Motor Control Blockset依赖。

## 三、参数不是只由电机决定

| 类型 | 输入 | 可以计算的内容 |
| --- | --- | --- |
| 电机及任务 | Rs、L、极对数、磁链、Ts | 电气时间常数、离散系数、电频率、反电动势范围 |
| 设计要求 | 工作转速/加速度范围、允许误差、响应速度 | 滑模注入下限、PLL自然频率/阻尼、有效范围 |
| 测量与执行 | 电流噪声、滤波、有效采样、施加电压误差与时序 | 边界层、有效阈值、相位修正和可靠裕量 |

所以参数可以“按规律计算初值＋约束检查”，不能只输入Rs/L就唯一得到一组保证正确的SMO及PLL参数。控制器电机参数与Plant参数分别保存，便于失配验证。

当前标称档案：Rs=0.105125Ω，L=103.7615µH，p=5，ψf≈0.005656854Wb，Ts=50µs。实施时从实际主模型工作区读取并核对，不把外部历史副本当成唯一真值。

对应计算：L/R≈0.987ms；3000rpm时电频率250Hz，电角速度约1570.8rad/s，反电动势αβ矢量幅值约8.886V。

## 四、SMO离散化：明确解决小电感下的数值约束

采用幅值不变αβ坐标：`L di/dt = v - R i - e`。

RL部分的零阶保持离散系数：

`a = exp(-R Ts/L)`，`b = (1-a)/R`。

当前a≈0.950605，b≈0.469873A/V。此离散化对RL和区间恒定输入准确，对区间内变化的反电动势仍是近似，必须做动态误差验证。

滑模注入定义明确为：`z = Kslide * sat(s/phi)`。Kslide单位V，phi单位A，局部斜率g=Kslide/phi单位Ω。

若使用原始注入直接反馈的显式离散SMO，边界层内误差极点是 `a-bg`，必要的局部稳定检查为 `|a-bg|<1`，即本机参数下 `g<4.151Ω`。例如Kslide=14V、phi=0.2A得到g=70Ω，不能用该显式更新直接实现。这个条件只针对此显式结构，不能直接套到参考的滤波反馈结构上。

**推荐：采用可解析求解的隐式饱和校正，保留20kHz执行，不靠假设1µs新采样来掩盖问题。** 这是对参考离散更新结构的明确调整，并非仅改参数；首批同时保留参考结构的独立对照。

对每个αβ轴，在t[k]执行：

1. 用上次观测状态和上一采样区间的已施加电压预测：`ip = a*ihat[k-1] + b*vbar[k-1]`。
2. 令 `d = ip - imeas[k]`，求解 `s + b*Kslide*sat(s/phi) = d`。
3. 当 `|d| <= phi+b*Kslide`，`s=d/(1+b*Kslide/phi)`；否则 `s=d-b*Kslide*sign(d)`。
4. `ihat[k]=imeas[k]+s`，`z[k]=Kslide*sat(s/phi)`。

这是有限段代数计算，无需Simulink代数环或迭代求解。边界层内局部极点为 `a/(1+bg)`。该局部性质不等于包含噪声、饱和和PLL的全局稳定性证明；还需验证边界层外收敛、时变反电动势与采样误差。

Kslide按预计反电动势上限，加电压重构/参数失配裕量选取。连续理想SMO的到达条件可帮助给出初值，但不能直接当作隐式离散实现的充分收敛证明。首轮以14V为候选，在当前目标范围核对裕量，扫描12/14/16V；如果动态超出设计速度范围，应重新计算而非继续沿用。

phi依据有效采样后的电流噪声、量化和顺序采样残差选取，首轮扫描0.1/0.2/0.4A。初值0.2A只是仿真候选，不是实板噪声测量结论。比较估计残差、注入高频成分、角度误差和失锁，避免只追求残差最小。

## 五、滤波与PLL按各自目标设计

反电动势提取：`ef[k] = r*ef[k-1] + (1-r)*z[k]`，`r=exp(-2*pi*fc*Ts)`。

首轮fc候选为500/800/1200Hz，800Hz作为初值。提高fc减少相位滞后，也增加高频噪声；不把fc设成与电频率相等就视为完成整定。

在稳态、小误差、固定参数条件下，上述隐式校正从区间反电动势到注入z的线性近似为：

`Gobs(q) = [bg/(1+bg)] q^-1 / [1 - a/(1+bg) q^-1]`。

滤波器为 `H(q)=(1-r)/(1-r q^-1)`。按 `q=exp(j*omega_e*Ts)` 计算 `Gobs*H` 的幅相，补偿整个已定义离散估计链的相位。若区间量采用中心时间戳，要先转换时间基准；不能再把同一半拍/一拍重复添加。动态时相位补偿是近似，另用加减速场景验收。

PLL输入先转成归一化转子方向矢量，再用叉积形式鉴相，局部得到 `eps≈theta_ref-theta_hat`。正反转的反电动势极性不同，首版按试验给定的非零旋转方向处理，方向来源不取电机真值；过零期间置无效。归一化用幅值下限防止除零，但不能把低幅值噪声当成有效角度。

对于单位鉴相增益、标准二阶type-II PLL，目标特征多项式为：

`s² + 2*zeta*omega_n*s + omega_n²`。

所以 `Kp=2*zeta*omega_n`，`Ki=omega_n²`，`omega_n=2*pi*fn`。这里fn是自然频率，以Hz表示，不直接等于闭环-3dB带宽。若不归一化，鉴相增益随反电动势幅值变化，不能直接用上述同一组Kp/Ki。

候选zeta=0.707，fn=60Hz，对应Kp≈533.1s^-1、Ki≈142122.3s^-2。再比较40/60/80Hz下的噪声和加速度跟踪。离散实现明确积分与角度更新顺序，检查离散极点，并加入积分抗饱和、速度限值及复位。

标准线性近似下，恒加速度引起的稳态相位误差约为 `alpha_e/omega_n²`。例如机械加速度1200rad/s²、5极对、fn=60Hz时约2.42°电角，仅用于解释动态目标；主模型当前并未自动施加这一加速度上限。

这些PLL整定关系是本方案的标准二阶推导。归一化输入及线性模型设计的参考依据见[MathWorks PLL文档](https://www.mathworks.com/help/mcb/ref/pllwithfeedforward.html)；本项目使用自己的普通块实现，不直接复制该文档的前馈PLL结构或默认参数。

## 六、电压输入和采样时刻先于调参

测量电流取快环真正收到的αβ电流，保留JEOS时刻和有效标志。上一周期电压来自已生效CCR及控制可用母线重构，按实际UEV分段处理；不能直接用刚算出的请求电压替代。

若顺序ADC开启，先明确电流等效时间戳；首轮使用既有参考测量条件验证核心，再加入顺序采样/滤波，不用“额外一拍延迟”统包不同时间来源。

标准RL预测要求相应区间的有效电压，优先按已生效片段的时间计算重构；高精度对照可采用RL指数权重，PWM开关纹波与周期平均近似的误差单独记录。

电机实际端电压可作为诊断对照输入，帮助区分SMO本体与电压重构误差；它不作为可实现无感版本的正式输入，不用真值角度/速度修正SMO或PLL。

## 七、验收与结果判定

先单独向PLL输入已知正交信号，验证积分确实累计、幅值缩放不改变设计响应、正负方向、噪声和复位；再独立验证SMO分段解与数值残差；最后接主模型旁路。每个阶段先验证数学与信号来源，再评价表现。

主模型场景：1000/2000/3000rpm稳态、固定变速、可持续范围内负载变化、负转工作点、Rs±20%/L±20%单项失配、实际测量链、同桥零死区/有死区、低速降速与无效样本。失配幅度是首轮测试设计，非已测电机温漂范围。

建议基础验收目标（本方案的工程目标，不是理论保证）：在标称、理想测量和已定义电压输入的稳态窗口，校正后角度RMS≤3°电角、最大绝对误差≤8°，速度均值误差≤1%给定值；分别报告未经校正和校正结果。窗口长度至少20个电周期，并检查速度和负载确已进入稳态。

角度误差使用 `atan2(sin(theta_hat-theta_true),cos(theta_hat-theta_true))`，避免0/2π跳变。锁定后捕获时长、速度纹波和动态峰值另外报告；参数失配与非理想条件不能自动套用基础门槛后宣称全部通过。

运行有效标志由反电动势幅值、电流残差、PLL相位误差、饱和状态及持续时间决定；门槛由噪声场景与设计目标确定。真值误差仅用于离线验收，不进入有效性逻辑。无效样本时状态更新/预测和恢复规则显式定义；低速不满足条件应如实显示无效。

旁路接入前后，原控制日志Time/Data严格一致；退出后结构、配置和参考可恢复。保留完整原始信号、失败包、参数及源码指纹，不为通过而移动窗口或临时放宽指标。
