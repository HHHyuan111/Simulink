# 主仿真算法扩展与 Ref 迁移方案

日期：2026-10-16。对象：`modern/PMSM_FOC_R2026a.slx`。

建议路线：先建立三个局部接口，随后开展 SMO 旁路观测和编码器条件下的谐波抑制，再做无感接管，最后迁入预测电流控制。每一批都能独立运行、关闭和恢复；继续使用现有电机、功率级、采样时序、观测和实验框架。

## 1. 本次检查范围与结论

本次静态读取了 Ref 四个 SLX 的 XML、MATLAB Function 源码、初始化回调、库引用，以及 ZIP 中的自编驱动源码；对照主 SLX 的信号标签及现有控制、启停、整机与采样链脚本/说明。没有执行参考模型回调，没有运行 MATLAB 编译或闭环仿真，也没有修改主 SLX。以下是迁移设计与源码风险判断，不是运行验收结论。

参考内容的定位：

| 来源 | 实际可提取内容 | 推荐用途 |
| --- | --- | --- |
| `Chensha_FOC_SMOPLL_Final.slx` | αβ 电流 SMO、反电动势低通、atan2 角度、SMO＋PLL | 无感估计的首个候选；先修正并离散化适配 |
| `11、进阶滑模：ChenshaMotor_FOC_SMOSimple.zip` | STM32G4 工程，`dreverSC/Src/callback.c` 的 `SMObserver_Calculate()` | 辅助核对 20kHz 场景下的 SMO 实现；该函数是 sign＋低通＋atan2 路线 |
| `SmallSPMSM_PI_DPCC_2022b.slx` | PI 对照和带两步预测的 DPCC | 预测控制迁移第一批，保留主模型原 PI 作比较 |
| `SmallSPMSM_iDPCC_2022b.slx` | 电流增量预测、历史电压及电压增量状态 | DPCC 验证后迁入增量版本 |
| `MFPCC_ESO_DPCC_2022b.slx` | LESO 估计电流与总扰动、基于估计的电压控制；另有 DPCC | 最后迁入 ESO 电流控制；这里的 ESO 不等同于无感位置观测器 |

已检查的控制函数及自编驱动中未识别出独立 PR、重复控制或多同步坐标系谐波抑制器。DPCC/ESO 可能影响电流频谱，但不能据此称它们已经实现专用谐波抑制。谐波抑制需要另行设计。

四个参考 SLX 都包含 SPS 的电机、Universal Bridge、powergui 等引用。迁移范围应是算法核心，继续复用主模型普通 Simulink 实现的被控对象；参考整机能否在当前环境直接编译尚未验证。

## 2. 源码中已经看到的适配点

### 2.1 SMO 与 PLL

- 参考 SMO 初始化写的是 R=0.958Ω、Ld=5.25mH、Lq=12mH、4极对；SMO 函数内部又硬编码 Rs=0.958Ω、Ld=5.25mH、Tsc=1µs。主模型现有沉沙档案为约 Rs=0.105125Ω、Ld=Lq=103.7615µH、5极对、50µs 快环。模型名称相近不代表电机参数相同。
- 顶层初始化 `Ts=10µs` 与函数内 `Tsc=1µs` 不同。实际执行率必须通过编译确认，不能直接把内部积分周期视为原模型真实周期，更不能照搬到主快环。
- `chart_98` 的 PLL 计算了 `integral_pll = integral_pll_old + ...`，但函数末尾没有 `integral_pll_old = integral_pll`。从源码可确定积分历史没有正常累积；需要修正并增加积分限幅/抗饱和，不能把修正前后称为同一算法结果。
- `chart_98` 的反电动势低通截止频率是200Hz，PLL鉴相误差未作幅值归一化。主模型3000rpm、5极对时电频率为250Hz，必须评估滤波相位滞后、鉴相增益随转速变化及补偿，不能直接沿用增益。
- ZIP 的 SMO 使用硬编码 `inv_Ld=9523.8`，即约105µH，与主电机更接近，但仍须统一参数来源；该函数使用上次 αβ 指令电压，不能仅凭变量名证明它等于实际施加电压。
- 明确 αβ/Park 的正方向、电角零位、正反转下的反电动势方向及 PLL 锁定分支。对正转能估角不等于反转及过零也成立。

### 2.2 DPCC、iDPCC、ESO

- 参考快环 `Tsc=100µs`，主快环为50µs；Rs、L、磁链、惯量也不同。先按主参数重建控制律，不改主电机来迁就参考。
- 多个函数把 `U_max=Udc/sqrt(3)` 放在 persistent 初始化中。需要改成每拍由当前控制母线计算，统一使用主模型既有0.96裕量圆限幅。
- 参考函数同时完成控制律、圆限幅、`theta+1.5*we*Tsc` 和逆Park。主模型已有完整前馈、最终限压、逆Park、真实CCR更新；整段粘贴会造成重复处理。
- DPCC 本身已经包含电机耦合/反电动势项，ESO 的总扰动也吸收相应作用。切换控制器时应由所选控制律明确负责前馈，不能把原 PI 的 dq 前馈再无条件叠加。
- “上次算出的电压”不一定是“上一采样区间真正施加的电压”。预测器和 ESO 的电压历史应关联实际生效 CCR、母线与时间区间；不能用未限压或尚在队列中的指令冒充。
- 参考固定1.5拍补角和两步预测依赖其延迟假设。主模型的JEOS、计算完成与UEV存在不同相位，应先明确预测时域和坐标旋转，再按真实事件推导，不能机械保留1.5拍或重复加延迟。

## 3. 主模型只增加三个局部接口

继续保留现有九宫格及小模块阅读方式；新增内容进入所属区域。初期采用停止仿真后选择模式，避免把运行时任意热切换列入首批范围。

### A. 反馈来源接口：采样反馈区域

统一输出 `theta_ctrl` [电角rad]、`omega_e_ctrl` [电rad/s]、`speed_ctrl` [机械rpm] 与有效标志。机械速度和电速度显式换算：`omega_e = pole_pairs * speed_rpm * 2*pi/60`。

模式依次增加：原路径、编码器、SMO旁路观测、SMO反馈。旁路时控制继续使用编码器；SMO只接测量电流与可实现的电压重构。真值供评估与明确标注的诊断对照使用。

必须统一替换 Park、逆Park、解耦前馈、速度PI及新增算法使用的角度/速度来源。仅换 Park 角度、前馈仍取真实转速，属于混合反馈，不能标记为完整无感。

### B. 电流控制器接口：电流环区域

输入：同拍 id/iq、参考值、角度/速度、采样周期、控制参数、有效标志、使能/复位，以及因果可用的施加电压历史。

输出：未最终限压的完整 dq 电压请求、诊断和内部状态。原 PI 模式保留原PI＋前馈运算顺序；DPCC/iDPCC/ESO 输出自己控制律对应的完整电压。

控制器互斥选择：原 PI → DPCC → iDPCC → ESO。统一复用下游限压、逆Park、SVPWM、CCR和功率桥。原 PI 的回算沿用既有语义；预测控制器使用与其状态含义相符的饱和处理，不把PI回算直接接入预测器。

### C. 谐波补偿接口：完整电压请求之后、最终圆限幅之前

`vdq_request = vdq_base + vdq_harmonic + vdq_existing_compensation`

此式表达统一电压合成的设计目标。现有死区补偿若处在其他坐标系，须先核对实际连接、变换角度和生效顺序后接入，不能只移动连线就假定等价。

所有附加电压共享同一个母线预算。最终残差仍回到基础PI；新谐波控制器还须定义自己的限幅和饱和冻结/回退规则。不能让两个积分型控制器各自按全部残差回算而相互争用。

## 4. 推荐分批顺序

| 批次 | 做什么 | 本批完成的可见结果 |
| --- | --- | --- |
| 0 | 冻结当前参考、明确三个接口及所有反馈使用点 | 新算法关闭时旧日志严格回归，配置和结构可恢复 |
| 1 | 主PI＋编码器控制下，接入修正后的 SMO＋PLL 旁路观测 | 同屏看角度误差、转速误差、电流估计和反电动势；不接管 |
| 2 | 编码器条件下，建立死区谐波基准，再实现一个6次dq谐波补偿器 | 同桥、同工况比较指定谐波及真实电流/转矩变化 |
| 3 | 先完成编码器辅助的 SMO 接管试验，再增加独立无感启动 | 可追溯反馈切换、锁定判断、失锁退出及启动状态 |
| 4 | 在编码器反馈下依次接入 DPCC、iDPCC、ESO | 与原 PI 在同一电机、桥、时序和限制下比较 |
| 5 | 从已单项通过的组合中选择少量集成工况 | SMO＋谐波补偿、SMO＋预测控制等逐组验证 |

批次1与批次2在逻辑上独立。推荐先完成旁路SMO，因为它能最快暴露电压历史和参数接口问题；随后做谐波单项，避免无感接管和谐波整定同时发生。

### 无感接管怎样推进

先由编码器完成启动和加速，SMO持续观测；进入预先定义的工作区、连续满足锁定条件后，进行受控接管。这一阶段明确称为“编码器辅助接管验证”。

真正独立无感启动另行增加：定位/预励磁 → 开环 I-F 加速 → 观测器锁定 → 角度及速度平滑接管 → 无感闭环。锁定条件采用反电动势幅值、电流预测残差、PLL误差及持续时间，不能用真实角度误差作无感运行许可。

保留原启停的门极许可、PI复位、PWM队列撤销机制，但扩展其准备条件：当前启停等待编码器测速有效，不能只替换最终角度而保留该依赖。停机、重启、失锁和反转均要定义SMO/PLL状态如何复位或继续运行。缺样期间也不能当成正常新采样继续更新。

基于反电动势的首版SMO先限定于可观测的转速范围；零速保持、低速重载及过零反转不作为首版承诺。其启动与适用工作区需要单独验证，参见[MathWorks无感控制路线](https://www.mathworks.com/help/mcb/sensorless-approach.html)。

### 谐波抑制怎样选首个算法

首个对象选择已有详细桥中的死区畸变，使用同一详细桥的零死区/有死区作参照。先关闭已有死区补偿测出目标谱线，再分别比较已有补偿、新谐波补偿及二者组合，区分作用来源。

建议首版采用随电频率调整的有限带宽6次dq谐振补偿，输出附加dq电压；先在固定转速工作点验证，再做变速频率跟踪与状态过渡。重点观察ABC的5/7次及对应dq的6次分量，但须从实测仿真数据确认幅值与序分量。MathWorks也有[死区导致5/7次谐波的抑制示例](https://www.mathworks.com/help/slcontrol/ug/reduce-thd-in-pmsm-using-adaptive-notch-filter.html)；本项目可借鉴问题设置，首版实现继续使用普通Simulink块或局部MATLAB Function，不强制引入附加工具箱。

3000rpm、5极对时基频250Hz，6次为1500Hz。控制周期50µs，应检查谐振器的离散相位、实际执行延迟、采样滤波和可用电压；不能仅因频率低于奈奎斯特频率就认定闭环可行。低速、停机、频率跳变及电压饱和时规定冻结、衰减或退出策略。

首版通过后再考虑5/7次多同步坐标系控制；重复控制、更多谐波阶次和观测器谐波抑制作为后续候选。电流谐波、反电动势谐波、估计角抖动分别评价。

## 5. 每批验收方式

共同要求：保存模型/源码指纹、Plant真实参数与控制器估计参数、算法状态初值、采样与执行周期、场景、原始信号和失败记录。参数失配实验只改变控制器估计参数，避免把电机和观测器一起修改而掩盖敏感性。

| 能力 | 核心检查 |
| --- | --- |
| 关闭回归 | 原路径和运算顺序保留；对共同原始Time/Data严格比较；主SLX及固定参考可恢复 |
| SMO旁路 | 电压/电流区间对齐、角度环绕误差、速度误差、PLL积分递推、正反转方向、失锁及缺样；核对控制未被旁路观测改变 |
| SMO闭环 | 所有反馈使用点来源一致、切换电压/电流冲击、启停依赖、锁定持续时间与退出；分别记录编码器辅助和独立启动 |
| 谐波控制 | 整数电周期或角度域分析，ABC 5/7次、dq 6次、电流RMS/峰值、转矩纹波、电压饱和占比及动态代价 |
| 预测控制 | 实际施加电压来源、预测时域、前馈不重复、动态母线限压、状态复位、参数失配及真实更新延迟变化 |
| 集成 | 先理想桥或同桥零死区验证算法，再逐项加入死区、噪声、滤波和采样窗口限制；优先运行少量有代表性的组合 |

频谱同时保留真实电流与控制测量电流，防止仅靠反馈滤波让谱线看起来变小。按统一带宽、窗口及归一化规则报告THD；任务同步瞬时转矩日志不能代替全带宽转矩纹波。谐波幅值很小时，同时报告绝对幅值，避免接近零的分母制造巨大改善率。

旁路SMO和离线分析可以立即推进；正式无感接管前需补齐本次试验用的过流/失锁锁存和退出规则，复用既有门极关断。8A仍是iq给定限制。没有母线动态模型时不宣称验证再生过压保护。

建议预先约定估角、速度误差、接管冲击、谐波降幅及动态代价的验收门槛；首轮按固定工况摸底后，在正式对比前冻结阈值。不预先承诺所有工况都优于原PI或已有补偿。

## 6. 第一批实际开发范围

第一批只交付“SMO＋PLL旁路观测”：修正PLL状态更新，参数化Rs/L/Ts及增益，按20kHz事件边界执行，接入可实现的电压重构与测量电流，增加一组统一观测并验证关闭回归。电压真值另作诊断对照，不作为最终无感算法输入。

第一批暂不替换主PI、不改原PI增益、不接管反馈。完成后即可依据波形决定参数、滤波与重构方案，然后进入谐波单项和接管开发。

本目录 `reference_inventory.json` 保存参考块、回调及函数位置；各 `*_chart_*.m` 为静态提取快照，供带读和比对，不作为已适配且可直接调用的算法文件。ZIP提取的 `firmware_*.c/.h` 同样仅作为来源快照。
