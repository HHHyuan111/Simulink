## 3. 异步电机模型

### 3.1 控制结构

这是带转子磁链电流模型观测器的异步电机 FOC 示例。根据实际连线，主要控制路径为：

```text
转速给定 - 转速反馈 → ASR 速度 PI → 转矩误差 → ATR 转矩 PI
                                               ↓
                                           q 轴电流给定
                                               ↓
三相电流 → abc/dq 变换 → d/q 电流误差 → ACMR/ACTR 电流 PI
                                               ↓
                                   dq/αβ 变换 → SVPWM
                                               ↓
                                 IGBT 逆变桥 → 异步电机

磁链给定 - 磁链观测值 → AFR 磁链 PI → d 轴电流给定
电流模型磁链观测、滑差计算与速度反馈 → 积分得到变换角度
```

它包含额外的磁链环和转矩环，不能只按“速度环加两个电流环”来理解。电机真实转速参与角度生成，因此这里不能直接认定为完整无位置传感器方案。

### 3.3 应先检查的地方

1. **额定参数中的表达式疑似笔误。** 电机块 `NominalParameters` 原文为 `[1.5+04 380 50]`。第一项实际算得 5.5；若作者原意是 15000，应写 `1.5e4`，但真实目标值仍需确认。该块的第一项单位是 VA，不能直接写成 15 kW。参数定义见 [MathWorks 异步电机文档](https://www.mathworks.com/help/releases/R2022b/sps/powersys/ref/asynchronousmachine.html)。定位：电机块 SID 312。
2. **速度阶跃不会在默认仿真内发生。** `Step Load2` 在 2 s 切换，停止时间却是 1.5 s。默认运行只能覆盖 800 rpm 给定阶段。定位：SID 350 和模型配置。
3. **观测器参数与电机参数含义需要核对。** 观测器时间常数使用 `0.000991/0.2206`，而电机块中的 0.000991 是转子漏感。官方定义的总转子电感还包含励磁电感。角度积分前，机械转速也直接加入滑差支路，未看到乘极对数 2 的增益。这两处应在下一步对照推导和波形核查，暂不将仿真精度视为已经验证。定位：Transfer Fcn SID 283、Gain SID 287、Sum4、Integrator；物理量定义同上方官方文档。

## 4. PMSM 主模型

### 4.1 控制结构与已有功能

这是表贴式/隐极式 PMSM 的速度—电流双闭环示例。当前参数 `Ld=Lq`，d 轴电流给定为 0。

```text
3000 rpm 给定 - 转速反馈 → 速度 PI → 转矩给定 → iq 给定
                                                        ↓
三相电流 → Clarke/Park → id、iq → 两路电流 PI 与前馈项
                                                        ↓
                                    反 Park → αβ 电压给定
                                                        ↓
                       内嵌 SVPWM 函数 → 三角载波比较 → 六路门极
                                                        ↓
                                  IGBT 逆变桥 → PMSM
```

电角度由电机模型的机械角度乘极对数、对 `2π` 取模得到；没有发现编码器脉冲计数或位置估算器。脚本中的 `RE=1024`、`rr=2π/1024` 定义了编码器相关数值，但当前角度链路直接使用电机真实角度。

内嵌 SVPWM 完成：αβ 投影、扇区编码、两个有效矢量作用时间、过调制处理、七段式切换时刻计算。函数输出三相比较阈值 `Tcm` 和扇区码；后级与 `[0, Ts/2, 0]` 三角载波比较，产生三对互补门极。没有看到专门的死区生成模块。

模型还保留两路 DSP Chirp 和误差监测支路。但实际控制输入仍是 `speed_ref=n` 和 `id_ref=0`；扫频输出只接到相应的监测参考标签，没有接到实际控制误差的给定端。因此，原样运行不能直接证明扫频闭环响应。另一个 500 Hz、幅值 `0.1*Vdc` 的 AC Voltage Source 当前没有电气连线，不能将其理解为已经施加的母线纹波。

### 4.3 静态检查发现的问题

**A. SVPWM 过调制归一化存在明确的顺序赋值问题。**

模型内原文是：

```matlab
if((t1+t2)>Ts)
    t1=Ts*(t1/(t1+t2));
    t2=Ts*(t2/(t1+t2));
end
```

第二行使用了已经修改的 `t1`，因此两个时间没有用同一个原始总和归一化。按模型原公式取 `alpha=12 V`、`beta=12 V`、`Vdc=24 V`、`Ts=50 μs`，复算结果为：

| 量 | 复算结果 |
| --- | ---: |
| 原始 `t1+t2` | 59.150635 μs |
| 处理后 `t1+t2` | 51.582857 μs，仍超过 50 μs |
| `t0=(Ts-t1-t2)/2` | −0.791428 μs |
| 三相 `Tcm` | [−0.395714, 6.303016, 25.395714] μs |
| 载波范围 | 0～25 μs |

这能导致阈值超出载波范围。正确处理应先保存原始 `t1+t2`，再同时按该总和缩放；本次仅记录问题，未改模型。定位：`SVPWM Function v1.0`，SID 240，内嵌 `chart_20.xml`。原函数已经提取到 `review/extracted/fcn.m`，便于直接阅读。

**B. 速度环封装显示的采样周期不控制内部实际采样。**

速度 PI 的封装字段是 `SampleTime=1/fwb`，按脚本等于 20 ms；内部零阶保持和离散积分器却都直接使用 `dt=50 μs`。调整封装字段不会按其显示值改变这两个模块。定位：`PI Controller_w`，SID 155。

**C. d 轴 PI 实际也引用了 q 轴参数。**

`PI Controller_w1` 连接在 d 轴误差后，但其封装使用 `kp_iq/ki_iq/ks_iq/uplimit_iq/downlimit_iq`。当前 `Ld=Lq`，两套参数恰好相同；将来改成凸极电机时，仅修改 `kp_id` 等参数不会改变这一路 PI。定位：SID 439。

**D. 功率、转矩和电流口径不完全一致。**

脚本标称 `Pn=200 W`，但用 `In=9.2 A` 计算得到 `Tn=0.29808 N·m`，在 3000 rpm 下对应机械功率约 93.64 W。200 W 在该转速下约需 0.63662 N·m，也超过当前速度环 ±0.357696 N·m 的限幅。需要确认额定电流的 RMS/峰值口径、电机额定点和限幅目标，不能只依据 `Pn=200` 认定模型已覆盖 200 W 工况。

**E. 速度 PI 设计公式与模型输出单位需要核对。**

脚本中 `K=(30/pi)*1.5*phis*p`，环路分析使用包含转矩常数的对象；主模型的速度 PI 输出命名为 `Te_ref`，又除以转矩常数得到 `iq_ref`。两处描述的输入单位存在需要核对的地方，因此 50 Hz 只能视为脚本设定目标。

**F. 当前结构以 `id=0` 的隐极电机为前提。**

转矩到电流换算分母按连线为 `1.5*p*(phis+Ld*id)`。这不是可直接推广到任意 `Ld≠Lq` 电机的通用转矩换算；q 轴前馈中的 `ωe*Ld*id` 也未接入。改变 d 轴给定或电机凸极性时，需要连同这些公式核查。

## 5. 两个 MATLAB 脚本的使用方式和局限

`PMSM_FOC_parameters.m` 会先执行 `clear all` 和 `clc`，之后把参数放入基础工作区。模型没有设置自动执行该脚本的 InitFcn，因此应先手动运行参数脚本，再打开主模型。`fcb`、`fwb` 和 `wc`、`wsc` 分别被写成独立的数值表达式；修改前一组不会自动同步后一组。

`Control_Loop_Calculation.m` 依赖参数脚本已创建的变量。它分析的电流环是：

```matlab
(kp_id + ki_id/s) / (Rs + Ld*s)
```

速度环则是：

```matlab
(kp_w + ki_w/s) * (wc/(s+wc)) * K/J/s
```

两个表达式都是开环形式，没有用 `feedback` 构造完整闭环。`getPeakGain` 计算频响最大增益及其频率，不能直接当作闭环带宽；这些表达式含积分，低频增益还可能无界。函数定义见 [MathWorks getPeakGain 文档](https://www.mathworks.com/help/control/ref/dynamicsystem.getpeakgain.html)。另外，两段都使用 `figure(1)`，后画的速度环图会覆盖前一幅图；第一段电流环图的标题也误写为速度环。

## 6. 旧备份与当前模型的区别

`PMSM_FOC.slx.r2020b` 的元数据显示：R2020b，2023-11-08 保存，模型版本 1.4；当前主模型为 R2022b，2023-12-05 保存，版本 5.102。

旧备份只有顶层 22 个模块，含其 PID 子系统共 30 个；能看到电机、逆变桥、坐标变换和一个 PID 雏形。逆变桥的门极输入没有接驱动，PID 输出没有继续接到控制功率电路的链路，也没有当前主模型的内嵌 SVPWM 和完整速度/电流闭环。

所以它可以用于查看早期搭建过程，不能当作当前完整模型的等价低版本导出。需要在 R2020b 运行完整 PMSM 时，应对当前主模型做兼容性导出和验证，不能简单重命名这个旧备份代替。

## 8. 后续使用价值与优先顺序

这套资料适合拿来学习电机 FOC 的信号路径、PI 搭建和 SVPWM 实现。其中 PMSM 主模型的分区和配套参数更清楚，可以先阅读它，再对照异步电机模型理解磁链观测、滑差和额外调节环。

下一步应先修正或确认 SVPWM 过调制归一化、异步电机额定参数表达式、速度阶跃时间，再核对控制器单位和观测器参数。之后才适合用启动、变速、负载扰动和电压饱和工况评价控制性能。仓库没有自动测试、已保存的结果数据或明确验收指标，现有文件不足以证明稳定性、带宽和额定点性能。

没有发现许可证文件；README 中的“研究和教学用途”说明也不是完整的开源许可证声明。

- `static_checks.json`：完整性检查与上述数值复算结果；明确标注没有 MATLAB 运行验证。
- `extracted/fcn.m`：从 PMSM 主模型提取的 SVPWM 函数原文，未修正。这里只作为阅读副本，主模型仍执行其内部函数。
