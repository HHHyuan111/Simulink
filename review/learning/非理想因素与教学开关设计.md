## 设计目标

让每个实验回答三个问题：这个因素从哪里产生？经过哪些模块影响控制？打开和关闭时，哪条波形能说明它的作用？

保留原来的小模块和计算过程，在相关接口增加必要的误差、保持或时序环节。色域标题继续采用“速度环”“电流环”“SVPWM”“采样反馈”等短名称。每个相关色域留一个小型“设置”入口，避免把所有分支、开关和长线铺满主画布。观测色域负责显示结果，无须为了形式统一而加入物理误差。

每项设置包含：启用标志、参数值、单位、来源、适用条件、运行前设置或允许运行中调整、对应观测。参数来源统一使用“演示 / 数据手册 / 实测 / 辨识”，并记录日期。

需要分开三种东西：

- **物理因素**：死区、导通压降、采样偏置、噪声、母线变化。
- **控制策略**：解耦、抗饱和、死区补偿、角度预测、滤波。
- **故障注入**：丢帧、错误方向、ADC 卡死、计算超时等异常工况。

物理因素和补偿策略使用不同开关。例如“死区”与“死区补偿”可以独立选择，便于比较理想、存在误差、加入补偿三组结果。

## 先讲清楚频率与延迟

### 五种容易混淆的量

| 量 | 含义 | 教学例子 |
| --- | --- | --- |
| PWM 频率 | 完整载波周期的重复频率 | 20 kHz，对应 50 μs |
| ADC 采样频率 | 捕获模拟量的频率及相位 | 每 PWM 周期采一次，或有定义的多次采样 |
| 电流环执行频率 | 电流控制器实际更新状态和输出的频率 | 每周期执行一次时为 20 kHz |
| 速度环执行频率 | 速度控制器实际更新状态和输出的频率 | 可用 1 kHz 演示多速率，每 20 次电流任务更新一次 |
| 环路带宽 | 对变化信号进行跟踪或抑制扰动的动态能力 | 需要按闭环响应确定，不能等同于执行频率 |

求解器步长是另一个独立量，用于数值计算。当前 1 μs 步长不表示控制器以 1 MHz 执行。当前速度环默认仍为 50 μs；上面的 1 kHz 是待演示选项。

速度环通常设计得比电流环慢，使电流环能较快跟踪外环给出的指令。执行频率比、带宽比需要分别选择；不存在仅凭 MCU 型号就能确定的唯一配比。[MathWorks R2026a 采样与 PWM 架构](https://www.mathworks.com/help/releases/R2026a/mcb/gs/motor-control-using-different-current-sampling-pwm-frequencies.html)展示了采样、计算和 PWM 可以有不同关系；其中部署示例面向其他处理器，此处借鉴时序原理。

多速率接口要明确“本次读取的是哪次采样”“输出保持多久”“同时发生时先执行谁”。速度任务未执行时，iq_ref 保持上次值；Rate Transition 等数据传递机制也应按实际调度设置。

### 用一条事件时间线管理延迟

```text
PWM 触发 ADC
    → 模拟采样窗口与捕获时刻
    → ADC 转换完成
    → 电流中断开始
    → 控制计算完成
    → 写入 CCR 预装载
    → 定时器更新使 CCR 生效
    → 驱动传播与死区
    → 桥臂电压改变
```

采样时刻和数据可用时刻不同。计算虽然完成，也可能要等到下一个定时器更新点才生效；若错过更新期限，则按实际固件保持旧值或进入相应异常状态。中心对齐模式本身不能唯一决定延迟是半周期还是一个周期。STM32 的更新源、RCR、CCR 预装载和 ADC 触发选择应结合固件及 [RM0440](https://www.st.com/resource/en/reference_manual/rm0440-stm32g4-series-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)核对。

建议教学设置：ADC 触发位置、转换耗时、ISR 等待时间、计算耗时、CCR 生效点、抖动幅度和超时处理。初期先使用固定耗时，之后才增加抖动。

纯延迟 Td 在频率 f 处额外产生的相位滞后为 360° × f × Td。例如 1 kHz 信号经过 50 μs 纯延迟，会额外滞后 18°。这只是该延迟项的贡献，完整离散环路还包含采样保持、滤波和电机等动态。建立事件模型后，不再额外叠加一份未经推导的“整周期延迟”。

## 测量链：零偏、噪声和采样窗口应分别演示

建议先建立以下通路：

```text
真实相电流
    → 分流电阻 / 放大器 / 偏置 / 模拟噪声与干扰 / RC 动态
    → ADC 采样保持、转换、量化与饱和
    → 固件标定与电流重构
    → 控制器使用的测量电流
```

模拟前端内各元件与噪声注入位置最终按原理图确定。模拟噪声经过实际对应的滤波和采样；ADC 内部误差可在后续位置单独表达。保留真值供诊断，闭环使用测量通道的输出。

| 开关短名称 | 参数示例 | 预期研究的问题 |
| --- | --- | --- |
| 零偏 | 各相偏置、固件校准值 | 测得电流为零时，真实电流是否也为零？ |
| 增益 | 分流/放大增益与标定系数的偏差 | 三相不一致是否带来 dq 脉动？ |
| 噪声 | RMS、带宽、相关性、随机种子 | 噪声如何经 PI 变成电压抖动？ |
| 开关干扰 | 干扰相对 PWM 边沿的位置、持续时间、幅度 | 改变采样点是否比加强滤波更有效？ |
| RC 滤波 | 实际 R、C 或有依据的等效动态 | 降噪获得多少收益，又引入多少相位滞后？ |
| ADC | 有效分辨率、参考电压、偏置、码值范围、转换时间 | 小电流是否出现量化阶梯，过量程如何截断？ |
| 采样窗口 | 拓扑、建立时间、采样孔径、消隐时间 | 窄脉冲或高调制度时是否还能获取有效样本？ |

零偏、增益误差和 ADC 量化不能由一条随机噪声统一替代。采样前端和固件标定值也要分开，否则同时改变两者可能恰好抵消误差。[ST AN2834](https://www.st.com/resource/en/application_note/an2834-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf)可用于核对源阻抗、采样时间、参考电压、校准及噪声等来源。

单分流、双分流、三分流和在线传感器的有效窗口不同，待实际电路确认后选择。窗口无效时应输出无效标志，按固件重构、预测或保持，不能继续读取理想相电流。噪声实验采用固定种子，使对比可重复。

母线也分成“真实母线”和“测得母线”：桥使用真实电压，控制器使用经过分压、滤波和 ADC 的反馈值。

## 角度与速度反馈

可设置“角度偏置”“角度延迟”“量化”“丢帧”，测速滤波单独设置。反馈来源在编码器、霍尔、磁编码器或无感估算器中按实物选择，不把它们混成同一种误差模型。

机械角与电角需区分：电角误差是机械角误差乘极对数。角度延迟造成的电角误差近似为 ωe × Td。当前演示参数 p=4、n=3000 rpm 时，电频率为 200 Hz；100 μs 延迟对应 7.2° 电角滞后。这只是算例，足以说明高速时角度时间戳很重要。

测量角偏差会使控制器使用的 dq 轴相对真实磁场旋转，观察真实/测量 id、iq、转矩和效率相关量。Park 使用采样时刻的角度，逆 Park 可选择使用预计电压生效时刻的角度；角度预测作为单独控制策略，不能直接偷用未来真值。

## 逆变器：死区及非线性

### 死区

死区期间同一桥臂上下管均关断，电流仍可能通过二极管续流，输出电压由电流方向等状态决定。当前理想桥依赖互补门极关系，尚不能正确描述该状态，因此不能直接在现有 NOT 支路后面加延迟后就宣称死区仿真完成。

拟采用两种互斥的表示方式：

- **平均误差**：用有适用条件的等效电压误差表示，适合较长时间的控制与教学对比。
- **开关细节**：明确两管关断、续流、电压钳位和门极时序，适合短时间研究过零失真、脉冲和采样窗口。

同一个死区不能同时通过门极延迟和平均误差重复计入。在简化、连续导流条件下，桥臂平均电压误差量级可写为 Vdc × td / Tpwm，符号取决于电流方向；过零附近和实际器件需要更细模型。[TI 死区原理说明](https://software-dl.ti.com/mcu-sdk/esd/AM13E2X-SDK/26_01_00_03/exports/docs/docs/am13e230x/user_guide/chapters/solutions/am13e230x/motor_control/control_advance_features.html#dead-time-compensation)用于此处的原理参考，不将其 TI 控制算法照搬到 STM32。

例如 24 V、20 kHz、1 μs 演示死区得到约 0.48 V 的上述误差量级；它不是实际板子的死区或精确相电压误差。死区和死区补偿分别控制，重点观察低速小电压工况、电流过零、dq 电流与转矩脉动。

### 其他功率级因素

| 开关短名称 | 考虑内容 | 主要教学现象 |
| --- | --- | --- |
| 导通压降 | MOSFET Rds(on)、二极管压降及温度依赖 | 小电压指令下相对误差更明显，损耗随电流变化 |
| 驱动延迟 | 传播延迟、上下沿不对称、相间差异 | 实际脉宽与指令脉宽不同 |
| 最小脉宽 | 驱动及采样建立所需时间、脉冲抑制规则 | 高调制度或扇区边界附近指令不可完整实现 |
| CCR 量化 | 定时器时钟、ARR、计数模式、舍入方式 | 占空比变化呈离散阶梯 |
| 母线动态 | 电容、ESR、供电阻抗、供电限流及再生吸收 | 加速压降、制动抬升与电压能力变化 |

寄生电感、电容、振铃、反向恢复和 EMI 可在需要研究开关边沿时追加。当前 dq 电机及理想桥不能据此预测纳秒尺度波形或板级 EMC。

## 电机、机械负载与固件

电机先对齐参数口径，再研究参数失配：电阻相值/线间值、电感和磁链定义、峰值/RMS、机械角/电角。模型真值参数与控制器使用的名义参数分开保存。

优先选择“参数失配”“温升”“负载扰动”“摩擦”作为教学项。先用 Rs、Ld、Lq、磁链、惯量 J 的偏差解释电流动态、前馈和加速；之后按需要加入 Rs 随温度变化、磁链温漂、电感饱和、干摩擦、齿槽转矩及负载特性。非线性电感应采用一致的磁链关系，不能只任意替换方程中的常数。

固件对齐单独安排：float32 或实际定点格式、舍入、饱和、查表/CORDIC 精度、PI 离散更新顺序、初始化/复位、任务先后及真实 C 核心。MCU 具备某项资源不等于固件已经使用它。暂时保持当前整定参数，先解释这些因素的影响。

过流、欠压、过温、传感器断线、丢帧和计算超时放入明确的故障注入实验，记录触发、关断、积分状态、复位和重启过程；具体阈值以真实板级设计为准。

## 开关的交互方式

以“采样反馈 → 设置”为例，面板中提供简短复选项：

```text
零偏       [开/关]   参数…
增益       [开/关]   参数…
噪声       [开/关]   参数…
RC 滤波    [开/关]   参数…
ADC 量化   [开/关]   参数…
采样窗口   [开/关]   参数…
```

面板中的选项指向真实参与仿真的参数，避免显示状态与实际模型不一致。原始换算、PI、变换与调制小模块继续可读。必要的新增物理环节就近放置，只有确需不同实现的部分才使用局部选择结构。

简单误差强度可通过参数或信号选择实现；平均/开关等不同实现可评估局部 Variant Subsystem。[R2026a Variant Subsystem](https://www.mathworks.com/help/releases/R2026a/simulink/slref/variantsubsystem.html)支持不同激活阶段，具体选择须结合模型状态与接口验证。第一版采用保守、清楚的规则：

- **运行前选择**：任务周期、采样架构、平均/开关表示、数据类型、求解设置，以及需要重新编译或初始化的结构。
- **通过验证后允许运行中调整**：部分偏置、干扰强度、负载等可调标量；记录准确切换时刻。滤波器、估算器和积分器的状态如何保留或复位必须明确。
- 不兼容的组合明确拒绝，例如在不支持续流的理想桥上启用开关级死区。

提供“参考”“时序”“测量”“功率级”“组合”预设，预设只负责选择参数组合，所有单项仍可查看。硬件数据齐备且校准完成后，再提供“实物配置”。

## 教学实验建议

| 实验 | 固定什么，只改什么 | 应观察什么 |
| --- | --- | --- |
| 外环慢一点会怎样 | 固定 PI 参数和电流任务，改变速度任务周期；不同时重新整定 | iq_ref 的保持阶梯、速度动态；避免将执行频率误称为带宽 |
| 同一算法晚一步生效 | 固定周期、采样点与 PI，改变计算完成时刻/CCR 生效点 | 时间线、指令至电压的等待、振荡或响应变化 |
| 噪声与滤波的代价 | 同一噪声种子和工况，分别开噪声、再开滤波 | 真值/测量电流、PI 输出抖动、滤波滞后 |
| 电流零偏为何影响真实输出 | 单独给某一路加入偏置，保持标定系数 | ADC 码、测量 dq、真实 dq 与转矩 |
| 角度为何越快越敏感 | 固定角度延迟，选择两个转速；与固定角偏差实验区分 | 电角误差、dq 串扰、转矩 |
| 死区怎样扭曲小电压 | 先使用经核查的桥模型，分别关闭死区、开启死区、再开启补偿 | 过零电流、桥臂电压误差、dq 脉动 |
| 母线下降时电压够不够 | 固定速度/负载，施加有定义的母线下降 | 最终可实现电压、限幅标志、积分恢复 |
| 有效窗口消失时怎么办 | 选定真实分流拓扑，逐步提高调制度 | 有效样本标志、重构/保持行为、控制误差 |

实验结果不预先保证超调必然增大或某条曲线必然改善。固定对比条件后，用记录解释实际结果。

## 实施和验收顺序

1. **先完成必要的算法正确性核查，暂缓整定。** 当前 d 轴参数绑定、q 轴前馈、最终电压矢量限幅/抗饱和以及 SVPWM 过调制归一化仍需单独修复验证；不能把这些错误当作物理因素或正常教学选项。建立有明确范围的参考版本。
2. **第一批：时序 + 测量 + 对照观测。** 固定耗时，多速率保持，电流零偏/增益/噪声/量化及角度延迟。采样拓扑未知时，窗口功能只作为待配置项，不宣称已贴合实板。
3. **第二批：桥模型 + 死区 + 器件/母线。** 先验证续流和桥臂状态，再接入闭环；补偿独立启用。
4. **第三批：电机与固件对齐。** 用实际参数、任务配置和代码替换演示假设，之后再谈有硬件意义的整定。

每批验收要求：

- 所有新增非理想因素关闭时，复现该批修改前已确认的参考结果；算法修复版本与此前版本的差异独立记录。
- 单个因素有可解释的输入输出或解析关系，叠加多个因素后不重复计算同一延迟/死区。
- 保存参数、开关状态、来源、随机种子、初始条件、给定和负载历史，进行可重复的 A/B 比较。
- 记录真实与测量电流/角度、指令与实际电压、饱和标志，以及关键事件时间。控制器不读真值旁路。
- 速度任务周期变化时，核对编译后周期与实际更新记录；PI 的离散状态更新确实使用相应周期。
- 当前 1 μs 数值步长对微秒或更短死区可能过粗。开关级实验需进行更小步长的收敛检查；平均误差表示则说明无法观察门极细节和高频纹波。
- 有了实测数据后，在相同工况和采样口径下校准，并用独立工况验证；开关数量不作为“贴近实物”的验收标准。

本文为完整设计。首批实施仅覆盖多速率、等效采样/角度误差及整周期延迟；完整实板时序、死区/续流、器件非线性及标定仍待后续实现。
