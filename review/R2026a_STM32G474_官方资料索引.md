# R2026a + STM32G474RET6 官方资料索引

检索日期：2026-10-10。优先使用 MathWorks 的 R2026a 归档页面和 ST 官方资料。部分 MathWorks 当前主页已显示 R2026b，不能直接将其中新增功能当成 R2026a 功能。

下列资料按开发用途整理。本轮确认了迁移入口、块接口与参数、G474RE 示例、工具版本和代码接入/PIL 方向；没有逐页审阅 STM32 参考手册，也没有验证本机工具安装或板级运行。

## D. 建议的阅读顺序

1. 转换函数 + 原生 PMSM/Converter：确定 R2026a 的模型基础。
2. G474RE 无感例程的 Peripheral Configurations：重点读 ADC 触发和 PWM 更新；即使最终采用编码器，该外设调度思路仍有参考价值。
3. 采样与 PWM 架构：画出实际板子的事件时间线。
4. C Caller：确定已有固件如何接入，分离硬件驱动与控制核心。
5. 数据手册和 RM0440：收到 `.ioc`、原理图后逐项核对。
6. PIL 与实测对比：在闭环模型与算法接口稳定后进行。

具体分层架构、开发阶段、验收产物和待填参数见同目录《R2026a_STM32G474_仿真开发方案.md》。
