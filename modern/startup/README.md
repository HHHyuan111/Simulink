## 操作

从固定参考开始，MATLAB中执行：

```matlab
addpath('D:/simulink/modern/startup')
open_pmsm_startup
```

打开的是原模型上的临时启停层与原生2×2 Scope，不是另建一个电机模型。点击原模型的运行按钮。双击“启停”设置框架开关、启动/停止/重启时刻，单位ms；这些参数在停止仿真后修改。默认启动0ms、停止15ms、重启20ms、总长30ms，完整经历两次接管。修改时间时，同时保证模型停止时间晚于重启时间。

Scope只显示状态、三项许可、实际转速和反馈dq电流。状态编号0—4分别为停止、等待、采样、电流、运行；许可组顺序为电流环、速度环、PWM。白底、蓝红主色与灰色辅助线，正文解释行为，图内不放结论。

原生Scope首次载入可能暂用默认配色，首轮仿真结束会自动刷新白底和曲线颜色。观察最初的等待、采样和两环接管时，可用原生缩放查看最初0.4ms；30ms总览主要展示停止和旋转中重启。

结束体验后停止仿真，再执行专用返回入口：

```matlab
close_pmsm_startup
```

它撤销启停层、临时反馈扩展及给定接口，恢复固定参考。启停层存在时，不直接使用旧工作台的参考恢复按钮：旧入口不认识本轮新增的结构，会拒绝把它当成普通参数修改。当前有自定义配置或已展开实验时，新入口会拒绝覆盖；先保留配置并恢复参考。

## 五个状态

| 状态 | 行为 | 离开条件 |
| --- | --- | --- |
| 停止 | 六门极关断，清PWM队列，PI按各自任务复位 | 接受新的启动沿 |
| 等待 | 保持关断；编码器、测速及滤波继续运行 | 上一快环快照中的测速有效 |
| 采样 | 三低侧零矢量，PI保持复位，PWM队列保持中性 | 使能后的新JEOS；开启窗口检查时要求ABC有效 |
| 电流 | id/iq实际给定暂为0，执行电流环 | 已完成一拍电流执行，下一速度任务边界到达 |
| 运行 | 速度环接管，使用保留的用户目标 | 停止请求或准备条件失效 |

状态每50µs在JEOS边界推进，速度环原周期100µs，门极及队列每62.5ns事件网格执行。停止请求在下一快环接受，接受后同一事件格点撤销输出；不是异步硬件急停。

准备判断使用上一快环的有效标志快照，明确增加一拍启动准备判断时间。它只作用于启停决策，没有给实际角度或速度PI反馈增加一拍延迟。所选电角零位假设正确，第一版采用同源计数角度和计数测速。

采样阶段使用三低侧零矢量，区别于全关和50%占空比。原ADC触发相位下，50%占空比不能保证低侧采样有效，可能一直等待；三低侧提供零线电压和低侧采样条件。进入电流阶段后恢复原调制与CCR链。运行中低侧无效样本沿用已有保持策略，尚未升级为完整缺样故障保护。

## 停止及旁路

停止时iq实际给定在快环边界撤销，不等待下一速度任务；PI误差受许可控制，原积分器增加电平复位。三个积分器保持原Backward Euler、初值、限幅、参数和回算路径；复位释放第一拍沿用原生组件行为，不宣称无扰切换。

可控PWM队列在停止和采样阶段清除shadow、active、pending、序号及时间历史，保持中性阈值；电流接管后只允许新提交生效。最终门极互锁在已有死区组件之前作用，全关会取消待开通沿。电机状态和测速历史继续演化，不把旋转中的转子清零。

关闭框架时，编译前重连原始误差、iq给定、CCR及门极路径，并移除PI复位端口。重新打开时恢复新增许可路径。原CCR组件保留，本轮受控队列是可撤销的局部扩展；没有改写固定参考中的旧函数。

## 批处理与验收

```matlab
r=run_pmsm_startup;                    % 默认30ms，运行后自动恢复参考
validate_pmsm_startup(r.folder);       % 独立MATLAB进程严格复跑
validate_startup_components;          % 状态优先级、旧PWM旁路、队列取消
validate_startup_legacy;              % 第16项原两组100ms档案回归
```

运行记录位于`startup/runs/<时间与ID>`，包含MAT原始信号、分析、参数、模型/参考/代码指纹及成功或失败状态。原始失败包保持失败，不改写为成功。单次分析与复跑验收分别记录，不能将仿真完成等同于验收完成。

交付依据为`startup_validation.json`、`legacy_validation.json`、`window_validation.json`、`bypass_validation.json`及`component_validation.json`。主启停实验保存全程门极和PWM历史，而不是只核对末段。详细桥已知近零静态近似、理想母线、标称电机及未实测时序等边界继续保留。

已定位并修正的开发问题包括：复位端口引起的原积分器自动位移、跨采样率接口及直接馈通环、停机跨速度任务时的旧iq给定、关闭框架时的PI内部舍入差异。保留早期失败日志与记录。新版旁路重连原路径，不用放宽数值容差掩盖差异。
