查看已保存结果无需重跑。400ms整机对照采用细事件网格，本机两组运行在十分钟量级，耗时随环境变化；日常带读可先看已验收结果，或使用原较短的单项实验。预览时长、实时进度等操作体验留待用户一起调整。

```matlab
pmsm_presentation('remove');                   % 已打开整理视图时先移除
```

每组400ms。`run`使用当前代码重新仿真，`repeat`要求同模型、同源码、同计划，比较全部保留信号的Time/Data；`verify`只校验已有档案。单独运行`render_pmsm_system_baseline`会改写派生图表，应仅用于尚未封存的工作目录；封存后修改任何派生文件都会令原校验失败。

本批整机验收针对默认10000/2/200及下述工况。脚本支持其他有效参数，不代表其他参数和全部工况已经完成组合验收。计划中继承的`scenario`描述速度滤波配置模板，整机身份以`kind=integrated_system_baseline_v1`为准。

| 控制 | 速度PI、电流PI、dq前馈、限压、抗饱和、SVPWM | 原速度/电流/坐标/调制模块 | 保留原PI，非固件控制律位级复刻 |
| 功率与电机 | PMSM、负载、死区、续流、器件压降、基础补偿 | 功率设置、死区配对/低速补偿实验 | 续流近零有静态近似，母线尚无动态模型 |
| 电流测量 | 零偏、增益、噪声、ADC量化、模拟/数字滤波、延迟 | 采样设置及对应单项实验 | 误差参数需校准；不能任意叠加重复延迟 |
| 时序 | 顺序ADC、JEOS快环、速度分频、CCR预装载、更新边界、采样窗口 | 时序设置及三项时序实验 | 部分时间待实测，未模拟完整CPU调度 |
| 位置与速度 | 机械计数、电角恢复、历史延迟、窗口测速、反馈选择、一阶低通 | 可展开编码器/测速/速度反馈/速度滤波 | 不含ABZ电气边沿、Z相及自动电角定位 |
| 实验与观测 | 单项对照、原始信号、参数/源码指纹、指标、图片、独立复跑 | 16项单项实验；新增整机基线 | 单项通过不代表所有因素组合通过 |

现有19项固定参考开关包含模式及策略，并不代表19种物理误差。编码器/测速/速度滤波为可撤销扩展，参数另存实验计划；恢复参考会移除扩展，原62项固定参数档案不改写。整机入口不增加未实现的空开关。

## 整机信号链

速度给定 → 速度PI → 转矩到iq换算 → 电流PI与前馈 → 限压 → 逆Park/SVPWM → CCR写入与更新 → 逆变桥 → PMSM。

反馈有两条：三相电流 → 顺序采样 → Clarke/Park → 电流环；机械角度 → 计数读取 → 电角恢复及窗口测速/速度滤波 → 坐标变换与速度环。电角度与速度估计来自同一机械运动及计数读取，真实值只用于传感器建模、参考组和观测。

20kHz电流/编码器/测速/滤波在每周期JEOS偏移28.875µs执行；10kHz速度任务在偏移78.875µs执行。触发24.375µs和计算5µs仍为推定/演示配置，未测量。两组都采用62.5ns网格、峰谷双更新。

## 两组配置

| 配置 | 理想反馈 | 编码器反馈 |
| --- | --- | --- |
| 控制电角度 | 原角度路径 | 机械计数恢复，零位0、附加延迟关闭 |
| 速度PI输入 | 原速度路径 | 同次计数窗口差分，再经一阶低通 |
| 计数/窗口/截止频率 | 同时观测，未接入控制 | 默认10000 / 2拍 / 200Hz |
| 电机、PI、初态、时序、负载、给定 | 相同 | 相同 |
| 逆变器 | 同一原理想桥，死区/压降/补偿关闭 | 相同 |
| 其他测量误差与采样窗口 | 关闭 | 关闭 |

本实验先使用原理想桥，集中检查反馈链组合。初版详细续流桥长时试跑耗时较高，首组原始数据保留，未完成的结果包标为失败；不把该组与后续理想桥结果混合。详细桥、死区及补偿已有单项入口，后续单独加入整机组合。

两组同时改变角度和速度反馈，是整机集成比较，不能把所有差异归因于滤波或角度量化中的一项。需要归因时回到16项单项实验。本批无功率关断场景，理想桥也不能用来证明关断后的续流行为。

电角零位已知正确，控制环从开始就执行；测速历史不足时为零并标无效，不用真值填补。这仍不包含上电定位、启动门控、主动保护或完整固件缺样处理。8A是iq指令限幅，不是过流保护。

## 工况与判定

| 时间 | 操作 | 观测 |
| --- | --- | --- |
| 0—200ms | 3000rpm目标，0.207N·m负载 | 加速及初始平台 |
| 200ms | 目标改为2000rpm | 速度变化、iq及转矩响应 |
| 300ms | 负载增至0.25N·m | 增载响应及末段平台 |
| 400ms | 结束 | 封存结果并恢复参考 |

上述为名义请求时间。实际速度给定在下一10kHz任务边界切换，负载在下一20kHz边界切换；分析会核对完整给定曲线并记录实际时刻。

新增离散给定块在首次速度任务执行前发布初值0；首次10kHz任务执行时已得到3000rpm。原始记录保留这个初始化阶段，不把它改成另一条更好看的曲线。

分别检查160—200ms、280—300ms、380—400ms三个平台窗口。预先定义平均速度误差绝对值≤30rpm、速度跨度≤60rpm、拟合速度斜率绝对值≤100rpm/s；三项都满足才标记该窗口通过。短窗口通过只是此工况的运行判据，不是完整稳定性证明或PI整定结论。不满足时保留真实指标，不移动窗口或放宽阈值来制造通过。

链路正确性另行检查：整数计数与方向、实际Park及逆Park角度、三窗口差分来源、滤波递推、实际速度PI输入、任务采样周期、给定边界、iq指令上限、最终限压，以及按请求序号独立追溯实际CCR阈值。先确保数据流正确，再评价运行表现。

末段PWM诊断与实际阈值按相同62.5ns原生格点逐行对应，允许时间表达式产生的双精度末位差并记录最大值，不插值、不更改原时间。跨次复跑另行严格比较每路原始Time/Data。

## 结果与复现

每次独立建立`framework/runs/<时间与ID>`，包含两组MAT原始数据、完整计划、参考清单、源码指纹、分析JSON、分窗口CSV和三张图：整机响应、反馈链、三相与dq电流。图中只保留主题、图例和单位，解释写在正文。

若两组原始仿真及恢复已完成、仅报告失败，可用`rebuild_pmsm_system_report(失败包路径)`在新目录重建派生报告。它只允许分析、绘图及复跑比较脚本变化，拒绝仿真或配置源码变化；保存原失败记录指纹、实际仿真源码、复制数据指纹及新报告源码。原失败包不会改成成功。重建报告不等于重新仿真，独立复跑仍需另行完成。

高频门极/PWM诊断只保留尾部4000点，实际阈值记录同样保留尾部；控制、机械计数、反馈、积分及1µs三相电流全程保留。该档案能检查末段PWM来源，不能作为全程开关边沿或启停关断的证据。

两组分别闭环运行，累计转子角度可以不同。同一绝对时间下ABC电流的相位差不能直接解释为传感器或死区延迟；比较波形形状时应另按电角度对齐。dq及转矩指标取自任务同步瞬时记录，不是PWM周期平均值或THD；不能直接用固定采样相位的转矩均值与负载作机械平衡判断。

实验结束移除新增输入、编码器、测速和滤波扩展，恢复原连接与整套参考，并比较原结构/参数/位置快照及主SLX指纹。失败包保留失败状态。图库及原实验档案不被覆盖。
