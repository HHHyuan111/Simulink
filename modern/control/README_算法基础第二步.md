# 电流环与调制基础修复

本轮继续修改同一个 `modern/PMSM_FOC_R2026a.slx`。沉沙200W电机参数、九个色域及原532个块的位置均保留，九个PI数值没有重新整定。最终验证结果与模型指纹以同目录 `algorithm_stage2_results.json` 为准。

## 控制链

电流误差 → 原d/q PI → 加解耦前馈 → 最终dq圆限幅 → 逆Park → SVPWM。最终电压限幅的残差回到原PI的回算支路。

- d轴PI现在分别绑定 `kp_id / ki_id / ks_id` 和d轴限值，避免两轴参数不同后继续误用q轴参数。
- 前馈为 `FFd=-ωe·Lq·iq`、`FFq=ωe·(phis+Ld·id)`。原 `Ld·id` 小模块继续参与计算。
- 双击电流环色域中的“解耦”，运行前选择开或关。默认开；关闭时两个前馈同时归零。限压及回算始终生效。
- “限压”取同一条 `UDC` 母线信号：`Vmax=0.96·max(Vbus,0)/√3`，超限时对整个dq向量乘同一个比例，保持方向。0.96来自固件 `algorithm_config.h` 的 `CTRL_VOLTAGE_UTILIZATION_RATIO`，不是新整定的PI参数。
- 限压和SVPWM对这条母线信号分别作50μs采样保持，保持电流控制执行周期。原调制母线常量保留作为旧实现对照，已不再驱动调制计算。当前母线信号仍是理想母线测量，尚未包含母线ADC及RC延迟。

## 回算为什么不会重复

设PI内部未限幅输出为 `u`，轴限幅输出为 `a`，前馈为 `f`，请求电压为 `r=a+f`，最终电压为 `v`。原轴限幅残差为 `u-a`，新增残差为 `v-r`。

原回算求和器改为 `u-a-(v-r)=u+f-v`。积分器因此只接收一次合并修正：

```
correction = Ks * (v - f - u)       % 与电流误差相加，单位A
I[k] = clip(I[k-1] + dt*Ki*(e[k] + correction[k]), Imin, Imax)
```

保留原Backward Euler及积分器限值；初始积分输出为0。它在同一控制拍内形成隐式求解，和固件逐拍显式实现仍有差别。本轮验证其数学关系，不宣称已经实现固件位级一致或可直接生成STM32代码。原轴限值/积分限值仍按标称母线设置；最终圆限幅随当前母线变化。

## SVPWM边界

保持原扇区编码与时间映射。超调制时先保存 `total=t1+t2`，再同时缩放两个有效矢量时间，避免第二次计算使用已被修改的分母。总零矢量时间 `t0=Ts-t1-t2`，观测中的t0是整个周期总时间。

零指令使用三相相同的50%占空比，平均线电压为零。无可用母线时也输出该共同阈值，避免除零。正常主链受0.96圆限幅保护；SVPWM的超调制分支仍通过独立组件测试覆盖。

## 观测入口

顶层仍使用已有“PI观测”和“时序观测”，没有新增大色域。

| 入口 | 新内容 |
| --- | --- |
| PI观测 | d/q前馈；请求及最终dq电压；可用电压；请求/最终利用率；饱和标志；最终残差；合并回算修正 |
| 时序观测 | t1/t2/总t0；三相理想占空比；超调制与阈值越界保护标志，分别显示 |

原PI观测的四路顺序仍为P、I、PI未限幅输出、PI轴限幅输出。新增“前馈”已包含d轴负号。dq电压图的顺序为请求d、请求q、最终d、最终q。两轴残差为 `Vfinal-Vrequest`；回算修正单位A，乘Ki后才进入积分器。调制边界标志顺序为超调制、阈值越界保护；越界判断有1ps浮点容差。

新增日志：

| 日志 | 各列含义 |
| --- | --- |
| `obs_voltage` | 请求d、请求q、最终d、最终q、Vmax、请求利用率、最终利用率、饱和标志 |
| `obs_aw_d / obs_aw_q` | 最终残差[V]、合并回算修正[A] |
| `obs_mod` | t1、t2、总t0[s]、Da、Db、Dc、超调制标志、阈值越界保护标志 |

利用率的分母是包含0.96裕量的Vmax。零母线时使用极小分母避免除零；此时非零请求会显示很大的请求利用率，应结合母线值阅读。控制日志按50μs记录，不据此判断PWM电流纹波；原快速日志仍按1μs记录。

`plot_observation_report` 在现有五页报告后新增“前馈、最终限压与回算”第六页，同时支持历史日志。算法比较图为 `algorithm_stage2_comparison.png`，本轮完整观测报告在 `report_algorithm/`。

## 验证方式与开发边界

组件测试复制实际模型块，用独立计算作比较：不同的d/q参数、PI隐式逐拍递推、零及四象限向量限压、六扇区及边界、过调制、占空比对应的实际αβ电压重构。闭环测试覆盖默认启动、负向启动、实际反转、负载阶跃、24→6→24V母线恢复；另检查非零id前馈、解耦关闭及保存后重载一致。

低压测试的40A峰值检查只是识别数值失控的宽松仿真界限，不是10A硬件保护，也不是允许实板照做的试验方案。指令8A限幅仍不等于反馈电流硬限幅。

当前8A指令上限对应约0.339N·m，只约为0.69N·m额定转矩的49.2%。因此50%额定负载已略超可持续指令能力，维持3000rpm不是该限制下的合理验收条件。本轮负载阶跃为0.3Tn→0.45Tn（0.207→0.3105N·m），上限及PI均不因此放大。

母线恢复测试采用连续物理电源，在固定数值网格内用1μs过渡连接24V和6V。现有桥中的继承采样数学块不应直接接一个20kHz离散物理电源，否则桥电压会丢失PWM细节；这与母线ADC的保持/延迟不是一回事。后续接入数字母线测量时，应将连续物理电源和控制器接收到的母线采样明确分开，再重新检查编译速率与快速波形。

构建与验证脚本是本次迁移流程：`build_algorithm_stage2` 要求迁移前指定指纹，候选文件及前后数据放在本机 `modern/.build/algorithm_stage/`。`validate_algorithm_stage2` 检查候选文件，`finalize_algorithm_stage2` 检查差异、编译周期并生成报告；检查和图像复核完成后才复制候选文件替换主文件。不能对已修改的主模型再次直接运行迁移构建脚本；本地前后备份用于回溯，历史验证记录不冒充当前版本。

本轮完成后可继续作为算法与教学仿真的开发基线。真实PWM更新事件、C/B/A顺序采样和有效窗口、ABZ测角测速、上电对齐、真实门极死区续流、器件参数及主动保护仍需后续实现，之后再按实测校准和整定。

## 本轮结果

3678组SVPWM向量的平均αβ电压重构最大误差约7.1×10⁻¹⁵V；不同d/q参数的积分递推误差均小于1.3×10⁻¹²V。以下为相同PI增益、14项非理想因素关闭、解耦开启的1s仿真结果：

| 工况 | 末值转速[rpm] | 最大电流绝对值iq[A] | 结果 |
| --- | ---: | ---: | --- |
| 默认3000rpm启动 | 2999.546 | 8.525 | 最终利用率最高0.767，无矢量饱和 |
| -2000rpm启动 | -2000.127 | 8.428 | 峰值速度绝对值2565.6rpm，动态仍有较大超调 |
| +2000→-2000rpm反转 | -1999.611 | 8.535 | 限压、调制及回算关系有效 |
| 0.207→0.3105N·m负载阶跃 | 2999.841 | 8.525 | 阶跃后恢复给定 |
| 24→6→24V母线 | 2999.409 | 27.887 | 低压观察窗100%饱和，恢复后观察窗0%饱和 |

默认启动峰值由修复前3135.85rpm变为3135.03rpm。这轮没有通过调参追求更小超调。低压压力工况的27.887A已经超过固件10A保护目标；本模型尚未实现该保护，因此“通过”只表示数值、限压、调制与恢复检查通过，不能作为实板低压故障验收结果。真实硬件验证前必须接入保护、母线动态和实际时序。
