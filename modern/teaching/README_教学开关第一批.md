# 教学开关：第一批

本批在现有 `PMSM_FOC_R2026a.slx` 上增加局部设置，不重新搭建模型。保留九个色域、原有小模块的位置、PI 数学、变换和 SVPWM 算法。所有新增因素默认关闭，PI 增益保持不变。

本批的用途是解释多速率、等效测量误差和整周期延迟。它还不是 STM32 定时器、ADC 和功率板的完整数字模型。参数均为演示值，不能作为板子的标定值或额定限制。

接下来的开发顺序及各阶段检查结果要求见[后续开发计划](后续开发计划.md)。近期先带读教学开关，再修正算法基础，暂缓 PI 整定。

## 在哪里设置

主画布新增三个白色小入口，双击打开复选项和参数：

| 入口 | 位置 | 内容 |
| --- | --- | --- |
| 时序设置 | SVPWM 色域右下方 | 速度任务分频、整周期输出延迟 |
| 采样设置 | 采样反馈色域右下方 | 电流零偏、增益、采样噪声、ADC 量化与饱和、数字低通、采样传递延迟 |
| 角度设置 | 坐标变换色域右下方 | 电角偏置、电角量化、整周期角度延迟 |

设置先在仿真停止时修改，应用后重新运行。入口显示“开 / 关”，至少一项启用时文字标红；具体单项状态在面板内查看。运行中热切换尚未作为本批的验证范围。想看新增环节的内部实现，右键“查看封装下内容”；原来的控制小模块仍直接显示在画布上。

## 时序设置

- 默认速度周期仍为 `Ts_speed=50 μs`，电流周期 `dt=50 μs`，PWM 为 20 kHz。
- 开启“速度分频”后，实际速度环周期为 `dt × 分频数`。演示分频数为20，即1 ms、1 kHz。速度反馈采样、PI 比例支路采样与离散积分都随之改变，增益不变。
- 开启“输出延迟”后，SVPWM 指令阈值按设定的整数个 `dt` 延迟后进入原载波比较。它集中表示输出晚到的影响，暂不区分计算耗时、定时器预装载和更新等待。
- 初始延迟输出为零阈值，使用原比较及互补门极关系，对应原理想桥的零线电压状态。这里没有实现真实启动门极封锁或故障关断。

模型 InitFcn 从“时序设置”读取选择，计算 `teaching_Ts_speed` 等派生量。原 `Ts_speed` 保留为参考周期；不要同时把派生变量当作另一个独立设置入口。若原参考周期被改动，关闭速度分频时会使用该参考周期。

执行频率与环路带宽分别讨论。此次改变任务周期而保留 PI 增益，是为了观察离散实现的影响，不代表该频率组合已经完成整定。

## 采样设置

处理顺序：

```text
真实三相电流
  → 各相增益、零偏、采样噪声
  → dt 同步采样
  → 可选 ADC 量化与饱和
  → 可选数字低通
  → 可选整周期传递延迟
  → 控制器的 Clarke / Park
```

全部关闭时，直接使用原始信号，保留原模型既有的采样。开启后，原采样块继续在同一 `dt` 网格上接收测量结果，不能再把它自行解释成额外一周期延迟。

| 项目 | 演示参数 | 含义 |
| --- | --- | --- |
| 零偏 | `[0.05 -0.03 0] A` | 三相分别施加固定测量偏差 |
| 增益 | `[1.01 0.99 1]` | 三相测量比例不一致 |
| 噪声 | 每相 RMS 0.02 A，种子9474起 | 按 dt 更新的独立高斯采样噪声；可重复，非开关尖峰或模拟带限噪声模型 |
| ADC | 12 bit，双极量程±20 A | 以电流为单位的等效量化与饱和；没有假定实际分流、电压偏置或放大增益 |
| 数字低通 | 500 Hz | 一阶离散滤波，初态为零；会同时改变噪声和信号相位 |
| 传递延迟 | 1 × dt | 使采样结果晚一个控制周期被使用，初始输出为零 |

ADC 的电流刻度为 `LSB=2×量程/2^位数`；码值0至4095等效对应−20 A至约+19.990234 A，零电流对应中间码2048。采用四舍五入式等效量化，具体硬件 ADC 传输特性和偏置换算待实板对齐。

数字滤波递推为：

```text
a = exp(-2*pi*filter_hz*dt)
y[k] = (1-a)*x[k] + a*y[k-1]
```

`filter_hz` 表示由连续一阶极点映射得到的参数；高频处不能直接把它当成精确离散 −3 dB 频率。它也不代表采样前的模拟 RC。模拟 RC、运放动态、PWM 边沿干扰、ADC 捕获相位、分流拓扑和无效采样窗口仍待实现。

控制器读取新增测量通道。原三相电流观测保留真值，二者通过独立日志比较。

## 角度设置

全部参数采用电角度：偏置默认2°，量化步长默认0.1°，延迟默认1个 `dt`。开启偏置/量化后将角度环绕到 `[0,2π)`，延迟发生在该测量链之后，控制器使用测量角进行 Park 和逆 Park。

延迟初态为0，前若干周期并非真实传感器初始化过程。此处没有编码器计数、霍尔插值、SPI 读数、无感估算器或角度预测补偿。

观察角度误差时使用 `atan2(sin(测量−真值),cos(测量−真值))`，避免跨越0和2π时误以为出现一整圈误差。

## 建议先做的教学实验

在 MATLAB 进入仓库 `modern` 文件夹：

```matlab
open_pmsm_model
addpath('teaching')
run_teaching_demo('timing')
```

这会以相同 PI 增益分别运行参考、速度环分频20、输出延迟一周期三种工况，生成 `teaching/demo_timing.png`、JSON 参数快照及本地 MAT 数据。设置通过 SimulationInput 临时覆盖，不保存到 SLX。

其他实验：

```matlab
run_teaching_demo('offset')
run_teaching_demo('noise_filter')
run_teaching_demo('angle')
```

每个工况都先关闭所有教学因素，再打开本实验指定的项；其余数值取当前面板参数。噪声种子保持一致。比较噪声与滤波时，测量值减真值包含滤波造成的动态误差，因此不能把这个差值的 RMS 全部称为噪声 RMS。

脚本保存实际使用的各组开关、模型工作区数值参数以及已保存模型 SHA，并检查运行前后的面板和工作区数值保持一致。工作区原来干净时，运行后恢复为干净状态；原来有未保存的参数修改时，保留这些修改。四组实验及参数恢复的检查结果见 `teaching_demo_check.json`。不会替你重新整定 PI。仿真中出现的超调或误差变化用于分析，不代表新工况已达到实物性能目标。

## 日志和验证

原12路日志继续保留。新增日志均以 `dt` 记录：

| 日志 | 内容 |
| --- | --- |
| `log_iabc_true` / `log_iabc_meas` | 真实和控制器收到的三相电流 |
| `log_iabc_noise` | 实际注入的采样噪声；开关关闭时为零 |
| `log_iabc_adc` | ADC 可选环节后的信号 |
| `log_iabc_filter` | 数字滤波可选环节后的信号 |
| `log_theta_true` / `log_theta_meas` / `log_theta_error` | 电角真值、测量值、最短角差 |
| `log_Tcm_requested` / `log_Tcm_applied` | SVPWM 请求阈值和延迟选择后的阈值 |

本批验证结果见 `teaching_validation.json`，保存后重新加载检查见 `teaching_reload_check.json`。验证脚本：

```matlab
addpath('teaching')
validate_teaching_controls
```

`verify_saved_teaching_controls` 用于独立新 MATLAB 会话，在模型尚未打开时执行；它重新加载磁盘模型，并在检查结束后关闭本次加载的模型。

首次接入时与本地修改前备份逐点比较原12路日志，保存后在新 MATLAB 进程中又验证了默认1秒仿真的12路日志逐点一致。参考数据位于忽略上传的 `.build`；其他机器若没有备份，验证脚本明确标记相应原始比较不可用，不把它声称为已经执行。组件验证采用所发布的默认面板参数。

本批只对组件语义、已列短时闭环工况、默认关闭复现和嵌入配置负责。当前算法仍有待独立修复的问题：d轴 PI 参数绑定、q轴完整前馈、最终电压矢量限幅/抗饱和及 SVPWM 过调制边界。动态整定、真实 STM32 时序、采样窗口、死区及续流、器件损耗和实物标定尚未完成。
