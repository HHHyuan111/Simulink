# 低侧采样窗口

第十二项固定实验 `sampling_window`，沿用原模型已有窗口与保持开关，整理操作、观测及重复实验。原控制器、PI、主SLX和布局不改。新增文件只负责实验配置、记录、核对和绘图。

## 三组分别在做什么

| 组别 | 窗口开关 | 保持开关 | 发布给控制器的电流 |
| --- | --- | --- | --- |
| 窗口关闭 | 关 | 关 | 接受各相孔径结束时的物理电流，即使窗口标志无效 |
| 无效置零 | 开 | 关 | 有效时接受样本，无效时置零 |
| 保持样本 | 开 | 开 | 有效时更新，无效时保持该相上次有效样本；没有历史时为零 |

三组共同开启真实时序，使用同一触发、稳定等待、5µs计算、峰谷双更新、62.5ns网格、PI、3000rpm给定、24V、0.207N·m负载及零初态。相邻组仅改变窗口或保持开关。其余附加因素关闭。

窗口关闭组是忽略可观测性的对照：从电机模型直接取到真值，不代表低侧分流在关断时仍能测到相电流。置零是教学近似，不模拟真实运放开关瞬态；保持只使用过去有效样本，不是电流重构，也不保证闭环改善。

## 怎么操作

```matlab
cd('D:/simulink/modern'); addpath('teaching')
open_pmsm_experiments
```

恢复固定参考，选择“低侧采样窗口”。两个输入分别为：

| 参数 | 默认 | 允许范围 | 含义 |
| --- | ---: | ---: | --- |
| 触发相位 | 31.25µs | 0—40.4375µs | PWM谷底到ADC触发的时间 |
| 稳定等待 | 0.5µs | 0—10µs | 低侧连续开通后，孔径开始前需要的等待 |

两个参数均按0.0625µs步进，三组共同应用。31.25µs是后移触发的教学压力值，0.5µs也是演示值，均未实测，不覆盖固定参考的24.375µs假设。等待不是门极死区，不把两个时间重复计入。

默认每组50ms；代码入口允许50—100ms，以限制全程高频记录规模。可以运行：

```matlab
r=run_pmsm_experiment('sampling_window');
r=run_pmsm_experiment('sampling_window',[24.375 1],.05);
[again,check]=repeat_pmsm_experiment(r.folder);
```

修改输入会清除旧报告入口。实验结束后恢复完整固定参考，不保存覆盖主模型。任意参数组合并不保证稳定，短时启动也不作为稳态验收。

## 模型中去哪里看

顶层“时序设置”提供 `real_on`、`window_on`、`invalid_hold_on`、`trigger_us`、`settle_us`。原“采样设置/顺序采样”执行已有 `timing/timing_adc.m` 逻辑：C→B→A孔径结束捕获，在JEOS一起发布给原测量链与Clarke/Park。当前场景没有叠加偏置、噪声、滤波或旧整拍延迟。

默认C/B/A孔径结束为32.4375/33.9375/35.4375µs，JEOS为35.75µs。快环和SVPWM周期50µs、偏移35.75µs；速度任务周期100µs、偏移85.75µs。计算结束40.75µs，仍需等50µs更新机会。

有效性检查覆盖完整采样孔径及之前的稳定等待，不能只看孔径结束时门极是否已经导通。已有模块使用SW请求门极的一网格历史，本场景门极死区关闭；不能把本实验扩大为“组合物理死区时，窗口也已按实际门极校准”。输入缓存使窗口检查保守一网格，物理电流取样时刻仍对应孔径结束。

## 看图与追溯来源

- `comparison.png`：各列一组、各行一相，同相纵轴一致。灰线是原始物理电流，彩色阶梯是实际反馈，叉号是窗口无效。窗口关闭组也会显示诊断无效标志，但仍放行真值。
- `mechanism.png`：三组共同一个PWM周期的门极历史及孔径。绿色/红色表示有效/无效；稳定等待的定义和判定过程留在正文。
- `response.png`：各组自己的转速、真实dq电流和转矩，保留完整短时启动，不强制同一物理轨迹。

电流页显示最后10ms。窗口页从置零组这10ms内选取无效相数最多的最后一次JEOS；全有效时取最后一次，绝对起点和选择规则记录在`window.json`。这是定位窗口失效的教学例子，不是选择“改善最大”的结果。各组闭环变化会反过来改变调制和有效窗口，不能要求三组有效比例相同。

每组24路原始信号，共72路。ADC诊断全程按JEOS快照记录，不是全网格事件脉冲；物理电流和请求门极按62.5ns全程记录，用于核对每一次孔径。实际门极和实际输出阈值保留尾部8000点，PWM诊断尾部4000点。所有日志设置在结果包中显式登记。

`samples.csv`逐次保存三相孔径真值、有效标志、实际发布值、来源样本序号及来源年龄。`sample_index`从1开始；`source_sample_index=0`表示置零或没有历史有效来源的初值，此时年龄NaN。保持组来源序号必须小于当前无效样本序号，初次无效时必须为零；连续无效不会刷新来源年龄。

窗口判定从原始门极独立检查整段孔径与等待；接受的样本逐一对应物理电流孔径结束值；置零/保持递推和实际控制器输入分别核对。不能以反馈变平或数值非零来判断其有效，也不能用电机真值补齐保持组。

专项验收入口为 `validate_pmsm_sampling_window`，只有全部通过才生成 `experiment_sampling_window_validation.json` 的完成标记。检查包括默认72路Time/Data严格复现、全程窗口与样本来源、参数修改、全有效三组旁路、旧真实时序档案、旧电流零偏实验、上一项更新边界分析、界面、文件篡改拒绝和完整参考保持。图片和MAT文件容器字节不作为数值重复性的判据；跨MATLAB版本及系统需重新验证。

## 本轮结果

默认三组各24路、共72路Time/Data逐点复现；门极窗口与孔径有效标志不一致数为0，接受的物理样本、策略递推值及实际控制器输入最大误差均为0。无效样本数（A/B/C）分别是：窗口关闭[293,171,52]，无效置零[298,250,213]，保持样本[299,253,201]。保持组末次样本最大年龄为[A/B/C]=[4450,2900,1900]µs，展示“保持旧值可能很久”；不能将其解释为电流变化更小或闭环性能更好。
