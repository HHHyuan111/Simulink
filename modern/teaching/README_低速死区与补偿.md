# 低速死区与补偿

本轮把已有补偿纳入600rpm固定三组对照，沿用主模型、PI、详细桥与现有补偿方法。600rpm是本场景临时公共给定，运行结束恢复原完整固定参考。

| 项目 | 零死区 | 死区 | 补偿 |
| --- | --- | --- | --- |
| 桥及步长 | 详细续流桥、62.5ns | 相同 | 相同 |
| 转速给定 | 600rpm | 600rpm | 600rpm |
| 负载 | 原0.207N·m | 相同 | 相同 |
| 初态与PI | 原零初态与PI | 相同 | 相同 |
| 门极死区 | 0μs | 默认2μs | 相同2μs |
| 补偿开关 | 关闭 | 关闭 | 开启 |
| 补偿时间参数 | 与演示死区同值，未启用 | 相同，未启用 | 与演示死区同值，启用 |

从零死区到死区只改变`gate_us`，从死区到补偿只改变`comp_on`。三组的`comp_us`保持同值，避免把补偿参数变化混入开关对照。其余测量、时序和功率附加因素关闭。

## 四张报告

“电角度电流”：同一完整转子电角周期内的ABC真实电流，三组叠加。真实电流与真实电角度按1μs同拍记录，保留原始样本。周期及各自时间窗口在`alignment.json`中，不用电流峰值做平移，不平滑或插值重采样。

“闭环响应”：完整启动过程的转速、转矩和真实dq电流；q轴命令显示补偿组给定。当前测量附加因素关闭，dq反馈与真值一致。控制命令随各自闭环运动变化，因此三组iq给定未被强制成同一条轨迹。

“补偿观测”：已有模块实际记录的ABC相电压修正、dq电压修正和滞环电流极性，以及165—195°的A相过零原始波形。这些诊断来自`限压/死区补偿`，不另外计算一套算法替代模型输出。

“启动相位”：三组速度、相对零死区组的速度差和累计电角度差，以及速度差积分核对。累计角度差不折回±180°；积分使用50μs控制记录，有离散积分残差。位置累计差不视为固定控制延迟。

## 沿用的补偿方法

既有方法使用测量三相电流判断极性：超过正滞环阈值取+1，低于负阈值取−1，近零时保持上次极性。默认阈值为±0.05A，初态极性为0。三相修正按`Vdc × tcomp / Ts × polarity`计算，减去三相均值后，用控制器角度变换到dq，合入既有最终限压及抗饱和链。

24V、2μs、50μs周期下，减均值前的单相修正幅值为0.96V。观测页显示减均值后的相电压，因此常见台阶为±0.64V和±1.28V；dq补偿还会随控制器角度变化。这些电压是前馈修正，不是额外串入电机的一组电源。

本轮固定沿用参考中的滞环阈值及算法。可能出现过补偿、欠补偿或某些指标变差，报告保留实际结果。未加入过零柔化、在线辨识或新补偿论文算法。

## 结果与复现边界

每组保留22路：原21路，加8分量的`obs_dead_comp`，包含ABC修正、dq修正和三相极性。三组原始文件为`reference.mat`、`factor.mat`、`compensated.mat`；全部进入结果包校验。运行失败不更新最新成功结果，结束恢复完整参考。

三组各自闭环运行，载波相对于转子的相位仍可能不同。电角度对齐有助于比较相对转子的波形变化，不把瞬时电流差直接称为谐波畸变。末20ms指标不预设严格稳态，当前报告不计算THD。

验收入口`validate_pmsm_low_speed_comp`检查相邻组设置差异、600rpm/负载/网格一致、实际补偿诊断公式、原始样本保留、默认三组66路逐点复现、零幅值物理信号回归、旧两组实验回归及主模型/参考/PI/布局保持。实际检查结果见`experiment_low_speed_comp_validation.json`。

## 默认工况结果

600rpm、24V、0.207N·m负载、2μs死区，统计窗口为180—200ms，指标基于50μs控制周期记录。各组按自身iq给定计算跟踪误差，以下为实际记录值，不是设定验收目标，也不是全带宽开关纹波统计。

| 指标 | 零死区 | 死区 | 补偿 |
| --- | ---: | ---: | ---: |
| 真实iq跟踪RMS / A | 0.01370 | 0.06498 | 0.02795 |
| 真实id跟踪RMS / A | 0.00791 | 0.30885 | 0.20173 |
| 转矩标准差 / N·m | 0.000584 | 0.002768 | 0.001191 |
| 转速跟踪RMS / rpm | 0.05935 | 0.41267 | 0.12392 |

相对未补偿死区组，本工况的iq跟踪RMS与转矩标准差均下降约57%。补偿没有恢复到零死区组水平，过零区仍有尖峰，部分瞬时电流偏差可能增大。末20ms的RMS改善不能推出所有工况、所有峰值或THD都改善。现阶段先把这种可比较、可追溯的实验方式固定下来，后续再单独研究补偿方法。

完整启动阶段的真实iq峰值约为8.02—8.10A，说明8A指令限幅不等于实际电流保护；本轮未新增主动保护。
