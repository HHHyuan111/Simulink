# 计数测速

第十四项固定实验`encoder_speed`。在同一次50ms仿真中，三个观测支路对同一机械计数分别做1拍、2拍、8拍差分。速度PI仍使用原反馈，角度也使用原路径；本轮先读清测速本身，不同时增加闭环反馈和滤波。

## 操作

```matlab
cd('D:/simulink/modern'); addpath('teaching')
open_pmsm_experiments
```

选择“计数测速”，恢复固定参考后运行一次并行观测。“查看测速对照”看三种窗口，“查看差分窗口”看计数、误差来源和初始化，“展开测速模块”打开原模型`角度设置/编码器/测速`。内部由历史延迟、计数差、单圈解绕、有效性判断和速度换算等基础块组成。

| 输入 | 默认 | 范围及含义 |
| --- | ---: | --- |
| 每转计数 | 10000 | 每机械转解码后的整数计数，20—1000000；不再乘4 |
| 窗口拍数 | 2 | 2—7个位置读取周期 |
| 长窗拍数 | 8 | 大于窗口拍数，最大32；教学扩展 |

短窗口固定1拍。读取周期50µs，实际读取偏移28.875µs；原速度PI每100µs执行一次。三个窗口分别50/100/400µs，每个读取周期滚动更新，并非等窗口结束才更新一次。实验时长支持50—100ms。

```matlab
r=run_pmsm_experiment('encoder_speed');
r=run_pmsm_experiment('encoder_speed',[5000 3 12],.05);
[again,check]=repeat_pmsm_experiment(r.folder);
```

本场景只有一个`reference.mat`，没有第二组`factor.mat`。三个观察器共享一次物理轨迹，比三次各自闭环运行更容易看清测速窗口的作用。改界面参数后旧结果关联会清空，需重新运行。展开用于阅读，运行参数以实验窗口为准；结束或恢复参考时移除临时模块，主SLX及固定参考不覆盖。

## 信号怎么走

机械真角度 → 原始整数计数 → 方向修正后的单圈计数 → 同步读取包 → 当前计数减W拍前计数 → 单圈解绕 → 换算rpm → 记录。

设每机械转N个计数，读取周期Ts，窗口W拍，速度为`Δcount × 60/(N×W×Ts)`。这里计算机械转速，不乘极对数。差值映射到`[-N/2,N/2)`，跨计数零点时保留正常正反转；恰好半圈方向有歧义，标记无效。计数端点法不能识别窗口内超过半机械圈的混叠，分析器用物理真值检查本次运行是否超出这个适用范围，不把真值补给估计器。

窗口必须有当前端点和W拍前有效端点。启动前W个输出标记无效，原始估计值为0；图中隐藏无效速度，CSV来源编号为0、来源时间为NaN。关闭测速开关时，三个速度值及有效标志均为0，物理轨迹和原控制器保持。

原速度输入另外从实际保持块取样记录，检查PI收到的仍是原机械转速。新增估计值没有连接速度PI，也没有接入滤波器。

## 为什么窗口长了更平滑，也会更滞后

分别保留三种速度：当前瞬时真值、同一窗口内的真实平均速度、计数差分估计。总误差拆成两项：

- 计数量化误差：估计速度减同窗口真实平均速度。
- 窗口平均误差：同窗口真实平均速度减当前瞬时真值。

两项相加等于总测速误差。窗口越长，单计数对应的速度间隔越小；加速时窗口平均又会落后于当前速度。不能只看波形更平滑就判断测速或闭环性能全面改善。

默认10000计数时，1/2/8拍的单计数速度间隔为120/60/15rpm。此次50ms启动实验末20ms统计如下，尚不是稳态结果：

| 窗口 | 计数量化误差RMS | 窗口平均误差RMS | 总测速误差RMS |
| --- | ---: | ---: | ---: |
| 1拍 | 49.68rpm | 1.03rpm | 49.69rpm |
| 2拍 | 24.98rpm | 2.06rpm | 25.06rpm |
| 8拍 | 6.01rpm | 8.19rpm | 10.18rpm |

## 与固件的对应和边界

AxDr_L快照`48d6e86814ac6657b1313b4c92ef24c88f492e07`配置ABZ2500线×4=10000计数/机械转、方向−1、测速默认2拍。在有效快环位置输入上调用`speed_est_step(pos_r,foc_fs)`；位置喂入20kHz、速度PI执行10kHz和1kHz配置宏是不同概念。固件估计器输出rad/s，本实验明确换算为原模型使用的rpm。

固件环形历史深度为8，当前实现的8拍窗口不能直接照搬到其8槽数组，否则会读到已覆盖的槽。本实验长窗使用Simulink历史延迟，是教学扩展。固件启动ready在W次调用后置位，本实验要求W+1个有效端点，未宣称启动行为或浮点位级等价。固件后续还有速度低通，本轮未实现；ABZ电气边沿、TIM滤波、丢脉冲、Z相和自动对齐仍待开发。

## 记录与验收

保留31路原始时间序列。三路测速日志`log_speed_short/window/long`各有7列：估计rpm、有效标志、解绕计数差、窗口时长、来源时间、当前时间、来源修正计数。`log_speed_control`记录原速度任务实际输入；原编码器日志也保留。

`speed_samples.csv`逐样本记录端点、时间、计数、有效性、真实速度和误差分解；`speed.json`保存独立核对与有限窗口统计。图为测速对照、差分窗口、运行状态三页，解释只放正文。

验收入口`validate_pmsm_encoder_speed`分为`default/repeat/parameters/finish`；结果见`experiment_encoder_speed_validation.json`。包括31路完整Time/Data严格复跑、实际模块的正反转/跨零/静止/半圈歧义/初始化/关闭、多个窗口和非整除计数、编译时刻、参数[5000,3,12]、关闭支路的物理轨迹回归、旧角度理想组27路、旧电流零偏42路及旧角度档案分析、界面和文件篡改拒绝。

此次旧角度理想组27路的Time和Data也全部严格相同。比较器仅对`log_Tcm_applied`保留双精度末位时间差的同62.5ns格点规则，要求数值严格相同且不插值；此次27路比较未使用该例外。主模型、PI、布局和完整参考保持；各旧场景证据分别保存，图库重绘不表示重新仿真所有场景。
