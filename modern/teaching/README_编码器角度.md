# 编码器角度

第十三项固定实验`encoder_angle`：理想角度、计数角度、同一计数加延迟三组对照。新增的是原模型中可展开的机械计数路径；速度反馈、控制器和电机沿用已有实现。

## 模型与操作

```matlab
cd('D:/simulink/modern'); addpath('teaching')
open_pmsm_experiments
```

选择“编码器角度”，先恢复固定参考，再运行三组。每组默认50ms，支持50—100ms，保持原PI、24V、3000rpm给定、0.207N·m负载、零初态和真实时序。触发为24.375µs，JEOS/角度读取偏移为28.875µs；读取周期50µs，速度PI执行周期100µs。其余附加误差关闭，真实顺序ADC采样仍属于共同背景。

| 输入 | 默认 | 含义 |
| --- | ---: | --- |
| 每转计数 | 10000 | 每机械转解码后的整数计数，范围20—1000000；不再乘4 |
| 延迟拍数 | 2 | 0—20个读取周期；默认100µs，是可放大的教学值 |
| 电角零位 | 0° | −180—180°；计数两组共同应用，默认假定已手动对齐 |

源码快照`48d6e86814ac6657b1313b4c92ef24c88f492e07`中ABZ为2500线×四倍频=10000计数/机械转，软件方向−1；当前电机5极对。10000计数对应0.036°机械角、0.18°电角。该来源是源码配置，未独立验证实板参数；修改为500等值属于教学设置。

代码入口：

```matlab
r=run_pmsm_experiment('encoder_angle');
r=run_pmsm_experiment('encoder_angle',[500 2 0],.05);
[again,check]=repeat_pmsm_experiment(r.folder);
```

“6 展开编码器模块”打开同一个原模型的`角度设置/编码器`，内部为基础Simulink块，可以逐个阅读。该模块临时接入，固定参考的SLX文件与`reference_v1`不覆盖；恢复参考或运行实验会自动移除展开的临时模块。它不是另建一套电机模型。直接操作也可使用`pmsm_encoder_view`；看完执行`pmsm_encoder_model('remove')`再恢复固定参考。

展开按钮用于阅读结构，只配置编码器遮罩；三组共用的真实时序由固定实验运行器应用。固定实验以界面三个输入框为准，不读取展开后手动修改的遮罩值。原统一参数档案仍是冻结参考的62项/19开关，编码器扩展参数另存在每次实验的`plan.json`和`record.json`中；本轮没有把临时参数写回原档案。

## 路径和方向

机械真角度来自原电机测量总线，在原机械角→电角换算之前取出：

机械角→计数方向与倍率→向下取整→单圈计数→同步读取→软件方向修正→机械角恢复→极对数→电角零位→环绕→可选历史样本延迟→原角度/编码器选择。

原角度设置的小模块保留。编码器输出接回原`theta_meas`，沿用原Park和逆Park入口的同步保持。选编码器时，旧偏置/电角量化/旧角度延迟开关要求关闭，避免重复施加同类误差。

计数定义为`raw=mod(floor(sensor_dir*theta_m*N/(2*pi)),N)`，方向修正为`corrected=mod(direction*raw,N)`，最后`theta_e=mod(corrected*2*pi/N*p+zero,2*pi)`。默认传感器坐标方向与软件修正都为−1，组合后与原模型正转坐标一致。传感器方向描述安装/接线坐标，软件方向描述修正；仅把控制角度乘−1会引入坐标方向错误，不能作为正常适配。

向下取整在原始方向上进行，量化误差不要求以0为中心；默认−1/−1组合可能表现为小幅正角误差。正反转、机械单圈环绕和计数不能整除极对数的情况均应按完整机械角处理，不能拿已环绕的电角度倒推机械计数。

“理想角度”直接使用原角度输出；“计数角度”使用当前读取的整数计数；“计数加延迟”使用指定历史读取包。零位参数只作用于计数两组；设为非零后，第一、二组差异同时包含量化和零位，并非纯量化实验。默认零位0是已对齐假设，尚未模拟上电寻找电角零点。

## 采样与初始化

计数、读取时间和有效标志作为同一包同步保持；延迟包同时包含角度、时间、有效标志和原始计数。延迟初态为零，无历史时角度0且有效标志0，不用当前真角度补齐；样本来源为无效时，导出的来源时间为NaN、来源编号为0。

有效标志当前用于诊断，尚未接入启动门控或故障状态机。旁路组也记录计数候选路径以便核对，但控制器使用原角度；该组的候选量化指标不代表控制器施加了量化。

读取有效标志在首个读取格点置位；Step阈值提前四分之一数值网格只用于避免浮点末位导致有效标志晚一拍，读取块及物理采样时刻没有提前。实际Park/逆Park角度另从原同步保持输出记录，不能用新模块自身输出代替“已经进入控制器”的证据。

速度仍使用原有速度反馈，未由计数差分获得。本批不模拟ABZ电气边沿、TIM输入滤波、丢脉冲、Z相、自动对齐或MCU浮点位级等价；这些不能因为写入10000计数就宣称完成。

## 观测与复现

三张图分别为`mechanism.png`编码器角度、`comparison.png`dq电流、`response.png`运行状态。图内仅保留主题、单位和图例；角度在同拍真角度附近按最短角差展开，避免把0/360°环绕画成误差跳变。启动段与末10ms窗口明确区分，不预设稳态或性能改善。

每组27路原始信号，共81路。新增`log_encoder_mechanical`在实际读取时刻记录机械真值；`log_encoder_control`记录原Park和逆Park实际收到的角度；`log_encoder`也在同一JEOS/读取时刻记录12列：当前原始计数、修正计数、恢复机械角、新鲜电角、最终反馈角、当前读取时间、来源读取时间、来源有效标志、编码器开关、延迟开关、来源原始计数、当前读取有效标志。

`encoder_samples.csv`逐次记录机械真值、原始/修正计数、真实电角、实际Park/逆Park角度、历史样本编号与年龄。`encoder.json`登记独立核对误差与有限时间窗统计。延迟大小在读取时刻按来源时间计算，不能把日志时刻至上一读取之间的额外保持时间误当成新增整数延迟。

专项验收入口`validate_pmsm_encoder`分为`default/repeat/parameters/finish`，完成记录为`experiment_encoder_validation.json`。检查实际模块的正反转/环绕、方向失配、非整除计数、非零零位、初始化、量化与历史来源、两个变换的实际输入、编译采样时刻、81路重复运行、零延迟回归、旧时序/电流零偏档案、上一项窗口分析、界面与文件校验。跨MATLAB版本需重新验证。

## 默认结果与证据范围

三组各27路、共81路Time/Data已独立逐点复现。末20ms电角误差RMS：理想角度0°、计数角度约0.108°、计数加延迟约4.73°；后者读取时来源年龄100µs，前两次无历史。默认量化最大误差约0.18°电角，符合单计数边界。50ms内仍在启动加速，以上不是稳态指标。

加入演示延迟后，真实d轴电流在末端约0.8A，而反馈d轴仍接近0；速度和转矩曲线整体仍接近。偏离的控制坐标使“反馈接近给定”与“真实转子坐标电流正确”产生差别。原有顺序电流采样是三组共同背景，不能把所有真值/反馈差都归因于编码器。

参数回归使用[500计数,0拍,7.5°]，检查实际计数与零位生效，以及零延迟两组除诊断开关列外一致。历史真实时序档案22路完整Time/Data严格一致；`obs_current_fast`和`log_Tcm_applied`记录密度不同，只核对重叠区间全部共同原始时刻，分别500与10点，数值完全相同，没有插值，不称为这两路完整时间轴一致。该历史比较与本实验81路完整严格复现是两种不同证据。

早期运行因诊断记录相位不一致、报告结构初始化错误产生失败包，均保留失败状态。修正后重新运行并完成默认与重复性检查，未将调试出图后的失败包改为成功记录。
