# 坐标与矢量

这堂课研究：同一组三相电流，为什么在abc中是交流，在αβ中是旋转矢量，在合适的dq坐标下接近直流？控制角度错一点，控制器看到的电流和真实转子坐标中的电流会怎样不同？

## 操作顺序

1. 选择“理想角度”和“稳态”，点击播放。先看三相电流，再看αβ矢量，最后看id、iq。
2. 点击暂停，拖动滑块或填写时间。曲线上的圆点和竖线对应同一原始采样点，时间会吸附到记录网格。
3. 开启“坐标轴”。灰色d/q为真实转子坐标，橙色虚线dc/qc为控制器坐标；电流矢量投影到这两套轴，得到真实dq和反馈dq。坐标轴线长只用于显示方向，不表示电流大小。
4. 切换“角度偏置”。保持观察窗口和时刻，查看两套轴的夹角，以及真实id和反馈id的差别。
5. 切换“启动”，观察电流建立过程。这里的“启动”是仿真开始后的前40ms，不包含实物上电定位和启动状态机。
6. 点击“导出本页”，保存当前四图、同窗口的两组dq对照、信号字典、指标和来源信息。正文说明随图导出。

默认读入已完成的5电角度偏置实验，两组各200ms。回放不运行仿真，也不修改模型。慢、中、快代表观察回放速度，不能理解为物理系统按实时速度执行。

想改偏置大小时，在工作台的“单项实验”中选择“角度偏置”，填写数值并运行，再用本课“载入实验”选择那次结果目录。仅支持已完成且校验通过的该场景，避免把不同模型或混合因素误当成单因素课堂。

## 三种视角如何对应

本模型采用幅值不变Clarke：

```text
iα = (2ia − ib − ic)/3
iβ = (ib − ic)/√3
i0 = (ia + ib + ic)/3
```

三相平衡时i0接近零。αβ固定在定子上，电流矢量随电角度旋转。α轴水平、β轴竖直，坐标等比例；瞬时矢量从原点连到当前采样点。轨迹仅显示所选窗口起点到游标之间的原始样本，窗口外的历史不混入。

Park变换为：

```text
id = iα cosθ + iβ sinθ
iq = −iα sinθ + iβ cosθ
```

以真实转子电角度计算，得到真实dq；以控制器使用的电角度对测量电流计算，得到反馈dq。显示的反馈dq来自模型原日志，并与上述变换逐点核对。真实dq由真实abc与真实角度推导，并与电机内部状态逐点核对。

两者的差别源于坐标定义或测量链。dq曲线不会因为“更平直”就自动代表真实电机电流更正确。

理想角度组的真实值和反馈值几乎完全重合，橙线会覆盖蓝线，这是两者一致的表现。dq接近直流指其主要分量，并不意味着每个采样点都没有纹波；本页保留原模型起伏。该实验附加测量噪声关闭，不能把曲线上的所有起伏都叫作采样噪声。

## 角度偏置的现象

若仅有固定偏置δ，测量电流等于真实电流，则：

```text
id_feedback = id_true cosδ + iq_true sinδ
iq_feedback = −id_true sinδ + iq_true cosδ
```

控制器努力让反馈id接近0时，真实id不一定为0。例如δ为正、反馈iq为正，真实id通常出现负分量。默认5°实验末段，真实id约−0.43A，反馈id接近0，符合坐标旋转关系；精确均值以导出指标为准。

独立运行的两组闭环会积累不同的转子角度，因此不能把两组三相电流在同一绝对时刻的相位差直接解释成采样延迟。本课每组内部使用自身真实角度和控制角度，直接检查坐标投影。

## 窗口、采样与比较

默认日志每50μs一拍，是控制域记录，适合理解电流包络、坐标变换和控制反馈；不能用本页细节判断PWM开关纹波，也不将连接采样点的线段理解为额外物理样本。

启动窗口为前40ms，全程窗口为完整记录，末段窗口沿用原实验预先规定的最后20ms。只有两组末段均满足平均速度误差≤30rpm、速度跨度≤60rpm、拟合速度斜率绝对值≤100rpm/s，才显示“稳态”；否则显示“末段”。这个标签仅说明速度平台检查通过，不能证明全部内部状态严格稳态或完整稳定性。

同一个窗口下，两组的abc、αβ、id和iq分别使用共同量程。αβ半径保留矢量与坐标轴显示空间。切换窗口时量程可变化；比较幅值时应使用同一窗口。没有平滑、插值重采样、按峰值平移或删去不利样本。

## 留档与复现

每次导出新建独立目录，不覆盖历史实验。record.json记录原实验身份、原始MAT和记录文件指纹、派生代码指纹、MATLAB版本、窗口、游标及输出文件指纹。signals.csv说明每条显示信号的来源与坐标定义，metrics.json给出同窗口的均值和变换残差。

本轮验证的是已存档数据的读取、数学变换、联动与导出。它不等于再次运行原仿真；原实验的数值复跑仍使用原实验复现入口与其版本约束。
