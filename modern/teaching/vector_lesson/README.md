## 体验顺序

1. 理想角度 → 稳态 → 播放，检查abc、矢量和dq之间的对应。
2. 暂停，拖动游标或填写时间；值吸附到原50μs采样点。
3. 切换角度偏置，开启/关闭坐标轴，比较真实id和反馈id。
4. 切换启动/全程，观察不同阶段。窗口量程按两组共同数据确定。
5. 导出本页，查看干净图片、两组dq对照及配套文字。

“稳态”依据末20ms的两组速度平台检查；未通过则显示“末段”。它不构成全系统稳定性证明。完整变换、来源和现象解读见[带读说明](带读说明.md)。

## 导出与验证

导出保存在`vector_lesson/exports/<独立编号>`，包括：

- snapshot.png：当前游标对应的四图。
- comparison.png：同窗口、同量程的理想/偏置dq对照。
- signals.csv：信号字典。
- windows.json：窗口及速度平台检查。
- metrics.json：同窗口均值、坐标变换与模型日志残差。
- notes.md及record.json：文字说明、来源和文件指纹。
