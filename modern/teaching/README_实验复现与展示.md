# 实验复现与展示

固定实验均可按保存的因素大小和时长重新运行。原六项场景之外增加“死区配对”“低速补偿”“噪声与滤波”“真实时序”“CCR更新边界”“低侧采样窗口”“编码器角度”“计数测速”“测速反馈”和“速度滤波”，其比较契约与检查分别记录。可复现需区分“同一份原始数据重新出图”和“重新仿真得到一致的数值结果”。

## 重新做实验

```matlab
cd('D:/simulink/modern')
addpath('teaching')
open_pmsm_experiments
```

在窗口恢复固定参考，选择场景和因素大小，运行对照。前七项每次两组，低速补偿、噪声与滤波、低侧采样窗口每次三组，第十项真实时序两组，第十一项CCR更新边界三组，第十三项编码器角度三组。第九项分别输入噪声RMS与截止频率；第十二项输入触发相位和稳定等待；第十三项输入每转计数、延迟拍数和电角零位。第十至十三项默认每组50ms，其他场景默认每组0.2s。每次结果创建独立目录，保留完整配置、原始信号、MATLAB版本、模型/参考/脚本指纹和图片校验信息，不覆盖上一次实验。噪声场景使用固定随机种子。

若需要严格复现某一份已保存实验，使用原结果目录：

```matlab
pmsm_reference('restore')
[r,v]=repeat_pmsm_experiment('原实验完整目录');
disp(v.all_exact)
```

函数先校验原结果包和参考版本，再按原因素值、原时长运行，并核对所有组的完整配置。比较原档案保留的每一路信号的`Time`和`Data`，逐点记录是否相同及最大数值差。比较结果另存于`experiments/repeat_checks`。

`all_exact=true`表示被比较的原始信号逐点相同。它不表示不同MATLAB更新版本、操作系统、求解器、编译环境或硬件平台必然逐位一致；跨环境应重新核对版本与数值误差。早期结果保留16路，后续两组场景各保留21路，低速补偿三组各保留22路，噪声与滤波三组各保留21路，真实时序两组各保留24路；比较以原档案实际保留的信号为准。

## 重新出展示图

```matlab
export_pmsm_experiment_examples
```

默认读取`experiment_reproducibility_validation.json`中已通过复现检查的结果目录；通过的专项验收场景也自动加入图库，包括`experiment_sampling_window_validation.json`。全部来源索引记录指纹。只读取原始MAT数据重新绘图，不运行仿真，不修改原始结果包。也可以传入具有`all_passed`和`run_folders`字段的已验证索引JSON。

输出为`experiments/examples/<场景>/comparison.png`、`response.png`及适用场景的`mechanism.png`、`startup.png`。每组配套`notes.md`解释参数、工况、曲线定义和边界；`summary.json`记录数据来源、绘图脚本版本及图片指纹。电角度对齐场景另有`alignment.json`，噪声与滤波另有`analysis.json`，真实时序另有`timing.json`、`events.csv`，均登记校验指纹。

第十一项CCR更新边界三组各保留24路，默认每组50ms；专项索引为`experiment_timing_deadline_validation.json`，通过后由同一导出入口自动并入图库。派生材料包含`deadline.json`和`events.csv`，同时登记校验指纹；`comparison.png`在该场景表示指令序号，`mechanism.png`表示更新边界事件。第十二项低侧采样窗口由专项索引自动并入，包含样本值/有效性、窗口机制及启动响应三张图。

PNG或MAT容器文件的字节一致性不等同于数值复现。字体、渲染器、图片压缩和文件时间信息可能改变文件字节；物理波形复现检查比较实际时间与数值。

## 用于宣传时对应什么证据

- 固定场景可以重复演示，因素大小可修改，十六项场景统一入口。
- 原始结果与展示图可追溯，展示图简洁，解释与实验条件在配套正文。
- 展示前区分演示参数、固件标称参数与实测校准参数。当前不是已经完成实板校准的数字孪生。
- 原门极死区场景包含详细桥和数值步长变化，不能把全部电流差归因为纯死区；新增“死区配对”使用同桥、同步长，电流按真实转子电角度对齐。仍不能把各自启动累计的角度差当作固定控制延迟。
- 保存宣传使用的具体结果包及对应文字，不依赖会更新的`latest.json`。逐次MAT结果默认被Git忽略，需要交付给其他机器时另行保留完整结果包。

完整默认实验的重跑入口为`validate_pmsm_experiment_reproducibility`，检查报告为`experiment_reproducibility_validation.json`。新入口包含新增场景时先要求相应专项验收通过。它检查各组实际保留的信号，不把这一结论扩大为所有任意参数组合均稳定或已实板验证；历史六项验收不自动算作新增场景的完整复现证据。
