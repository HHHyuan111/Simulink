## 采样前模拟低通

“采样设置 → 滤波与延迟”新增“模拟低通”，默认关闭。三相各用连续一阶环节`H(s)=ωa/(s+ωa)`，初始状态0，演示截止频率5kHz。

信号顺序为：真实电流 → 增益/偏置/已有噪声 → **模拟低通** → 同步采样 → ADC量化/饱和 → 数字低通 → 整周期传递延迟。模拟滤波和数字滤波可单独开启，不能将二者的截止频率直接相加。现有噪声在模拟滤波之前；没有另外加入ADC内部噪声。

这仍是等效电流域的一阶前端，未包含放大器带宽/压摆率、ADC采样电容、低侧有效窗口或三相顺序采样。原理图到位后，用实际RC和放大器参数替换演示值。

## 功率级平均误差

“逆变器与PMSM”色域底部新增“功率设置”，其中两项默认关闭：死区平均压降、器件导通压降。原理想桥输出经过小“压降”块，再进入原V-I测量与电机；全部关闭时通过旁路保持原波形。

设正相电流从逆变器流向电机，`i`按每个PWM周期保持：

```text
direction = i / (abs(i) + Iblend)
drop_raw  = dead_on * (tdead/Tpwm) * (Vdc + drop_on*Vf) * direction
            + drop_on * Ron * i
drop      = drop_raw - mean(drop_raw)
Vactual   = Videal - drop
```

去掉共模适用于当前浮置星点的三线电机。公式参考固件独立诊断工具`mc_deadtime_comp.c`的压降结构，在仿真对象侧扣除，而不是向控制器加入补偿。没有启用固件补偿算法。

| 参数 | 当前值 | 来源 |
| --- | --- | --- |
| 死区目标 | 0.5μs | AxDr_L dev `board_config.h`及TIM1的80计数/160MHz配置 |
| Ron | 0.01Ω | 演示值，待器件型号、温度确认 |
| Vf | 0.7V | 演示值，仅在死区项和器件项同时开启时计入 |
| Iblend | 0.1A | 过零平滑的演示值 |

**这是周期平均等效模型。** 当前1μs数值步长无法解析0.5μs的门极死区；六路门极仍严格互补，不产生上下管同时关断区间。没有逐开关沿二极管续流、最小脉宽、开关损耗或母线动态。0/100%占空比、脉冲消失和过零附近也不能据此做精确器件结论。后续真实门极死区模型加入后，应替换此等效项，避免重复计算。

## 日志与指标的边界

- 原`log_*`保留，通常每50μs记录一次，只适合控制量与同相位采样的比较。
- `obs_pi_speed/d/q`依次记录`[P I 限幅前 限幅后]`，每50μs一组。速度任务启用分频后，记录里会重复保留值；记录频率不等于控制执行频率。
- `obs_state`记录真实`[id iq ωm θm]`。`obs_id_ref`直接来自主id给定常量，避开原辅助Chirp的同名标签。
- `obs_gates_fast`、`obs_carrier_fast`、`obs_current_fast`、`obs_phase_ideal/actual`、`obs_torque_fast`、`obs_vdq_fast`按求解步长T记录。当前T=1μs，每PWM周期50点。
- 报告将快速实际dq电压按完整PWM周期求均值，再与指令比较，避免拿每周期同相位的开关电压样本冒充平均电压。
- 电流“每周期去均值RMS”包含基波在周期内的变化，不等于纯开关纹波或THD。功率是模型电机端的电输入功率，不是包含开关、驱动、铜损等分项的整机效率。
- `|Vdq|/(Vdc/√3)`仅监视电压裕量；当前最终矢量限幅和前馈抗饱和尚未修复。PI限幅比例按日志样本统计，未宣称满足性能验收。

快速日志会增加长仿真的内存占用，教学对照默认运行120ms；先用短窗口分析开关细节。关闭因素时仍保留观测，方便统一比较。
