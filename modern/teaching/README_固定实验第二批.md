## 三种报告

“三相电流”保持原来三行ABC、两列参考/因素开启的布局；同相纵轴一致，真实电流为1μs记录，控制器测量为控制周期记录，按阶梯显示。

“闭环响应与误差”同时保留速度、转矩、真实/反馈dq、测量误差及实际电流轨迹差。不能只看反馈跟踪；末20ms统计不预设已经严格稳态，也不把两组轨迹差直接视为某次谐波。

新增“因素机制”只对第二批三项启用：

- 数字滤波：滤波前后A相、三相滤波改变量，以及当前离散滤波器的解析幅相响应。这里不叠加噪声，因此用于观察滤波代价，不宣称完成降噪对照。模型使用`a=exp(−2πf dt)`、`y[k]=a y[k−1]+(1−a)x[k]`，初态为零；参数f用于确定极点，不把它无条件等同于离散系统精确−3dB频率。
- 角度偏置：真实/测量角度、最短角差、真实/反馈dq。角度环绕不算成360°大跳变；单位为电角度，机械误差需要乘极对数。
- 门极死区：A相上管和下管的请求/实际门极、两管同时关断的空白，以及真实A相电流对照。门极图用局部相对时间显示，配套文字记录绝对窗口起点；短于死区的请求脉冲可能被抑制。

## 数值与模型边界

门极死区会切换详细桥，并把固定步长从1μs细化为62.5ns。当前理想参考保持原始设置，因此这一对照包含死区、桥路径和数值步长变化，不能称作严格隔离的纯死区误差，也不能由较小转矩波动宣称死区有益。后续要定量比较死区或补偿，先增加“同一详细桥、同一步长、0死区与非零死区”的配对对照，再进行算法评估。

门极死区不代表已经完整模拟驱动传播差异、MOSFET开关瞬态、寄生参数、温度和器件非线性。详细桥近零电流带属于数值近似，当前要求Ld=Lq。角度偏置不含完整编码器ABZ接口；数字滤波不代表模拟前端电路。

仍未实现主动过流保护。8A是iq指令限幅，并不保证真实电流峰值不超过8A。本次1500Hz滤波演示中真实iq峰值约9.48A，正说明反馈处理会影响实际闭环。

## 本次实际结果

统计窗口0.18—0.20s，不预设严格稳态：

| 工况 | 真实id均值 | 控制器反馈id均值 |
| --- | ---: | ---: |
| 固定参考 | +0.001A | +0.001A |
| 数字滤波1500Hz | −0.640A | −0.001A |
| 电角偏置+5° | −0.429A | +0.001A |

滤波与角度偏置都能让反馈id接近零而真实id偏离零，原因不同，需结合机制页区分。门极死区本次已在尾部诊断中检查30个完整开通沿：延后2μs；下降沿立即关断，无上下管同时导通。三相电流测量因素与补偿均关闭。
