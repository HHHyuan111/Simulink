# 速度滤波

第十六项固定实验`speed_filter`。固定机械计数与差分窗口，只比较“无速度滤波 / 加速度滤波”两组。原速度PI、电流环、角度路径、电机、负载、初态与真实事件时序保持相同，暂不整定PI。

## 操作

```matlab
cd('D:/simulink/modern'); addpath('teaching')
open_pmsm_experiments
```

选择“速度滤波”，恢复固定参考，再运行两组。默认每组100ms；50—100ms可用脚本设置。默认延长至100ms，是因为前50ms的iq给定常达到8A限幅，测速差别未必能传到执行端。

| 输入 | 默认 | 范围 |
| --- | ---: | --- |
| 每机械转解码计数 | 10000 | 整数20—1000000，不再乘4 |
| 差分窗口 | 2拍 | 整数2—7，每拍50µs |
| 截止频率 | 200Hz | 20—5000Hz，可用小数 |

```matlab
r=run_pmsm_experiment('speed_filter');
r=run_pmsm_experiment('speed_filter',[5000 3 500],.1);
[again,check]=repeat_pmsm_experiment(r.folder);
```

[5000,3,500]用于检查多个参数是否实际生效，不是与默认值作单一截止频率整定比较。若要只研究截止频率，应保留计数和窗口，例如改成[10000,2,500]。

“展开速度滤波”打开原模型`速度反馈/速度滤波`，内部由输入增益、历史增益、求和、单位延迟、有效性选择及旁路开关构成。看完恢复参考即可移除；固定实验以窗口与保存的计划为准，不读取展开后手动修改的遮罩。运行后恢复原连接，不保存覆盖主SLX或`reference_v1`。

## 信号链与更新节奏

机械计数 → 指定窗口差分 → 有效测速 → 可选速度低通 → 原反馈选择 → 原速度任务保持 → 原速度PI。

两组都使用指定窗口的计数测速，角度仍走原路径。滤波每50µs、在JEOS偏移28.875µs更新；速度PI每100µs、在偏移78.875µs消费一次。滤波不改原保持块，没有另加纯延迟块。低通自身有动态滞后，不能把它与窗口平均及原速度任务保持时间混为一谈。

背景中的1拍及长窗观察器继续记录，长窗固定为指定窗口的4倍；它们没有成为两组控制输入。两组闭环轨迹各自变化，不强制共用同一转速或计数轨迹。

## 对应固件的哪一部分

AxDr_L快照`48d6e86814ac6657b1313b4c92ef24c88f492e07`：`algorithm/control_filter.c`初始化一阶低通，`motor/foc_drv.c`设置`wr_lpf.fc=CTRL_SIGNAL_FILTER_CUTOFF_HZ`及`fs=DRIVE_FOC_FREQ_HZ`，`app/control_cycle.c`每快环调用`ctrl_fb_update`。默认截止频率200Hz，滤波更新20kHz，速度PI消费10kHz。

模型沿用该递推形式：

`a = 1/(1+2πfcTs)`，`b = 1-a`，`y[k] = b*x[k] + a*y[k-1]`。

200Hz、50µs时，a约0.94088，b约0.05912。当前拍输入直接参与当前输出，历史来自前一个读取格点；不是先整体延迟一拍再滤波。固件滤波量为机械rad/s，本模型为机械rpm，线性滤波与常数单位换算可以交换。固件使用float与近似常数，模型用double，不宣称浮点位级等价。

滤波初态0。无有效测速历史时输入零，内部状态仍按零输入递推，发布值零；关闭时直通原有效测速，内部滤波候选仍记录。这是明确的教学处理。固件位置缺样时有估计器冻结/保持，本实验尚未模拟其完整缺样链，也没有启动接管或故障停机状态机。截止频率是源码参考或教学参数，不是实测整定结论。

## 怎样区分平滑收益与动态误差

只在滤波组的同一轨迹上做线性分解，真值路径只用于观测，不送进控制器。设窗口真实平均速度为w，计数测速为x，瞬时真实速度为n，H为当前低通，则有效区间：

`H(x)-n = H(x-w) + [H(w)-w] + (w-n)`。

- `H(x-w)`：滤后的计数量化贡献。
- `H(w)-w`：滤波对真实窗口速度造成的动态误差。
- `w-n`：差分窗口平均速度与瞬时速度的差。

三项相加等于总误差，逐点核对。关闭滤波时H为直通，滤波动态项为0。历史不足的窗口真值按零输入定义，与估计器的零初始化一致；统计只取有效样本。加速时滤波速度往往落后，减速时可能高于当前速度；量化贡献下降不等于实际反馈总误差或闭环性能全面改善。

三页报告分别是：速度滤波（实际PI输入与iq给定）、闭环响应（真实速度、iq给定、转矩、真实q轴电流）、平滑与滞后（滤波组同轨迹的速度与误差分量、启动）。逐列对照图同一行使用相同纵轴，解释与参数放在正文。

## 数据与复现

每组33路原始时间序列，共66路。原`log_speed_control`仍是实际原速度保持输出；`log_speed_feedback`继续记录选用计数、来源开关与原速度。新增`log_speed_filter`按20kHz记录7列：有效测速输入、未旁路滤波状态、实际发布值、候选有效标志、滤波开关、系数a、系数b。

默认100ms实验末20ms结果如下，仍为短时动态工况。两组各自闭环轨迹不同，量化贡献的直接滤前/滤后比较应使用滤波组自身：24.90→1.33rpm，约下降94.7%；不是把两组强行视作同一计数序列。

| 指标 | 无滤波 | 加滤波 |
| --- | ---: | ---: |
| 计数量化贡献RMS | 24.76rpm | 1.33rpm |
| 滤波动态误差RMS | 0rpm | 5.06rpm |
| 实际PI反馈误差RMS | 24.93rpm | 5.50rpm |
| iq给定逐拍变化RMS | 0.50758A | 0.02331A |
| 转矩标准差 | 0.01346N·m | 0.01081N·m |

此处iq逐拍变化含20kHz日志中10kHz保持拍的零差；转矩标准差包含动态趋势，不是纯谐波幅值。结果说明该工况下平滑作用已传到给定和被控对象，不能扩大为所有截止频率和工况都更好。

`filter_samples.csv`按10kHz速度PI消费时刻记录计数来源、实际PI输入、滤波状态与误差分量；`speed_filter.json`保存递推检查、系数、窗口/量化/滤波误差及有限时间窗指标。不同任务的时戳按相同62.5ns事件格点关联，并要求实际时间差小于1ps，不插值；完整复跑则逐路严格比较各自的Time/Data。

验收入口`validate_pmsm_speed_filter`分为`default/repeat/parameters/finish`，最终报告为`experiment_speed_filter_validation.json`。检查关闭旁路、20/200/1000/5000Hz递推、正负输入、零初态、无效输入/状态衰减/发布值、编译更新时刻、实际PI输入、默认66路复跑、[5000,3,500]参数、GUI展开/恢复和文件篡改拒绝。

默认无滤波组与上一项50ms窗口测速的26路完整原始观测核对前50ms；不把不同尾部记录区间的事件诊断称为完整时间轴相同。参数工况无滤波组与上一项[5000,3,12]、100ms窗口测速组的32路比较；另外回归旧电流零偏42路及上一项两套档案的分析。模型、PI、布局和固定参考保持；各项专项证据分开保存，不把图库重绘视作全部场景重新仿真。

默认66路Time/Data已独立严格复现，[5000,3,500]参数回归通过，其无滤波32路Time/Data与上一项对应工况全部严格相同。本轮跨任务格点关联与逐路严格复跑分别记录；参数回归未使用时间网格例外来替代32路的严格Time/Data相等。
