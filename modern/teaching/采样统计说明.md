# 采样统计

Scope负责看现象；这里负责把同一段记录的差别变成数值。统计工具只读数据，不修改控制器、电机、采样开关或已封存实验。

## 使用

教学工作台重新打开后，选择“观测 → 电流采样演示”，演示结束再选择“观测 → 最近演示统计”。命令行等价入口：

```matlab
[out, provenance, metrics] = preview_pmsm_current_sampling;
open_pmsm_sampling_metrics;
```

演示仍然是20ms启动过程，使用当前电机和PI参数。仅在SimulationInput中开启真实时序及ADC、关闭旧PWM整周期保持和旧采样整周期延迟，结束后检查用户参数恢复。

默认统计Scope记录的最后500µs，包含两端点。当前真实时序网格62.5ns，对应8001个点。表头显示实际区间和点数。**它不会跟随Scope缩放或后续模型运行自动更新**；再次运行演示才更新“最近演示统计”。

## 电流表怎么读

| 比较项 | 含义 |
| --- | --- |
| 反馈−真实，A/B/C | 最终反馈与同一时刻真实相电流的偏差，包含所有已开启因素 |
| 保持−真实，A | 模型零阶保持输出与同一时刻真实A相电流的差别 |
| 反馈−保持，A | 保持阶段之后的差别；启用滤波、旧延迟等时不能只归因于量化 |

RMS表示这段记录内偏差的总体大小，保留直流偏差；均值表示正负偏差是否长期偏向一边；最大绝对值表示这段记录中最大的偏离。所有电流指标单位都是A。

`反馈−真实 = (保持−真实) + (反馈−保持)`逐点成立，但三个RMS不能直接相加或相减，因为其中存在相关项。不要用两个RMS之差推算ADC量化误差。

分析结果另外保留真实三相电流的窗口峰峰值。它含有窗口内的基波变化、启动趋势和开关纹波，**不称作纯PWM纹波峰峰值**。

## ADC表怎么读

时序间隔直接来自事件记录：触发到JEOS，以及A/B/C各相采样结束到JEOS。按记录的PWM周期起点配对，缺失或重复事件不会用其他周期的脉冲补齐。“未配对”列包含缺失和歧义；“—”表示无可用事件，不代表零延迟。

C、B、A顺序采样时，C较早完成采样，所以它到JEOS的间隔通常比A大。这是事件间隔，不能当作整个反馈链的唯一延迟；还要区分保持更新、计算和PWM生效。采样结束事件也不能证明当次样本有效，有效窗口标志单独保存在分析结果中。

统计按窗口内JEOS选择记录，但允许从完整事件日志寻找同周期、窗口起点之前的触发。因此，窗口边界处的触发数和JEOS数可能不同，不应直接认定为丢事件。

## 当前演示示例

现有19.5–20ms启动片段中，A相“反馈−真实”RMS约0.19959A，“保持−真实”约0.19911A，“反馈−保持”约0.01184A。触发→JEOS为4.5µs；A/B/C采样结束→JEOS分别约0.3125/1.8125/3.3125µs。这些数值说明当前片段中的阶段差别，不是稳态性能、实板精度或纯死区影响的结论。

## 自定义区间与复现

```matlab
metrics = pmsm_current_sampling_metrics(out, [0.0196 0.0199]);
open_pmsm_sampling_metrics(metrics, provenance);
```

区间必须位于已保留的原生Scope记录中；当前最多64000点，真实时序下约4ms。计算不插值、不平滑，并核对四组Scope时间轴及ADC原事件来源。非均匀网格、越界区间和采样后的稀疏ADC日志会被拒绝。

最近结果保存在`modern/.build/current_sampling_metrics.mat`及同名JSON，包含参数快照、临时覆盖项、模型/演示/分析源码哈希。用于宣传或长期比较时，单独保留本次`out`、`provenance`、`metrics`，不要把会更新的“最近结果”当作永久实验档案。固定对照继续使用已有封存实验框架。

验证：`validate_pmsm_current_sampling_metrics`，记录见`current_sampling_metrics_validation.json`。覆盖已知误差、已知事件间隔、无事件、缺失/重复事件、无效区间与网格，以及现有演示的重复分析一致性、原数据未改变和原生表格入口。

桌面完整入口已验收，记录见`sampling_metrics_desktop_validation.json`；[原生统计表预览](native_sampling_metrics.jpg)。
