# 电流采样教学

入口：模型顶部“时域观测 → 电流采样”。采样设置、当前采样链用于自己运行；“保留本次运行 → 对比我的运行”用原生数据检查器看自己保留的最近两次结果。“内置示例”单独读取固定实验。不增加控制算法，也不自动执行仿真或恢复参数。简短操作见[自己运行、自己对比](../signal_chain/user_runs/README.md)。

“内置示例”默认打开下面的噪声与滤波图，图窗“教学对比”菜单可切换采样延迟、数字滤波、PWM更新、死区补偿；复用已打开图窗。1/2拍延迟、1500/500Hz数字滤波的200ms实验与原组共用逐点一致的参考，六格时域联动，说明及证据见[采样因素的闭环影响](../signal_chain/feedback_effects/README.md)。

“PWM更新”：5/10.5/15μs计算时间对照，上方微秒级写入/生效及指令序号，下方毫秒级dq、转矩与转速；两类时间轴各自联动，不新增面板。条件、结果及更新窗口解释见[PWM更新与闭环](../signal_chain/timing_feedback/README.md)。五种主题的共同口径见[三条教学链](../signal_chain/teaching_chain/README.md)。

## 当前采样链

复用原生“电流与采样”Scope，白底、1120×800、默认500μs窗口。打开后在模型点击运行。四格共用时间轴：三相真实电流、三相控制反馈、A相真实/捕获保持/反馈同轴、ADC触发与JEOS同轴。观测按`timing_h`运行，简化模式1μs、事件模式62.5ns，不将50μs控制记录插值成高频波形。

A相保持值取原“采样设置/捕获”输出，反馈取真正送往坐标变换的测量电流。理想旁路时，捕获支路仍可能有阶梯，但控制反馈直接取真值；不能把未选支路当成控制延迟。可分别开启已有ADC、滤波、延迟或真实时序研究，注意不要重复叠加同一延迟。ADC事件用于看微秒级因果关系，不用于从短窗口评价稳态谐波。

## 噪声与滤波对比

读取既有三组档案：参考、固定噪声、同一注入序列加数字低通；3000rpm、24V、0.207N·m，原PI、理想桥、其他附加因素关闭，噪声0.02A RMS、截止1500Hz。这是已保存的演示工况，不随当前参数更新，也不是实板标定。

2×3图窗按问题组织，比较量同轴：

| 画面 | 曲线 | 要回答的问题 |
|---|---|---|
| A相电流 | 滤波组真实电流与实际反馈 | 控制器看到的电流与物理电流差在哪里？ |
| A相噪声分量 | 同一注入序列滤波前后 | 噪声直接分量如何衰减？ |
| A相噪声功率谱 | 上述分量的Welch PSD | 衰减主要发生在哪些频率？ |
| d轴电流 | 滤波组真实、反馈、给定 | 看起来跟住给定，真实电流也一样吗？ |
| q轴跟踪误差 | 三组真实iq−各自iq给定 | 各组实际跟踪偏差怎样变化？ |
| 转矩 | 三组电磁转矩与共同负载 | 测量链变化怎样传到机械输出？ |

五个时域画面共用180～200ms时间轴、联动缩放；PSD独立频率轴。物理电流用原始1μs记录，反馈、dq及转矩用原始50μs控制记录。没有插值、平滑或人为对齐跨次电流峰值。

PSD使用120～200ms、20kHz噪声记录，去整窗均值，周期Hann窗256点、50%重叠，单边A²/Hz，图中为dB re 1A²/Hz。原频率间隔78.125Hz；4倍零填充只加密显示，不提高分辨率。PSD面积核对加窗分段功率，不等于有限记录无权RMS。噪声分量依据本组实际注入与同一滤波递推分解，线性重构误差已检查；它不是总测量误差，也不是另外做的平滑图。

滤波会带来确定性的幅相误差，因此噪声PSD降低不代表真实id、iq或转矩表现全面改善。转矩采用控制任务时刻的瞬时记录，不是全带宽PWM转矩纹波；本轮不新增“滤波改善率”之类易误读指标。图窗菜单“工况与说明”提供数据口径，图内保留简短标题、图例与单位。
