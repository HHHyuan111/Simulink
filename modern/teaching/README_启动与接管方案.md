# 启动与接管方案

## 这一步解决什么

现有实验从仿真开始就运行各控制环，适合比较测量、时序和功率因素，但没有完整表达“什么时候允许控制、什么时候允许出PWM、停机后留下哪些状态”。下一批增加一个独立的“启停”开关，在同一个原模型中局部接入，不改九宫格和原有小模块的控制算法。

开关关闭时恢复第十六项原连接与数值；打开时演示启动、反馈准备、电流环建立、速度环接管、停止与旋转中重启。电机机械状态连续，不在停机时把转速或角度清零。第一批假设电角零位已经正确，沿用原控制角度路径；计数测速及速度滤波按前一项配置接入。

## 已核实的接口事实

可重跑核对：在独立MATLAB进程中，进入`modern`并执行`addpath('teaching'); audit_pmsm_startup_interfaces`。实际结果见[startup_interface_audit.json](startup_interface_audit.json)。这是接口与组件核对，不是新启动闭环的验收报告。

| 位置 | 当前事实 | 启动层必须处理 |
| --- | --- | --- |
| 速度PI，SID155 | 单误差输入，转矩输出，Backward Euler；无使能/复位接口 | 显式允许执行和清积分；保留N·m到iq的原换算 |
| d/q PI，SID439/453 | 单误差输入，Backward Euler；无使能/复位接口 | 三个PI分别控制，关闭时不只遮住输出 |
| 原速度保持，SID190 | 保留10kHz速度任务输入边界 | 不额外插入一拍测速延迟 |
| `输出延迟/CCR预装载` | 有shadow、active和pending状态；只有时间、请求、配置三个输入 | 停止及重新启动需清旧pending和中间缓存 |
| `Universal Bridge`理想支路 | 直接代入当前公式，六门极全0得到三相电压全0 | 不能用它证明断开续流或滑行 |
| 已有`续流`支路 | 全关时按相电流选择二极管；近零采用已声明的静态近似 | 启停功率实验使用此支路，首批死区/压降/补偿均设0或关闭 |
| 门极死区组件 | 全关请求会取消已安排的开通沿 | 关断必须覆盖六路，并在实际门极处验收 |
| 测速与滤波 | 20kHz更新；滤波零初态；测速历史不足时valid=0 | 继续观测转子；valid表示可计算，不表示滤波已稳定 |

组件实算还确认：改变当前请求不能取消已经写入的CCR，旧pending仍会在下一UEV生效。因此只在SVPWM前把电压置0，无法保证实际输出及时停下。需要同时处理最终门极和历史队列。

## 对照固件，哪些相同、哪些暂时不同

本机固件HEAD为`48d6e86814ac6657b1313b4c92ef24c88f492e07`；本次读取文件的SHA256另存核对报告，避免仅凭分支名认定内容。

`drive.c`分开保存请求、发布状态和`pwm_active`。START先设置三相50%占空比，再启动硬件输出并清控制历史；STOP调用六路停止并清控制器。`drive_reset.c`会清PI及控制中间量，重新开始时保留本次用户目标；它没有在这里清除测速环形历史或速度低通状态。模型采用同样的分离原则。

固件还有ABZ自动定位：固定角d轴电流，1.2s保持、0.3s采集，再按圆均值及电流条件判断成功。该阶段下一轮独立开发。本批“已知电角零位”是显式教学前提，不能宣传为复刻了固件完整上电过程。固件START内部请求晋升RUN后，当拍发布状态仍可为STARTING，下一快环才发布RUN；教学状态不宣称逐拍对应全部固件状态。

50%占空比是使能后的零平均线电压，不是功率关断。全关后仍可能有续流和转矩，不能要求电流或电磁转矩瞬间归零。现有母线是理想电压源，本批不能验证再生引起的母线过压、驱动器引脚电平或HAL调用耗时。

## 状态和接管顺序

采用五个可见状态，避免把准备条件藏进一个复杂“启动”模块。状态在20kHz快环边界推进，门极互锁在已有62.5ns事件格点执行。

| 状态 | 进入/离开条件 | 电流环 | 速度环 | 功率输出 |
| --- | --- | --- | --- | --- |
| 停止 | 初始、停止请求或反馈运行条件失效；新启动沿才离开 | 禁止，保持复位 | 禁止，保持复位 | 六路关断，旧PWM队列作废 |
| 等待 | 已接受启动；等待选定测速窗口有效及所需角度读取有效 | 禁止，保持复位 | 禁止，保持复位 | 六路关断 |
| 采样 | 先清PWM队列并设置中性占空比，再使能；等待使能之后的新一组电流采样 | 禁止，保持复位 | 禁止，保持复位 | 中性PWM，尚不执行电流闭环 |
| 电流 | 新样本有效，id/iq给定暂为0；至少完成一次有效电流环执行 | 执行 | 禁止，保持复位 | 新电流控制结果经原CCR链生效 |
| 运行 | 到下一次允许的速度任务边界后接管 | 执行 | 执行 | 原限压、SVPWM、CCR和桥链 |

“采样”不能省略：低侧窗口检查打开时，六路关断期间未必能获得可用电流样本。若在关断的“等待”中要求低侧电流先有效，可能永远等不到启动条件。因此先等独立于功率开通的角度/测速，再用中性PWM获取新电流。首批可关闭窗口误差做基础验收，另单独检查窗口打开时不存在上述等待死锁。

优先级：停止/运行条件失效 > 初始化和队列清除 > 状态推进 > 控制计算 > 正常PWM提交。同一快环发生停止与接管时必须停止；RUN期间反馈失效不自动恢复输出，需要停止请求确认后再出现新启动沿。这是本批的输出互锁规则，不代替完整故障锁存、超时和保护体系。

外部请求在下一次快环被接受，接受后六路输出在同一事件格点关断；记录请求时刻、接受时刻和实际关断时刻，避免把50µs以内的任务等待隐藏掉。异步硬件急停后续独立建模。

## 给定、积分和历史的处理

用户目标、各环实际给定、各环执行许可、PWM许可分别记录。停止时保留用户目标，实际电流给定回0，执行许可撤销，三个PI保持复位。仅把误差置0不能保证积分清除，因为回算和旧积分仍可能存在。

速度PI的复位保持到“运行”接管，电流PI的复位保持到“电流”阶段。复位采用持续电平，并在各自任务边界被消费，不能用一个50µs脉冲假设10kHz速度任务必然看见。复位解除后的Backward Euler第一拍如何执行，必须由实际组件测试确定并写入结果，不改成另一套积分算法。

速度接管第一版直接使用保留的用户目标，iq沿用8A指令上限。积分清零不等于无扰切换，目标与当前转速不同时可能出现比例跳变；保留并展示这个现象。斜坡给定、积分预置及无扰切换作为后续独立可选能力，不提前宣称已经实现。

停机时保留转子转速、机械角度和计数；测速及速度滤波持续更新，不因为驱动停止而把运动估计清0。第一次仿真启动仍保留原零初始化，历史不够时不伪造真值；旋转中重启可以使用一直在更新的有效测量。

PWM相关的shadow、active、pending、请求缓存及门极待开通状态要按停止/重启契约处理。停止时最终六门极为0；重启先完成中性初始化，再开门极，不能让上一轮非中性CCR短暂恢复。原全局PWM事件相位继续推进，本批不声称复刻硬件停表及重新起表的全部细节。

## 接入原模型的位置

顶层只增加简短的“启停”入口。状态与许可在这个入口展开，局部信号通过明确命名的接口进入速度环、电流环和功率输出；不把原PI、SVPWM、电机重新打包成大黑盒。

| 接口 | 首批改动 |
| --- | --- |
| 三个原PI内部 | 增加显式执行/复位接口；保留原参数、积分方法和回算路径；关闭框架时精确旁路 |
| 原速度给定、转矩到iq换算 | 区分用户目标与当前允许给定，不更换转矩常数 |
| `输出延迟`内部 | 可撤销旧提交及中性初始化；关闭框架时不改变原事件顺序 |
| 桥的门极输入及实际门极出口 | 六路统一互锁；请求与生效分别观测；续流桥继续处理关断电流 |
| 观测区 | 增加状态、执行许可、有效标志、积分、队列和实际输出观测；布局清理仍后移 |

继续采用可撤销安装，在独立副本验收；不覆盖主SLX或`reference_v1`。现有开关表不增加尚未实现的空选项。

## 第一批操作与实验

只给用户一个“启停框架”开关，以及三个时间输入：启动、停止、重启，单位ms。计数10000、差分2拍、速度低通200Hz作为这组实验的显式档案配置；其他因素先关闭。时间必须有序且处于运行区间，参数错误在仿真前拒绝。

建议首个演示时间为0/70/85ms，总时长130ms。它是待实跑确认的教学候选，不是已验证结果。电机、PI、3000rpm目标和0.207N·m负载保持；停机时负载继续施加，允许电机减速，必要时缩短停机间隔展示旋转中重启。若另做空载实验，明确另存工况，不悄悄改负载。

第一批实验按机制验收，而非强行制造“性能更好”：

1. 初始无测速历史：不得提前进入电流或速度闭环，不得用理想速度替补。
2. 正常启动：新电流采样、首次电流执行、速度任务接管时刻有先后依据。
3. 运行中停止/旋转中重启：物理转子连续，PI按契约清除，没有旧CCR回放。
4. 停止和接管同拍、写CCR和UEV相邻或同拍：停止优先，原UEV先于写入的规则保持。
5. 准备条件一直不满足及运行中失效：等待或撤销输出，不靠真值绕过；失效恢复不自动重新启动。
6. 低侧窗口开/关：使能后获取新样本，无关断等待死锁；原窗口无效策略单独说明。
7. 框架关闭：第十六项原始Time/Data严格回归，主文件、PI参数、原布局和完整参考保持。

观测三页：“状态与门极”“给定与积分”“电流与转速”。图片只保留主题、图例、曲线及单位，参数和解读写在正文。门极验收要覆盖所有停止区间和每次启停附近，不能只看当前末4000点日志；需要完整互锁扫描及边沿事件记录。

每次结果包记录请求计划、实际接受时刻、状态及原因、三环许可与积分、选定测量有效性、用户/实际给定、CCR提交和生效序号、六门极、三相电流、dq、转矩和速度。保存源码/配置指纹，独立重跑后逐点核对；主参考恢复也属于验收。
