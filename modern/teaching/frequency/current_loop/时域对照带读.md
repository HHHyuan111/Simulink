# 电流环时域对照

从“频域分析 → 固定实验：电流环频率响应”打开 Bode 图，再点击图窗原生菜单“时域对照”。默认显示 1250 Hz，顶部“频点”菜单可切换全部 13 个实际测点，“频率响应”返回对应档案的 Bode 图。

也可以直接执行：

```matlab
open_pmsm_current_frequency_time                 % 默认1250 Hz
open_pmsm_current_frequency_time([],100)         % 低频
open_pmsm_current_frequency_time([],2500)        % 较高频
```

这些曲线取自生成 Bode 图的同一份固定实验档案，使用 0.2 A 扰动数据，不读取当前工作区 out，也不重新仿真。每次截取所选频点测量段最后三个周期；两组使用相同的原始时刻，不移动相位、不归一化幅值、不补采样点。四个子图联动时间缩放，数据提示、平移、缩放、导出均使用 MATLAB 原生功能。

## 四张图怎么对应

蓝色为原反馈，红色为增加一个 Ts 测量延迟；灰色阶梯线为离散电流给定。真实电流、反馈、PI误差及反馈与真实的差值，各自占一格。

| 视图 | 信号 | 学习重点 |
|---|---|---|
| 真实电流 | 原电机真实 id，与给定比较 | 对应闭环 Bode 上面的幅值与相位 |
| 反馈电流 | 实际送往误差节点的 id，与给定比较 | 控制器看到的电流可能落后于真实电流 |
| PI误差 | 给定−反馈 | PI 根据此误差动作；它不是给定−真实电流 |
| 反馈−真实 | 同一时刻的反馈减真实 id | 直接观察测量延迟造成的信息差 |

原反馈组的“反馈−真实”接近零；延迟组中，当前反馈等于上一个采样点的真实电流。本实验 Ts=50 μs，读图时可以比较同一组的真实电流和反馈电流相差多少时间。

不要把两组的真实电流简单理解为同一条曲线平移 50 μs。改变反馈延迟后，PI的动作与电机的闭环轨迹都发生了变化。因此，延迟组某段真实电流更接近给定、相位看起来更靠前，不代表整个环路更稳健，要结合反馈、误差及相位裕度看。

## 建议顺序

先看 100 Hz：电流变化较慢，观察跟踪与小误差。再看 1250 Hz：接近本实验的环路增益交越频率，更容易区分真实电流、反馈与PI误差。最后看 2500 Hz：比较衰减、峰值和相位变化，并回到 Bode 图核对同一测点。

以下数值来自已验证固定档案 `20261015_151702_340_31cebcc9` 的完整八周期拟合，给定峰值均为0.2 A；不是用图片峰值手工测量。相位为真实电流相对于给定的相位，负值表示滞后。

| 频率 | 原反馈：真实电流峰值 / 相位 | 增加1Ts：真实电流峰值 / 相位 | PI误差峰值：原反馈 / 增加1Ts |
|---|---|---|---|
| 100 Hz | 0.2004 A / −4.4° | 0.2009 A / −2.6° | 0.0155 A / 0.0155 A |
| 1250 Hz | 0.1564 A / −52.8° | 0.2119 A / −42.3° | 0.1631 A / 0.2211 A |
| 2500 Hz | 0.1057 A / −84.8° | 0.1690 A / −95.8° | 0.2175 A / 0.3478 A |

1250 Hz处最容易产生误判：延迟组的真实电流幅值更接近0.2 A，相位也比原反馈组靠前，但控制器收到的是延迟50 μs的反馈。这个纯测量延迟在1250 Hz对应22.5°，因此延迟组反馈的相位约为−64.8°，比其真实电流更滞后。它的PI误差也更大。真实电流表面跟踪变好，不等于测量更准确或局部相位裕度提高。

2500 Hz处，测量延迟对应45°；两组真实电流都已衰减，延迟组真实电流的相位也比原反馈组更滞后。不同频率表现不同，所以不能把增加反馈延迟理解为把整个闭环响应统一右移50 μs。局部相位裕度需看返回比的交越点，不能由单张时域图判断。

高频波形的折线与点标记来自真实的 20 kHz 记录。比如 1250 Hz 每周期16点、2500 Hz每周期8点，不能通过补点把它们变成更高采样率的测量。线条只便于阅读。原生“频点”菜单列的是实际测量频率；例如请求1600 Hz因整数周期采样而实际为1538.46 Hz，不用插值伪造1600 Hz的时域记录。

图片只放基本主题、坐标和图例，解释放在本正文。展示样例位于 `example/time/`：100 Hz、1250 Hz、2500 Hz三张PNG及来源清单。需要交互时使用图窗入口；需要完整重做数据时使用 `repeat_pmsm_current_frequency`。

## 验收边界

本轮只新增同源时域查看与入口，不改变电机、PI、实验计划、平均电压适配或原SLX，也不修改既有频响档案。13个频点的130条绘图曲线与原记录逐点核对；三个周期重新拟合与原八周期频响一致到既定容差；原生菜单、联动缩放、无效频点拒绝、模型自定义参数及工作区保留均通过。详见 `time_view_validation.json`。

这仍是零速d轴、周期平均电压的小信号实验，不是死区延迟的解释，也不能直接代表旋转工况或实板表现。
