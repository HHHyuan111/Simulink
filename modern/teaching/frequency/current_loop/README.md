# 电流环频率响应

这是第一项环路频响教学实验：使用原 PMSM 模型的固定参考及实验专用周期平均电压适配器，在零速、零负载条件下比较“原反馈”与“增加 1Ts 延迟”。原 PI 保持不变；Ts=50 μs。这里增加的是电流测量链的一个采样周期延迟，不能把它称为逆变器死区。

## 图窗含义

四个视图依次是闭环幅频、闭环相频、环路增益、环路相位。蓝色为原反馈，红色为增加一个 Ts 延迟，圆点为实际测量频点；连线只帮助阅读。灰色参考线分别为 −3 dB、0 dB、−180°。图内只保留主题、坐标、图例，数值指标见结果档案。

闭环响应测量真实 d 轴电流对给定的响应。返回比则取**同一误差节点的反馈/误差**，包含实际原 PI、保持环节、原电机与测量链的影响。此处零速、q 电流近零，适用于这一局部单输入单输出实验；不推广为旋转、耦合、大信号工况的完整稳定性分析。

## 实验链与质量检查

注入点为原 d 轴误差正端；反馈取该误差负端，误差取原 d 轴 PI 输入，真实电流取原电机状态。原速度环与 q 轴环仍保留，转速给定和负载临时为零。实验仅在独立进程内临时增加注入、平均电压和记录块，结束后恢复原图，并检查模型结构和 SLX 哈希。

原模型的 1 μs PWM 边沿网格不足以解析本实验约 0.1 V 量级的电压扰动。直接使用开关级波形，部分微小脉宽变化不会落到数值时间网格上，无法作为局部线性频响。实验适配器从原 SVPWM 输出 Tcm 按 D=1−2Tcm/Ts、Vabc=Vdc·(D−mean(D)) 计算周期平均相电压，接到原功率压降链输入。原控制器保持、SVPWM、电机和测量环节保留；仅本次实验绕过开关脉冲到电压的映射。它不包含开关纹波、边沿量化、死区、器件导通压降或实际 ADC 触发时序，不能用本图证明这些硬件因素的性能。

平均电压后另有两组共用的 1T（1 μs）单位延迟，避免电压回算路径产生不支持的代数环。这个数值适配延迟也包含在本次估计中，已写入计划，不能解释为开发板实测延迟。对照组额外增加的是测量链的 1Ts（50 μs），两者要区分。

13 个频率约覆盖 50 Hz～4 kHz。每段频率取 fs/N，使其与控制采样网格一致；请求频率和实际频率均存入计划。每段先等待至少四周期且不少于 10 ms，再记录八个完整周期。用相同采样点的正弦、余弦、直流项最小二乘拟合幅值与相位，不用电流 FFT 峰值代替频率响应。

每组均用 0.2 A 和 0.1 A 两种扰动复跑，检查：

- 减半扰动后响应差异小于 2%，避免把大信号非线性当作小信号响应。
- 拟合残差与前后半窗的复幅值漂移均小于 3%。
- 原 PI 和最终电压限制均未触发。
- q 电流与机械速度保持近零，确认局部轴间解耦条件。
- 给定=误差+反馈，采样时间网格完整一致。

不满足条件的频点不用于指标，也不伪装成可信曲线。闭环带宽以单位直流跟踪增益的 −3 dB 交点估计；相位裕度只在有效频点夹住返回比 0 dB 交点时计算。频点之间使用对数频率插值。未覆盖交点时报告缺失，不外推，不把未测到的裕度写成无穷大。

## 当前范围与下一步

2026-10-15 固定参考结果（13 个有效频点，指标为点间插值估计）：

| 工况 | 闭环 −3 dB 带宽 | 返回比 0 dB 交越频率 | 局部相位裕度 |
|---|---:|---:|---:|
| 原反馈 | 1.55 kHz | 1.20 kHz | 77.9° |
| 增加 1Ts 测量延迟 | 2.88 kHz | 1.20 kHz | 56.2° |

延迟组的带宽增加伴随闭环峰值抬高，不能据此认为性能更好。独立进程复跑四次扰动运行，24 路原始信号的 Time/Data 与分析结果严格一致；两组返回比之比与一个 Ts 纯延迟的理论响应最大误差约 5.1×10⁻¹⁰。验收见 `delivery_validation.json`，最近结果见 `latest.json`。

本项是**零速 d 轴、固定 PI、周期平均电压适配**的教学基线，未测实板，不包含旋转工况下的完整多变量裕度，也尚未提供速度环频响和增益裕度。开关级原模型仍用于死区和纹波实验。先体验延迟如何改变闭环峰值及相位裕度，再逐步扩展 q 轴、速度环和单因素滤波对照。带宽变大也不必然意味着控制更好，必须同时看峰值和裕度。

方法依据：[MathWorks 逐频正弦信号](https://www.mathworks.com/help/slcontrol/ug/creating-sinestream-input-signals.html)、[PMSM 频率响应估计示例](https://www.mathworks.com/help/slcontrol/ug/frequency-response-estimation-for-pmsm-model.html)。本实现使用原模型仿真与基础 MATLAB 拟合，不要求额外调用 frestimate 或线性化工具箱。
