# 频域分析

模型顶部“频域分析”集中提供最近输出的电流 FFT/PSD、固定电流环频响实验及归档死区、噪声实验。各入口分别标识数据来源，不自动视为同一工况。

新增[电流环频率响应](current_loop/README.md)：零速 d 轴、周期平均电压适配、原 PI，比较额外 1Ts 测量延迟；提供闭环 Bode、返回比及局部带宽、相位裕度估计。它与下面的电流谐波谱是不同分析。

新增[q轴锁轴频率响应](q_loop/README.md)：独立q轴注入、理想机械约束与速度给定隔离，另有原生“锁轴观测”页用于区分转矩、实际转速与未约束加速度。它仍是局部电气环路实验，速度环与自由转子实验尚待建立。

## 死区电流频谱

打开工作台“频域 → 死区电流频谱”，或运行 `open_pmsm_spectrum`。这是MATLAB原生图窗，可使用原生缩放、数据提示和导出；三页时域Scope继续保留。频域没有建立第二套电机模型，也没有新增补偿算法。

三相FFT与A相同步谐波放在同一张白底2×2图中，图片只保留主题、坐标和图例。波形较低的频点不等同于所有指标都改善；本例补偿后的某些次数仍可能增加。

## 当前固定口径

- 数据：现有“低速补偿”封存实验，600rpm、2μs演示死区，零死区/死区/已有基础补偿三组；同桥、同网格、同PI和工况。输入实验编号由示例summary.json指定，所有原档案先验证SHA256。
- 电流：真实三相电流obs_current_fast，原始1μs采样，约1MHz。使用同拍真实转子电角度，不使用50μs控制记录计算开关电流频谱。
- 窗口：三组共同的[120,200)ms，80000点，约四个50Hz电周期。按整数采样网格选择，右端不重复纳入。转速变化<1%、前后半窗基波幅值漂移<5%才接受；这属于明确的稳态筛查，不是对所有工况严格稳态的证明。
- FFT：去直流、周期Hann窗、单边峰值幅度，按窗相干增益校正。原始频点间隔12.5Hz，等效噪声带宽18.75Hz。显示采用4倍FFT补零，频率刻度间隔3.125Hz；它只细化同一有限记录的频谱显示，不提高真实分辨能力。未补零数组及谐波指标保留。图中只展示0—1000Hz，纵轴是dB re 1A，20log10(峰值安培/1A)。它不是功率谱密度，也不是噪声RMS。
- 谐波：直接按记录的真实电角度同时最小二乘拟合直流和1—19次sin/cos项，不插值、不平滑、不按峰值平移。幅度为峰值；百分比以本组同相基波为分母。FFT用于查看频域分布，拟合用于减小非整频点对谐波幅值读数的影响，两种口径不混用。
- “2—19次同步谐波比”=sqrt(sum(Ah²,h=2..19))/A1，不包含全部开关纹波、非同步成分及19次以上成分，不能简称全带宽THD。

当前A相5次谐波约0.147%/5.039%/1.622%，7次约0.083%/3.345%/1.463%；2—19次同步谐波比约0.193%/6.436%/3.563%。数值仅适用于本实验和窗口，全部三相结果见[指标表](deadtime_v1/harmonics.csv)。

## 复现与文件

```matlab
addpath('D:/simulink/modern/teaching')
open_pmsm_spectrum
% 从原档案重新生成派生材料，不运行仿真、不修改参数
export_pmsm_deadtime_spectrum
% 校验幅值、拒绝不适用输入，并进行两次逐点复现
validate_pmsm_spectrum
```

打开图窗时先核对原档案、算法指纹与派生文件；缓存有效就直接打开原生.fig。重新计算只写frequency/deadtime_v1，不写入已封存的实验文件夹。analysis.mat保留数值数组，spectrum.fig是可交互原生图窗，spectrum.png用于简洁宣传，harmonics.csv为指标，manifest.json记录来源、口径和指纹。图窗内临时缩放不会自动保存。

验收见[spectrum_validation.json](spectrum_validation.json)：已验证已知基波及5/7次谐波的幅值、DC和比值、非整频点拟合、非均匀采样/周期不足/明显变速/无基波的拒绝，以及真实三组数据两次计算逐点一致；原档案和模型指纹保持。验证不包括实板标定。

下一步：先结合时域Scope读清5/7次与过零畸变，再将相同分析入口扩展到采样噪声实验。闭环带宽与相位裕度需要单独设计激励和频响测量，不能从这张电流FFT直接推断。

原始1MHz电流记录的奈奎斯特频率为500kHz，本次不额外滤波或重采样；分析不能排除原记录中的混叠，也不能代替实板ADC频谱。若要研究高频开关纹波，需要单独约定记录带宽与抗混叠方式。


新增入口：[噪声与滤波频谱](噪声与滤波.md)，使用功率谱密度和噪声RMS口径，与本页确定性谐波分析分开。


显示补零后能看见更细的谱形和窗旁瓣；这些细节来自同一记录的DFT，不能把每个细小峰都当成新增谐波。要真正提高频率分辨能力，应采集更长且符合筛查条件的稳态记录。蓝/红为主色，零死区基准以中性灰虚线区分。样式更新及原科学数组/CSV保持核对见display_refresh_validation.json。
