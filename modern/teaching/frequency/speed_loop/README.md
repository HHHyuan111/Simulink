# 速度环阶跃基线

本轮完成速度环扫频前的阶跃与直流平台检查。保留原速度PI、转矩到iq换算、d/q电流内环及自由转子机械方程，不整定参数。后续已增加[三点频响试测](../speed_probe/README.md)，正式带宽与相位裕度验收尚未实施。

## 使用

在`D:/simulink/modern`下：

```matlab
addpath('teaching')
open_pmsm_speed_step       % 读取已验证档案
repeat_pmsm_speed_step     % 独立进程重跑，保留当前模型和参数
```

模型“频域分析”入口新增“扫频准备：速度环阶跃基线”。图窗菜单可选20或10rpm，四幅图共用时间轴，可同步缩放。此处读取固定参考档案，不代表当前工作区out。

## 连接与边界

- 临时给定进入原`Sum4`正端1；负端2保留原速度反馈，误差进入原速度PI。
- 原速度PI输出仍通过原转矩到iq换算进入q轴误差正端2，没有采用锁轴实验的iq直接注入。
- 原电机`dwm_dt`仍连接机械状态导数端口3，没有锁轴约束。记录电磁转矩、自由加速度及四个电机状态，核对原机械平衡。
- 沿用电流环实验的周期平均电压适配：原SVPWM的Tcm计算相电压，附共同1μs数值保持。只在独立进程临时替换桥输出，原SLX不保存。这不是详细开关桥、死区、编码器测速或实板验证。
- 记录网格50μs，速度PI保持和积分器编译执行周期均100μs。记录周期不能替代任务执行周期。
- 零外部负载，零初始速度；20ms施加阶跃，总长250ms，200～250ms计算平台跟踪和漂移。原控制参数冻结。

## 结果

| 指标 | 20rpm | 10rpm |
|---|---:|---:|
| 10%～90%上升时间 | 6.5ms | 6.5ms |
| ±2%稳定时间（相对阶跃时刻） | 45.7ms | 45.7ms |
| 超调 | 15.69% | 15.69% |
| 平台跟踪比 | ≈1 | ≈1 |
| 峰值真实iq | 0.3187A | 0.1594A |

两组归一化速度轨迹最大差约7.21×10⁻¹⁰(rad/s)/rpm。速度/电流PI无削顶，最终电压限幅残差接近数值精度；这证明本局部实验未明显进入限幅，不证明任意转速或负载下均线性。

## 如何读图

20ms后速度误差变正，速度PI要求正转矩，原换算生成正iq给定，电流内环跟踪后产生电磁转矩，使转子加速。超调后误差变负，iq和转矩短时反向，使速度回落。零负载平台中维持转速所需电流趋近零，这是当前理想机械条件的结果，不是实物空载电流预测。

当前理想速度反馈与真实速度几乎重合。图中重合不表示没有分别记录，也不把重合曲线人为错开。后续单独开启速度测量延迟后，才能观察反馈时间差及其闭环影响。

稳定时间按实际给定的±2%误差带计算，末尾至少保留25ms持续合格区间；若窗口不足，返回未取得稳定时间，不用截止时刻伪造合格。上升时间使用原始样点阈值交叉，不插值。阶跃指标不能直接换算成已验证Bode带宽或相位裕度。

## 可重复性

每次独立记录原始Timeseries、参考配置、模型与源码哈希、实际速度任务周期、分析和图形。发布时检查临时模块移除后原结构恢复，原SLX哈希保持。另做独立进程重跑，比较两种幅值全部12路信号的Time/Data及分析结果；界面检查曲线原始点、尺寸、颜色和联动缩放。验收摘要见`delivery_validation.json`。

## 下一步

基于本轮45.7ms稳定时间，先选择少量速度正弦试验点，等待时间至少覆盖此稳定尺度，同时用残差和前后半窗漂移验收，不仅按固定时间认定稳态。再确定正式扫频范围与测量周期；基线有效后仅增加一种可调速度反馈延迟。原PI整定、编码器测量组合与全工况性能继续后移。
