# 下一步：速度环独立实验方案

状态：阶跃与直流平台基线已实现，见[速度环阶跃基线](speed_loop/README.md)。20/10rpm两组得到约6.5ms上升时间、45.7ms稳定时间和15.7%超调。20/80/250Hz三点正弦试测已实现，见[试测结果](speed_probe/试测结果.md)，下一步在20～80Hz加密并补低频点。尚无正式速度环扫频及带宽/裕度验收数据。d轴、理想锁轴q轴实验是已完成的电流内环教学基线；本文件不把这些结果替代为速度环性能。

## 目标与连接

在原PMSM模型中释放q轴实验的理想锁轴约束，恢复原机械加速度、转矩和惯量路径。保留原d/q电流环及速度PI，独立进程临时向原速度误差正端注入小幅转速给定，负端沿用原速度反馈；q给定继续由原速度环输出生成，不能沿用q轴测试时的给定隔离。

第一阶段先建立理想平均电压下的单组速度环基线。第二阶段才增加一种可调的速度测量延迟对照，避免同时混入编码器量化、窗口测速、滤波、死区、保护与启停。原控制器与电机参数保持冻结。

## 需要明确的单位与时间

| 项目 | 本参考配置 | 需要记录或检查 |
|---|---|---|
| 电流/PWM控制周期 | 50 μs，20 kHz | 电流环实际执行采样率 |
| 速度PI周期 | 100 μs，10 kHz | 原速度保持及积分器编译采样率 |
| 速度给定、反馈、PI误差 | rpm | 不与机械rad/s混用 |
| 原速度PI输出 | N·m | 原转矩到iq给定换算仍参与闭环 |
| 电机机械速度与角度 | rad/s、rad | 真实机械轨迹、自由加速度、原机械方程 |
| 速度延迟演示值 | 待基线通过后确定 | 明确按速度任务周期计算，独立开关与大小；非实板标定 |

平均电压适配及其共同1 μs数值延迟需继续明确记录。所得速度环结果包含原电流内环和机械动态，不能仅用一个机械积分器的理论曲线充当整机验证。

## 稳态与扫频策略

先以零速附近的小幅参考建立局部实验，暂不加入额外摩擦或旋转工作点。速度范围、电流、转矩和电压需持续记录，检查没有触发已有电流/电压限幅。

采用独立的短阶跃或恒定给定平台检查直流跟踪增益、稳定等待时间和速度漂移，再据此选择逐频正弦的最低频率、等待周期和测量周期。不能把电流环的10 ms等待原样当成速度环的稳定时间。

低频扫频可能显著增加仿真耗时；先试跑少量频点评估成本，再确定正式频率范围。若没有覆盖低频或指标交点，保留原始结果并明确报告缺失，不外推带宽或裕度。直流平台测量与正弦测点分开记录，不伪造零频扫频点。

每个频点用两种小幅给定验证线性、残差和前后半窗漂移。观测包括真实转速、反馈转速、PI误差、原速度PI输出、iq给定/反馈、转矩、d轴电流及电压限制。
