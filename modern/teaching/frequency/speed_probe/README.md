# 速度环频响试测

本实验承接速度阶跃基线，先测20、80、250Hz三点，检查等待时间、线性和计算成本。尚未形成正式扫频验收，不报告插值带宽或相位裕度。

## 使用

在`D:/simulink/modern`下：

```matlab
addpath('teaching')
open_pmsm_speed_probe       % 查看归档三点试测
repeat_pmsm_speed_probe     % 独立进程重跑
```

也可从“频域分析→扫频准备：速度环阶跃基线→频响试测”进入。频响图的“时域对照”菜单选择频点，时域图的“给定幅值”菜单选择10/5rpm。白底原生四宫格共用时间轴，显示测量窗末尾三个周期的原始样点，不对齐相位、不重采样、不人为错开重合曲线。

## 实验条件

沿用阶跃实验的独立进程临时适配：原速度PI、原转矩到iq换算、原电流内环与自由转子；原SVPWM周期平均电压及共同1μs数值保持；零外部负载、零速附近正反向小幅摆动。没有加入死区、编码器测速或实板标定因素。

参考幅值10和5rpm，注入及记录网格50μs；原速度保持与积分器实际执行周期100μs。三点周期均为速度任务周期的整数倍。每点等待至少两个周期且不少于100ms，再测四个完整周期。总仿真长586ms/幅值。等待时间大于阶跃基线的45.7ms稳定尺度，但仍以残差和半窗漂移检查正弦稳态，不能仅靠等待时长宣称合格。

按原速度任务的100μs、零偏移执行时刻，同步拟合参考、真实速度、原PI输入误差和反馈，分别计算`T=真实/参考`与`L=反馈/误差`的基波复数比值。真实速度由原机械状态rad/s换算成rpm；误差正负端保持原连接。各频点直接显示测量值，图中不连接成假定的连续曲线。

初次试跑对全50μs记录拟合时，250Hz反馈的采样保持阶梯产生约3.93%相对残差，不能通过3%门槛，故未发布为有效档案。修正为原速度任务100μs网格分析后重新运行；原始记录和时域图仍保留全部50μs样点。这是离散速度环频响，不是重采样后的连续速度波形；没有插值、平滑或提高容差。

## 质量与可重复性

两种幅值分别检查：基波拟合相对残差及前后半窗漂移低于3%，参考=误差+反馈；原速度/电流PI和最终电压限制不削顶，机械平衡成立。幅值减半后T/L变化需低于2%。原结构恢复且SLX哈希保持后才更新最新有效档案。

每次记录原始12路Timeseries、参考参数、源码与模型哈希、实际编译速度周期、各点拟合和每幅值墙钟耗时。独立复跑比较24路Time/Data；分析比较排除墙钟耗时，其余数值保持严格一致。图形另核对全部频点、两种幅值的48条曲线及时间联动。验收摘要见`delivery_validation.json`，具体测值与后续范围见`试测结果.md`。

## 下一步

先依据实际三点结果选取低频、峰值和交越附近的正式频点，保证等待、测量周期和计算成本可控；完成后才计算覆盖充分的局部指标。正式基线通过后，再单独引入可调速度反馈延迟。原PI整定、全工况验证和保护/定位继续作为后续独立步骤。
