## 为什么要明确锁轴

q轴电流产生电磁转矩，会驱动机械转速；速度变化又影响反电动势、坐标变换与速度环给定。如果直接照搬d轴扫频，测到的可能是多个环路共同作用的结果。

第一版只研究零速约束下的q轴电气环路。它采用理想外部夹具约束，转速与转角保持初值零。电磁转矩仍由原电机方程计算，夹具反力矩与其平衡。这不是自由转子运动，也不包含实际夹具柔度、摩擦、热或锁轴硬件。

原模型本例Ld=Lq，零速时电压方程中的速度耦合项为零；d/q PI相同。因此两轴电气频响应接近，这是一项一致性自检。q轴与d轴的关键区别仍然存在：q轴有非零电磁转矩，需要外部机械约束才能保持零速。

## 三个原生查看入口

- Bode：闭环幅频、闭环相频、返回比增益、返回比相位。
- 时域对照：真实iq、反馈iq、PI误差、反馈−真实；给定是灰色，原反馈蓝色，增加1Ts红色。
- 锁轴观测：q轴电流、电磁转矩、机械转速、机械加速度。加速度页的蓝红曲线是原dwm_dt在**同一锁轴轨迹**上算出的未约束值，灰线是实际接入积分器的零加速度。它们不是两份自由转子仿真结果。

锁轴观测应呈现“电流与转矩非零，转速与实际加速度为零”。不能把转速零理解为没有转矩。

## 验收与范围

除原有幅值减半、稳态漂移、正弦拟合残差、无电压限幅检查外，还检查d轴电流近零、转速与角度为零、实际加速度为零、原速度环给定为零，且非零电磁转矩与原未约束加速度满足Te=J·dwm_dt（此固定工况负载和摩擦为零）。只有所有频点通过且指标交点被覆盖，才发布最近有效档案。

本实验给出局部零速锁轴q轴频响、带宽和经典相位裕度估计，不代表自由转子、旋转工况或实板裕度。原始MAT与逐次档案在本机保存；源码、简洁样例和验收摘要可纳入Git。新检出工程执行复跑命令生成自己的完整数据。

本轮验收：两组、两种幅值共四次运行，40路原始记录Time/Data及分析结果在独立进程严格复现；13个频点的电流与机械两页共260条绘图曲线逐点核对，原d轴130条时域曲线另行回归。菜单、时间联动、当前自定义参数与工作区保留均通过。见 `delivery_validation.json`。

在本固定条件下，q/d闭环响应最大差异约1.4×10⁻¹⁵，返回比差异约9.0×10⁻¹⁴，与Ld=Lq及相同PI的预期一致。原反馈及增加1Ts两组的局部相位裕度分别约77.9°、56.2°；这些指标仅属于上述平均电压、理想锁轴工况。
