# 看懂死区

教学样板三步：在一个原生Scope中切换“门极与电压”“电流与转矩”“补偿作用”，把开关过程、闭环响应和补偿机制联系起来。沿用已有详细逆变桥，不更换补偿算法或PI，不自动覆盖当前参数。

## 从模型打开

关闭旧的观测选择窗口，双击模型顶部“时域观测”→“死区原理”。教学窗口提供“功率设置”和三个观测按钮，切换同一专题Scope的观察内容，任意时刻只保留一个专题Scope；切换会清除旧图，请重新运行模型，避免将旧数据配上新标题。仿真运行中须先停止再切换。

前两步先开启门极死区，关闭补偿和其他附加因素，可用2μs演示值；这不是实板测量值。第三步开启已有补偿，先将补偿时间设为相同2μs，再独立调整。研究零死区对照时保持详细桥开启，仅把死区时间改为0。不要把关闭详细桥后的变化全部归因于死区。

## 同轴对照

Scope采用白底2×2、统一1120×800窗口，默认显示100μs（20kHz下两个PWM周期），四格共用原始仿真时间。

| 位置 | 同一坐标轴中的曲线 | 观察目的 |
|---|---|---|
| 左上 | A相上管请求（蓝虚线）、实际（红实线） | 看开通延后与立即关断 |
| 右上 | A相下管请求（蓝虚线）、实际（红实线） | 与上管同步看两管关断间隔 |
| 左下 | A相真实电流 | 判断此时电流方向 |
| 右下 | 理想桥臂参考（蓝虚线）、实际桥臂极点电压（红实线） | 看门极差异是否以及怎样形成电压差异 |

理想电压参考由本次请求门极与母线电压计算：互补有效请求下`Vpole_ref=Vdc×AH_requested`。它与实际波形来自同一次运行，不是另一次理想闭环仿真，不存在跨次转子位置累计差。实际电压直接取现有详细桥极点电压诊断。两者都不是电机相对浮动中性点的相电压。

详细桥未启用时，右下两条曲线为NaN，避免显示未选中支路的电压。电流和门极仍有原始记录，但不能把这一状态作为详细桥死区实验。

## 阅读顺序

放大一个请求开通沿，比较实际开通时刻；同时检查另一只管子的状态，再结合电流方向看桥臂电压。并非每个死区间隔都表现为同样的电压缺口，续流路径也参与决定电压。短于死区的请求脉冲可能没有实际开通，不能强行给每个请求沿配一个实际沿。

同单位、同物理定义的比较量叠在同轴；不同单位的量分格但同步时间。不对曲线移相、插值或平滑。需要更细观察时使用Scope原生缩放与游标。

## 电流与转矩

默认显示20ms，以1μs从原信号源采样，不把50μs控制日志插值成密集曲线。四格共用时间，比较量直接叠加：

| 位置 | 同轴曲线 |
|---|---|
| 左上 | 真实A/B/C三相电流，蓝/红/灰 |
| 右上 | iq给定（蓝虚线）、实际（红实线） |
| 左下 | id给定（蓝虚线）、实际（红实线） |
| 右下 | 负载转矩（蓝虚线）、电磁转矩（红实线） |

id/iq实际值直接来自原电机状态，给定及转矩均取现有日志同一信号源。此页用于研究当前运行内的跟踪与纹波；给定/实际差异不全由死区造成，转矩与负载差异还包含加速度和机械损耗。需配合同桥0/2μs受控实验进行死区归因，不能仅看一条曲线下结论。

本页没有把两次运行的ABC电流按绝对时间强行叠加。跨次闭环运行的转子角度可能不同；跨次波形形状对照通过下述“补偿前后对比”查看。

## 补偿作用

默认20ms窗口，按现有控制记录周期（默认50μs）采样；用于看补偿更新与iq跟踪，高频电流纹波仍在1μs的“电流与转矩”预设查看。

| 位置 | 曲线与目的 |
|---|---|
| 左上 | A相测量电流（蓝）与正/负滞环阈值（灰虚线）同轴，判断何时触发极性更新 |
| 右上 | 补偿模块实际记录的A相极性−1/0/+1，独立状态坐标 |
| 左下 | 补偿模块实际记录的A相电压修正，单位V |
| 右下 | iq给定（蓝虚线）与真实iq（红实线）同轴 |

极性和补偿电压直接取现有`obs_dead_comp`诊断，未另外计算一套极性算法作为显示输出。阈值来自同一个`dead_comp_cfg(4)`，跟随现有功率设置。比较量同轴，不把无量纲极性与安培电流强行当成同单位叠加。

补偿关闭时，现有诊断输出为0；极性图为0不表示电流没有方向，而表示本次补偿没有运行。补偿开启后，阈值区间内保持上一次极性，初始化时可以为0。A相修正还减去了三相共同均值，不能只用A相极性直接乘常数解释所有电压台阶；这也不是真实电压误差。

本页解释“补偿怎样介入”。开启同一补偿设置后，回到“电流与转矩”预设重新运行，观察三相电流、dq跟踪及转矩；最终改善程度仍需同工况、同桥的补偿关/开对照和稳态指标，不用当前短时观测证明所有工况改善。

## 当前验证范围与后续

独立批处理检查理想桥、详细桥0/2μs各1.5ms：原日志不变、Scope源信号对应、62.5ns细网格开通间隔、无重叠、门极关断、关闭详细桥后的电压空值、原结构恢复及实验封装正常/异常恢复。结果见`../layout/appearance/deadtime_scope_validation.json`。短时检查不代替稳态补偿或完整启停验证。

“电流与转矩”另以同一详细桥0/2μs、600rpm给定各3ms检查：添加观测前后原始日志一致、9条Scope曲线与原始源值对应、模式切换仅保留一个专题Scope、正常/异常恢复保留所选模式。结果见`../layout/appearance/deadtime_effects_scope_validation.json`。这些检查验证观测功能，仍不代替稳态死区畸变评价。

“补偿作用”另检查补偿关闭、匹配2μs补偿及零幅值补偿三组各4ms：原日志一致、7条Scope曲线对应原来源、极性诊断符合现有滞环规则、相电压修正符合现有三相减均值公式、零幅值物理信号回归、三个预设切换与正常/异常恢复。结果见`../layout/appearance/deadtime_comp_scope_validation.json`。不新增补偿算法，不宣称短时检查完成稳态效果验收。

## 补偿前后对比

教学窗口新增一个“补偿前后对比”按钮，直接读取已保存的600rpm、24V、0.207N·m负载、2μs死区实验。它不是本次运行的输出，不会自动运行仿真，也不会修改当前设置。

白底2×3主题图窗中，上排A/B/C相分别叠加补偿前（蓝）与补偿后（红）；下排依次为A相电流频谱、A相低次谐波、电磁转矩与负载。三相电流使用同一个完整真实电角周期，各自保留原始1μs样本，不插值、不按峰值移相；三格电角度缩放联动。此周期约168～188ms，转矩则使用180～200ms时间窗口。电角度、频率、次数与时间横轴各有明确单位，不强行同步不同物理含义的横轴。

频谱与谐波复用`pmsm_current_spectrum`，取120～200ms共80000个1μs原始电流/角度样本，约四个电周期。频谱去直流、周期Hann窗、单边峰值幅度，以dB re 1A显示0～1000Hz；4倍零填充只加密显示，不提高12.5Hz频率分辨率。低次谐波以真实电角度联合拟合直流及1～19次分量，显示2～19次占各自基波的百分比。只展示A相频域作为代表，三相时域仍完整保留；不能把低次谐波比例当成全带宽THD。该工况A相5次约5.04%→1.62%，7次约3.34%→1.46%，并非所有次数均降低。

图窗菜单“指标与工况”可查看两个指标：iq跟踪RMS和转矩标准差。指标按180～200ms内原始50μs控制记录计算，本工况分别约从0.064983A降至0.027954A、0.002768N·m降至0.001191N·m；不能据此声称所有峰值、PWM高频纹波或所有工况都改善，也不是THD。

本次复用已有归档，未重新运行物理实验。校验档案完整性、模型指纹、工况和指标，并逐点核对9条原始绘图曲线、2条频谱与2组谐波柱、菜单与按钮、联动缩放、当前模型与参数保持、档案只读；结果见`deadtime_lesson/comparison_validation.json`。频谱方法另含已知基波/谐波及非整频点的合成信号检查与重复分析检查，见`frequency/spectrum_validation.json`。下一步先体验这条教学路径，再依据反馈简化操作，不继续堆叠算法或板载因素。
