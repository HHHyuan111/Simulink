# 固定参考与开关操作

本轮只完善基线与操作规则，保留主模型、原控制算法、PI数值和布局。模型仍是教学与算法研究版本，实板参数尚未全部校准。

## 先分清两个操作

| 操作 | 改变什么 | 用途 |
| --- | --- | --- |
| 关闭附加因素 / 教学预设 / 实板参考 | 开关与部分死区值；其他当前参数保留 | 快速准备对照实验 |
| 恢复固定参考（整套） | 恢复冻结的工作区、开关和幅值、给定与负载、PI、初态、日志及运行设置 | 回到同一个确定起点 |

参数窗口入口：

```matlab
cd('D:/simulink/modern')
addpath('teaching')
open_pmsm_settings
```

“恢复固定参考（整套）”会直接应用到当前已停止的模型，并备份原设置到`modern/.build/reference_backups`。它不自动运行、不保存覆盖SLX；表格中尚未应用的修改会被重新读取的参考值替换。

脚本等价入口：

```matlab
pmsm_reference('verify');    % 核对模型、脚本与档案指纹
pmsm_reference('restore');   % 完整恢复，更新检查通过才返回
out=sim('PMSM_FOC_R2026a');   % 按参考的1秒工况运行
```

恢复要求仿真停止、Fast Restart关闭。参数恢复不会撤销连线、算法代码或布局修改；检测到这类修改会拒绝恢复，以免把不同模型误称为同一基线。主SLX或记录的脚本版本改变后，也需重新验证并建立新版本基线。

## 开关阅读顺序

所有开关在停止仿真后修改。先固定其他条件，改变一项或一组必要依赖，运行后比较，再恢复参考。所谓单因素实验允许启用其必要模式，例如低侧窗口必须在真实时序模式下比较；比较两组都应使用相同的时序背景。

| 分组 | 开关 | 作用位置 / 配套参数 | 先观察什么 |
| --- | --- | --- | --- |
| 时序 | 速度分频 | 速度任务；周期倍数 | 执行周期、速度和电流 |
| 时序 | 整周期输出延迟 | 调制输出；延迟拍数 | 请求量与实际生效量 |
| 时序 | 真实时序 | ADC触发至CCR更新；触发/计算时间和更新边界 | 单周期事件和任务相位 |
| 时序 | 低侧窗口 | ADC有效性；导通稳定等待 | 有效标志、真值与测量值 |
| 时序 | 无效样本保持 | 无效样本处理策略 | 控制器实际收到的电流 |
| 电流 | 零偏 / 增益误差 | 三相测量入口；ABC偏置/比例 | 真值、测量值及误差 |
| 电流 | 噪声 | 测量入口；RMS和种子 | 噪声、三相与dq电流 |
| 电流 | ADC量化与饱和 | ADC等效输出；位数和全跨度 | 原始码、量化误差及饱和 |
| 电流 | 模拟低通 / 数字低通 | 采样前 / 采样后；各自截止参数 | 滤波前后幅值与滞后 |
| 电流 | 整周期采样延迟 | 测量传递；延迟拍数 | 测量发生与控制器使用时刻 |
| 角度 | 偏置 / 量化 / 延迟 | 测量角；电角偏置/步长/拍数 | 最短角差、dq电流 |
| 功率 | 平均死区压降 | 旧平均压降模型；时间和平滑带 | 平均压降与电流 |
| 功率 | 器件导通压降 | 当前桥模式；Ron和Vf | 相电压、三相电流 |
| 功率 | 门极死区 | 实际门极与续流；死区时间 | 请求/实际门极及三相电流 |
| 控制 | 死区补偿 | 最终限压前；补偿时间与极性滞环 | 补偿电压、三相/dq电流及转矩 |

逐项关闭路径、开启行为、参数键、依赖和局限由`pmsm_switch_catalog.m`统一定义。它也供应用前的依赖检查使用，避免说明与代码各写一套规则。

## 必须遵守的组合关系

- 真实时序与旧整周期输出延迟、旧整周期采样延迟互斥。
- 低侧窗口需要真实时序；无效样本保持需要低侧窗口。
- 门极死区与旧平均死区压降互斥；补偿需要门极死区。
- 门极桥当前要求Ld=Lq；有效时序还要满足采样/计算预算与事件网格约束。

应用前先检查开关依赖，数值约束再由参数检查及模型更新验证，失败回滚。依赖合法不代表工况一定稳定，更不代表已与实板一致。
