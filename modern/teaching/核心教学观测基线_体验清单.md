# 核心教学观测基线：体验清单

本轮只整理三个核心专题，原FOC、PI和主SLX保留。先从模型顶部“时域观测”进入；三个主题排在最前面。新菜单未显示时，关闭旧的“时域观测”窗口再打开。归档图是原生MATLAB图窗，当前运行仍使用原生Simulink Scope。

## 建议用15分钟体验

| 顺序 | 操作 | 希望你重点反馈 |
|---|---|---|
| 1 | 时域观测 → 死区与补偿 → 补偿前后对比 | 三相电流、频谱、谐波和转矩同屏，是否能一眼找到前后差异？六格是否合适？ |
| 2 | 死区与补偿 → 门极与电压 / 电流与转矩 / 补偿作用 | 三个原生Scope预设的阅读顺序是否清楚？注意切换后需重新运行，旧缓冲不回放。 |
| 3 | 时域观测 → 速度控制 → 阶跃响应、正弦跟踪 | 转速、iq、转矩、误差放一起，是否容易串起内外环关系？试试缩放一格，看其他格是否同步。 |
| 4 | 时域观测 → 电流采样 → 噪声与滤波对比 | 能否区分物理电流、反馈、噪声分量、噪声PSD及闭环误差？滤波代价是否直观？ |
| 5 | 电流采样 → 当前采样链；速度控制 → 当前控制响应 | 打开后在模型点运行，检查同轴对比、图例、时间缩放、窗口大小与颜色是否舒服。 |

前面三项归档查看无需重跑仿真。当前Scope需要当前模型运行；参数设置只在你实际修改并确认时变化。死区专题要求详细桥/死区与补偿配置正确，当前模型任意参数运行不一定复现固定归档结果，不要为了让画面相同盲目恢复参数。

## 三个容易误读的地方

1. 当前Scope与“已保存实验”是两个数据来源。你修改当前参数后，归档对比不会自动变化。
2. 死区跨次三相电流按真实电角度比较；频谱、转矩各用明确稳态窗口，不强行共用所有横轴。
3. 滤波的噪声分量下降不代表真实电流与转矩全面改善；q轴误差使用每一组自己的给定。

你的反馈可以只按三个问题来：**哪里难找、哪里难懂、哪里看着不舒服。** 先打磨这三个专题，再增加新算法或新因素。
