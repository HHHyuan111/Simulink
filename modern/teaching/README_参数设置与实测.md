# 参数设置、教学演示与实测替换

2026-10-16量程说明更正：当前计算模型的`adc_span`是单侧双极量程，默认82.5表示±82.5A、全跨度165A；量化步长为`2*adc_span/2^adc_bits`。当前参数编辑窗口已更正显示，历史接口中的“全跨度”文字不能按字面使用。模型数值未改变，也未由此完成实板量程校准。`obs_adc_codes`为顺序采样的固定12bit/165A跨度参考码，不跟随`adc_bits`与`adc_span`，不能当成可配置ADC量化支路的实际码值；实际送入控制器的电流看`log_iabc_adc`和`log_iabc_meas`。详细核对见[信号链检查](../signal_chain/README.md)。

在modern目录运行：

```matlab
addpath('teaching'); open_pmsm_settings
```

统一窗口按时序、采样、角度、功率、电机与工况、负载分组；原画布各“设置”入口继续可用。表格可修改当前值、来源/测量记录、校准状态，其他列提供单位和测量方法。点击“应用到模型”才改变当前模型；会备份旧配置并做模型更新检查，失败则回滚。应用不会自动运行仿真或保存SLX；保存模型后参数和来源一并持久化。来源匹配到相同参数值才显示，避免模型外部改值后仍误标已校准。

开关填写on/off；数值填写数字或一行向量，例如`[0.05 -0.03 0]`。不要输入脚本表达式。时序更新方式保留原两个选项文字。原局部设置中的内部表达式不在表格开放编辑。JSON保存/载入的是表格完整档案，载入后可预览，再应用；档案包括单位、来源和测量方法。

## 固定参考与三类局部预设

窗口新增“恢复固定参考（整套）”：恢复冻结的参数、PI、初态、给定/负载及运行设置，并备份原状态；不自动运行或保存SLX。使用步骤、版本核对和开关规则见[固定参考与开关操作](README_固定参考与开关.md)。下述三类预设保留为局部快捷设置，不能代替整套恢复。

- 关闭附加因素（原“理想参考”）：关闭现有非理想因素，保留当前电机参数与算法解耦；并非把电机重置为早期演示电机。
- 教学演示：真实PWM/ADC时序和门极死区开启，死区/补偿时间均设2μs，补偿默认关闭，便于逐步开启比较。其他因素关闭，先隔离主效应。
- 实板配置参考：真实时序和门极死区开启，死区/补偿时间为固件编程0.5μs，补偿关闭。触发相位、计算耗时、器件参数等仍有待实测项，不能叫已校准实板模型。

预设只覆盖开关及上述死区值，其他幅值/电机参数沿用当前值；应用前可查看全表。不包含自动辨识，不以仿真优化值冒充测量值。参数来源与校准状态由用户填写，建议包含日期、温度、工作电流、测量设备与固件版本。

## 电机参数和依赖关系

Rs、Ld/Lq、磁链、极对数、惯量、粘性摩擦、母线、电流指令上限、给定转速、PWM频率和速度任务周期可直接编辑。修改写入原Model Workspace代码末尾的用户覆盖区；原9个PI增益不变。同步更新Kt、电流/PWM周期、速度环转矩限幅和轴电压限幅，避免只改基础值而依赖量未更新。详细续流桥当前要求Ld=Lq。

当前电流任务与PWM同频，不能在表格中独立配置两者；修改频率还必须满足触发/转换/计算预算及事件网格约束。速度分频开关开启时，会覆盖基本速度任务周期。F表示现有粘性摩擦，不包含静摩擦、齿槽转矩。负载仍是Step块的前值、后值和时间。8A是iq指令上限，主动过流保护未实现。

当前顺序ADC的采样孔径1.1875μs、每通道槽1.5μs，以及CCR的4000级量化仍固定在固件快照值；统一窗口暂不开放这些内部常量。更换ADC时钟/采样周期或PWM定时器分辨率时需要后续同步改动。模型有参数校验不代表任意组合都能代表真实硬件。

## 主要实测对应

| 因素 | 测量或配置来源 | 填入位置 | 对照观测 |
|---|---|---|---|
| 任务频率、更新方式 | TIM/ADC配置、GPIO时序 | 时序设置，电机与工况 | 时序观测 |
| 触发/同步/计算延迟 | PWM事件、ADC触发、JEOS、CCR写入时间差 | 时序设置（μs） | ADC/PWM事件 |
| 电流偏置/增益 | 零电流均值、已知正负电流标定 | 采样设置（ABC） | 真值与测量值 |
| 噪声与滤波 | 固定工况统计、前端扫频/阶跃 | 采样设置 | 误差、滤波前后 |
| 角度偏差/量化/延迟 | 零位定位、编码器计数、采集到使用时刻 | 角度设置 | 真角度与测量角度 |
| 死区及导通压降 | 门源波形、工作电流/温度下器件压降 | 功率设置 | 实际门极、续流、三相电流 |
| 电阻/电感/磁链 | 记录温度、接法、幅值/RMS约定的辨识 | 电机与工况 | 电流、转矩、速度 |
| 惯量/摩擦/负载 | 转矩与加速度、不同速度空载损耗 | 电机与工况、负载 | 速度、转矩 |

数值步长、随机种子、续流近零带属于数值/复现参数，不当作板载可测物理量。母线目前恒定；器件输出电容、反向恢复、独立最小脉宽、位置传感器完整算法、主动保护尚未实现，未提供无作用的假开关。

## 三相电流演示

```matlab
addpath('deadtime'); run_deadtime_demo             % 2μs，600rpm，0.207N·m
run_deadtime_demo(2,300,0.08,0.14)                 % 低速轻载
run_deadtime_demo(0.5,600,0.207,0.08)              % 固件编程死区参考
```

输出到`deadtime/report_demo`，每次运行会更新；本轮固定报告另存于`report_teaching`和`report_low_speed`。三组统一PI、负载、速度及稳态初值；区别仅死区和补偿。三相全貌与A相过零三列等坐标，另有逐相叠加/差值图。电流为PWM周期平均，THD统计末两个电周期的2—25次谐波，不含开关频带。脚本恢复运行前设置，不保存覆盖模型。

展示更明显的差别使用公开标注的2μs参数，不改变PI或人为处理某一组电流。补偿时间与门极死区独立可调，误差不保证在所有工况都改善，需看实际报告。

本轮结果：600rpm/0.207N·m的低次THD为0.186% → 6.528% → 4.110%；300rpm/0.08N·m为0.608% → 11.110% → 16.044%（依次无死区、死区无补偿、死区有补偿）。后者特意保留为当前基础补偿在放大死区、轻载工况的边界案例，不能以“补偿开了就一定更好”理解。后续可单独对照补偿幅值、过零滞环和采样到生效的延迟，不在本轮改算法或PI掩盖结果。
