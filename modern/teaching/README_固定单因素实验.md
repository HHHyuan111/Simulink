# 固定单因素实验

本批完成“固定参考 → 单因素对照 → 查看结果 → 恢复参考”的流程。沿用当前主SLX及`reference_v1`，不改PI、控制算法或布局，也不修改已冻结的参考档案。

## 从这里开始

```matlab
cd('D:/simulink/modern')
addpath('teaching')
open_pmsm_experiments
```

这是固定实验入口，原参数窗口继续用于自由配置。先点击“恢复固定参考（整套）”，选择实验和因素大小，再点击“运行参考与因素对照”。完成后分别查看三相电流和闭环响应。

每组默认运行0.2秒；末10ms用于电流局部图，末20ms用于指标统计，不假定该区间已经严格稳态。两组使用相同PI、3000rpm给定、24V母线、负载及零初态；唯一差异是对应开关和幅值。全部因素幅值均作为演示值，不标为实测。

实验要求当前模型位于完整固定参考。若已经手动改了参数，会提示先恢复，不静默覆盖。未保存的算法/连线改动和版本不符仍由参考检查拒绝。实验通过SimulationInput临时覆盖，结束后恢复参考，不保存覆盖主SLX。运行中不热切换因素。

## 第一批：测量链三项实验

| 实验 | 默认因素大小 | 先回答的问题 |
| --- | --- | --- |
| 电流零偏 | ABC分别为`[0.05 -0.03 0] A` | 控制器反馈接近给定时，真实电流是否也正确？ |
| 采样噪声 | 每相`0.02 A RMS`，使用参考中的固定种子 | 噪声如何传入控制器，又如何影响实际电流和转矩？ |
| 采样延迟 | `1 × 50μs` | 相同电流晚一拍进入控制器，会怎样改变闭环？ |

零偏允许ABC三个值各在±2A内，噪声允许0—2A RMS，延迟允许1—5拍。这些是本批入口的参数范围，不是稳定性或硬件额定范围。暂不组合其他因素；滤波、真实事件时序和死区等保留现有入口，后续再纳入固定场景。

脚本方式：

```matlab
pmsm_reference('restore')
r=run_pmsm_experiment('current_bias');
r=run_pmsm_experiment('current_noise',0.05);
r=run_pmsm_experiment('sample_delay',2);
% 可选第三个参数为两组共同的运行时长，0.05—1秒，须落在控制周期上。
r=run_pmsm_experiment('current_bias',[0.1 -0.1 0],0.3);
pmsm_experiment_verify(r.folder);
```

`pmsm_experiment_plan`可以只生成计划、不运行模型；输入只接受有限数值或数值向量，不执行表达式。

## 两张图怎么读

`comparison.png`：三行分别为A/B/C相，左边固定参考，右边因素开启。同相使用一致的时间窗和纵轴。灰色为1μs记录的电机真实电流，彩色为控制采样记录的阶梯显示；不平滑波形，不混用采样率。

`response.png`：依次观察速度、转矩、d轴电流、q轴电流、三相测量误差，以及因素引起的实际电流变化。dq图同时保留真实状态与控制器反馈，避免只用反馈误差判断控制效果。

最后两幅的含义不同：

- 测量误差：同一实验内的测量值减同时刻真值，说明测量链的影响。
- 实际电流变化：因素组真值减参考组真值，说明闭环轨迹的变化。

指标包含ABC测量误差的均值/RMS、速度跟踪误差、q轴反馈及真实跟踪误差、转矩标准差、真实iq峰值和电压饱和比例。当前报告不计算THD，也不把短窗口的转矩标准差全部归因于某个谐波。

## 每次结果独立保存

每次创建新的`experiments/runs/<时间_场景_唯一编号>`目录，不覆盖上一组实验：

- `record.json`：状态、实际因素、完整两组参数、指标、基线/模型/脚本指纹及文件清单。
- `reference_state.json`、`reference_manifest.json`、`plan.json`：冻结状态、基线身份和本次完整实验计划。
- `reference.mat`、`factor.mat`：早期结果保留16路观测；第二批入口起保留21路，增加真实/测量角度、最短角误差以及请求/实际门极。控制记录及1μs真实三相电流完整保留，高频事件/门极诊断只留尾部4000点。
- `comparison.png`、`response.png`、`metrics.csv`：统一图像和指标。

`latest.json`仅在完整成功后更新。切换实验或修改大小会清除窗口关联的旧结果；查看图像前验证档案指纹，防止错误图像或未完成实验被当作本次结果。失败记录保留原因和恢复状态。

逐次结果是本地生成数据，已加入Git忽略；后续可挑选固定示例图进入仓库。

## 第二批已完成：滤波、角度与死区

2026-10-13增加`digital_filter`、`angle_bias`、`gate_deadtime`三项。仍然每组只打开一个用户开关，保留相同PI、给定、负载和初态；增加“5 查看因素机制”。默认分别为1500Hz、5°电角度、2μs，均为可修改的演示值。

门极死区开启后自动使用详细桥和62.5ns步长，理想参考使用原1μs步长。这个场景适合观察开通延迟、关断空白和整体闭环变化；两组电流差还含数值及桥路径变化，不能全部归因为死区，指标变小也不表示死区提高性能。

具体操作、三张报告及边界见[第二批固定实验](README_固定实验第二批.md)。新增验证结果见`experiment_stage2_validation.json`；当前简洁展示图校验见`experiment_gallery_validation.json`，早期版式记录保存在`experiment_stage2_render_validation.json`。三项第一批实验的原16路信号与既有档案逐点一致；主SLX、PI、布局及固定参考未改变。

## 新增：死区配对

第七项`gate_deadtime_pair`让两组均启用同一详细桥与62.5ns步长，只改变门极死区0/设定值。电流以真实转子电角度对齐，启动累计角度差单独成页。它的零死区组属于详细桥，不是所有附加因素关闭的理想参考。见[死区配对实验](README_死区配对实验.md)。原六项场景保持原定义。

## 新增：低速补偿

第八项`low_speed_compensation`固定600rpm和原负载，使用零死区、死区、已有补偿三组；相邻组只改变死区值或补偿开关。共用同一详细桥、步长、PI与零初态，增加实际补偿诊断。见[低速死区与补偿](README_低速死区与补偿.md)。

## 新增：噪声与滤波受控组合

第九项`noise_filter`比较“无噪声无滤波 / 固定噪声 / 同一噪声加滤波”。噪声RMS和截止频率分别设置，沿用已有模块与PI。报告分开显示噪声衰减、总测量误差和真实闭环响应，不能把测量变平滑直接称为控制改善。见[噪声与滤波](README_噪声与滤波.md)。它是受控组合实验，不把两个已开启因素称为单一物理因素。

## 新增：真实时序事件观测

第十项`timing_events`建立已有ADC/控制/CCR/PWM事件时间线，默认每组50ms，计算耗时可设置。记录各相孔径结束采样、JEOS、快慢任务、写入和实际输出生效，显示三页简洁报告。它是已有模式观测，切换同时含网格、载波及采样更新规则差别，不作为纯延迟性能对照。见[真实时序实验](README_真实时序实验.md)。

## 新增：CCR更新边界

第十一项`timing_deadline`在同一真实事件架构下，共用10µs教学触发、62.5ns网格和双更新，仅改变计算耗时5/10.5/11µs。比较赶上、恰逢、错过更新机会的事件和实际生效指令，默认每组50ms。中间耗时固定边界，前后可按网格调整；主模型、PI和参考不改，详见[CCR更新边界](README_CCR更新边界.md)。

## 新增：低侧采样窗口与无效样本

第十二项`sampling_window`在同一真实时序与工况下，对照窗口关闭、无效置零、无效保持上次有效样本。只组合原有开关，不引入电流重构算法；触发相位和稳定等待可调，默认50ms/组，保存24路/组。默认复现、参数回归、旧档案兼容和完整参考保持通过，见[低侧采样窗口](README_低侧采样窗口.md)。

## 新增：编码器角度

第十三项`encoder_angle`在同一真实时序下比较理想角度、整数计数角度、计数加延迟。每转计数、延迟拍数及电角零位有独立输入；默认零位0时相邻组只启用计数路径或延迟，非零零位时第一、二组差异同时包含零位。原模型临时接入可展开基础块，结束恢复原连接；三组27路/组，速度仍沿用原反馈。操作、81路复现与来源核对见[编码器角度](README_编码器角度.md)。

## 新增：计数测速观测

第十四项`encoder_speed`是一次仿真内三个观察器的并行对照，默认窗口1/2/8拍，不是三组独立闭环。每机械转计数、窗口和长窗可设置，估计速度未接入PI。报告将计数量化与窗口平均误差分开，保留31路原始信号及逐样本来源；只有一个`reference.mat`。操作与验证范围见[计数测速](README_计数测速.md)。

## 新增：测速反馈选择

第十五项`speed_feedback`比较原速度、窗口测速、长窗测速三组独立闭环。只改变速度来源及窗口，原速度任务、PI与角度路径保持，速度滤波关闭；历史不足用零并标无效。默认50ms时iq给定达到8A限幅，保留实际现象；100ms参数工况继续观察限幅退出后的影响。每组32路，实际PI输入来源有单独记录，见[测速反馈](README_测速反馈.md)。

## 新增：速度滤波

第十六项`speed_filter`固定机械计数及差分窗口，比较无速度低通/加速度低通两组，只有滤波开关不同；默认100ms，以继续观察限幅退出后的响应。输入为计数、整数窗口和截止频率，默认[10000,2,200]；33路/组，20kHz滤波、原10kHz速度PI，沿用固件递推形式。将量化贡献、滤波动态及窗口平均误差分开，见[速度滤波](README_速度滤波.md)。
