# 噪声与滤波

本轮在已有噪声源和一阶数字低通之上，建立固定三组测量链实验。沿用原模型、PI、电机、3000rpm给定、24V母线、0.207N·m负载、零初态及1μs求解步长；其余附加因素关闭。这里完善实验框架，没有新增滤波控制算法。

| 组别 | 噪声 | 数字滤波 |
| --- | --- | --- |
| 参考 | 关闭 | 关闭 |
| 噪声 | 开启 | 关闭 |
| 滤波 | 同一噪声序列 | 开启 |

相邻组只改变`noise_on`、`filter_on`。三组噪声RMS和滤波频率设置保持相同，关闭时旁路；两组带噪声实验使用相同种子9474、9475、9476。各组真实电流随各自闭环运动变化，因此“同一噪声”不表示三组物理电流被强制一致。

## 三页报告

“噪声与滤波”：每列一组，每行一相，显示末10ms真实电流与反馈。真实电流按1μs记录，反馈按50μs记录并以阶梯显示；同相纵轴相同。原始电流自身包含PWM纹波，不能把全部纹波叫采样噪声。

“闭环响应”：末20ms的真实id、真实iq、转矩与转速。三组iq给定随各自闭环变化，图中q轴命令只显示滤波组；指标按各组自己的给定计算。观察真实电机状态，而不只看反馈是否接近给定。

“滤波观测”：A相注入噪声与滤后噪声分量、滤波组三相测量总误差、滤波组d轴真值与反馈，以及现有离散滤波器的解析幅相响应。幅相曲线是由系数计算的结果，不是实测或闭环辨识。

## 区分三种量

现有滤波器位于abc采样后、Clarke/Park前，零初态。递推为`y[k]=(1−α)x[k]+αy[k−1]`，其中`α=exp(−2πfcTs)`，控制周期Ts=50μs。

在滤波组自身的数据上，输入为`真实电流+注入噪声`。线性滤波可以分成`H(真实电流)+H(注入噪声)`；已有滤波输出与该分解的和需要数值一致。

- 滤后噪声分量：`H(注入噪声)`，反映噪声被衰减多少。
- 滤波确定性误差：`H(本组真实电流)−本组真实电流`，包含幅值和相位变化，也包含对真实PWM纹波的滤除，不全部叫纯延迟。
- 总测量误差：`反馈−同时刻本组真实电流`，等于上述两项之和。

噪声分量变小，总测量误差仍可能增大。控制器使用滤波反馈进行Park变换与PI控制，反馈接近目标也不保证真实id接近目标。记录这两种结果正是本实验的教学目的；不为了改善图片而平移、平滑原始物理曲线或改PI。

该线性分解隔离的是注入项通过滤波的直接贡献，不等于整个闭环的噪声影响。噪声经控制器改变物理电流的间接影响仍包含在本组真实电流中，需要结合闭环响应页判断。

特别注意：噪声RMS设为0时，前两组应完全相同，但第三组仍启用滤波，仍有确定性影响。第三组应与相同频率、无噪声的“数字滤波”单独实验一致，不能要求零噪声时三组全部重合。

## 默认工况结果

默认0.02A RMS、1500Hz、3000rpm，统计180—200ms。A相实际注入噪声RMS为0.01925A，滤后噪声分量RMS为0.01002A，下降约48%；同时总测量误差RMS约0.47188A，主要来自滤波确定性误差。这两个数回答不同问题。

| 指标 | 参考 | 噪声 | 滤波 |
| --- | ---: | ---: | ---: |
| 真实id跟踪RMS / A | 0.11784 | 0.11724 | 0.65859 |
| 真实iq跟踪RMS / A | 0.17644 | 0.16984 | 0.25134 |
| 转矩标准差 / N·m | 0.007522 | 0.007238 | 0.010679 |

在本工况和原PI下，滤波降低了噪声分量，却使上述真实闭环指标较噪声组变差。滤波组真实id均值约−0.634A，反馈id均值约0.00366A，直观显示“反馈接近目标”与“物理电流正确”是两回事。噪声组某些窗口指标略小于参考组，不据此声称噪声改善控制；有限窗口、采样纹波与闭环轨迹都会影响统计。

标称电频率250Hz处，当前离散滤波器解析幅值约−0.117dB，相位约−7.388°，对应相位延迟约82.09μs。该延迟是当前频率下的幅相特征，不是固定ADC延迟，也不是额外加入了82μs的延迟模块。真实三相电流滤波后仍用当前角度进行Park变换，会体现为dq真值与反馈差异。

滤波组完整启动的真实iq峰值约9.48A，8A指令限幅仍不等于主动过流保护。本轮保留这些结果，未为改善指标改变PI或增加补偿算法。
