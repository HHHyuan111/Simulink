# CCR更新边界

第十一项固定实验 `timing_deadline`。这次三组都使用已有真实时序，保持同一数值网格、ADC触发、控制任务、PWM更新方式、PI和工况，仅改变计算耗时。教学目标是区分“算完”“写入CCR”和“PWM实际采用新指令”。没有新增控制算法或修改主模型。

## 操作

```matlab
cd('D:/simulink/modern'); addpath('teaching')
open_pmsm_experiments
```

恢复固定参考，选择“CCR更新边界”，运行三组。默认耗时 `[5 10.5 11]` µs，依次对应赶上、同边界、错过。第一项允许0.0625—10.4375µs，第三项10.5625—20µs，步进0.0625µs；中间保持10.5µs，使三个名称始终对应真实的边界关系。参数变化会清除界面的旧报告入口。

也可运行：

```matlab
r=run_pmsm_experiment('timing_deadline');
r=run_pmsm_experiment('timing_deadline',[4 10.5 12],.05);
[again,check]=repeat_pmsm_experiment(r.folder);
```

每组默认50ms，为启动过程；末20ms指标不预设稳态。教学触发相位统一为10µs，区别于固定参考中的24.375µs未实测假设。它只临时应用在本实验，运行后恢复完整参考，主SLX不保存覆盖。

## 看懂三个时刻

PWM周期50µs，峰谷更新机会相隔25µs。ADC按C→B→A采样，孔径结束分别为11.1875、12.6875、14.1875µs，JEOS及快环时刻为14.5µs。电流环/SVPWM周期50µs、偏移14.5µs；速度环周期100µs、偏移64.5µs。控制记录周期与任务执行偏移分别核对。

| 组别 | 计算耗时 µs | CCR写入 µs | 新指令生效 µs | 写入后等待 µs | JEOS到生效 µs |
| --- | ---: | ---: | ---: | ---: | ---: |
| 赶上 | 5 | 19.5 | 25 | 5.5 | 10.5 |
| 同边界 | 10.5 | 25 | 50 | 25 | 35.5 |
| 错过 | 11 | 25.5 | 50 | 24.5 | 35.5 |

表中时刻以本PWM周期谷底为0，50µs是下一周期谷底。计算耗时增大5.5µs，可能使JEOS到生效增加25µs：它跨过了一个更新机会。反过来，同边界与错过组虽然写入时刻相差0.5µs，仍采用同一50µs边界，默认实际生效阈值逐点一致。不能把软件多耗时多少直接当成输出就多延迟多少。

JEOS到生效 = 计算耗时 + 写入后等待。ADC触发到JEOS的转换时间属于前一段，不应把这些已包含的时间再重复叠加；三相孔径结束的时刻也分别不同。

同拍先处理UEV、再写入CCR是**已有模型的离散事件约定**。因此25µs同时发生时，新写入值等待50µs生效。实板上的总线写入、预装载转移和中断裕量必须测量，不能用这个教学边界宣称硬件恰好同时写入必然可靠或必然错过。此模型不含完整CPU调度或跨周期中断排队。

事件/序号页显示最后两个PWM周期，默认49.9—50ms，相对横轴0对应49.9ms。图只保留主题、图例和单位，解释留在本文。物理电流没有平滑、重采样或按峰值平移。

窗口起点的生效事件可以属于上一周期写入的指令；不能把某行从左到右遇到的第一个写入点和第一个生效点直接配成一对，应结合指令序号和`deadline.json`。默认三组运行状态差别较小，主要教学现象是生效边界及等待时间变化，不宣称必然产生明显振荡或大幅性能差异。50ms时仍在加速，尚未达到3000rpm给定。

## 数值证据与复现

每组保存24路原始Time/Data，三组共72路。ADC/PWM诊断保留尾部4000点；物理电流和实际生效阈值按62.5ns保留尾部8000点，控制日志保留全程。事件清单见`events.csv`，每条指令的JEOS/写入/生效配对、采样误差和实际输出误差见`deadline.json`。

实际输出按**指令序号追溯该指令写入时的影子CCR**核对，并检查其整个有效区间。恰逢边界时，生效事件所在行的影子CCR可能已被下一条写入覆盖；直接用它当作刚生效值会验证错指令。本实验同时检查同拍UEV/写入顺序，并核对三相采样各自孔径结束时的物理真值。

专项验收入口为 `validate_pmsm_timing_deadline`，报告为 `experiment_timing_deadline_validation.json`。验收覆盖默认三组72路严格复跑、实际事件/输出、编译任务周期与偏移、修改耗时后的事件变化、界面运行/报告/旧结果清除、事件文件篡改拒绝、历史两组电流零偏21路回归，以及第十项旧档案分析保持。主模型、完整参考、PI和布局均需保持一致，报告只有全部通过才标记完成。各项默认实验的证据分别保存，不声称本轮统一重跑全部十一项。

2026-10-13，本机R2026a Update 5全部上述检查通过，默认三组72路Time/Data逐点一致，各相孔径结束物理真值与已配对指令有效区间实际阈值最大误差均为0。编辑耗时为[4 10.5 12]µs后，实际写入改为18.5/25/26.5µs，生效仍为25/50/50µs。初次出图的配对表初始化错误已修正，原失败结果包保留失败标记，不纳入展示。

结果包保留模型、参考、运行脚本、MATLAB版本、参数与文件指纹。同一环境的严格复现以信号Time/Data为准，PNG/MAT容器字节不保证一致；跨MATLAB版本和系统应重新验证。10µs触发及耗时仍为演示值，未实板校准。

下一步建议把已有低侧采样窗口做成固定教学对照，讲清“取样有数值”和“数值是否有效”的区别。继续沿用已有算法及开关，不增加重构/补偿方法；位置反馈、启动保护和固件实测校准随后推进。
