# 死区配对实验

本轮建立同桥、同步长的死区对照，并把转子位置累计差与电流相对转子的变化分开观察。沿用当前主模型、控制算法、PI、布局和固定参考。

## 两组如何设置

| 设置 | 零死区组 | 死区组 |
| --- | --- | --- |
| 桥路径 | 详细续流桥 | 同一详细续流桥 |
| 固定步长 | 62.5ns | 62.5ns |
| 门极死区 | 0μs | 默认2μs，可修改 |
| 补偿及其他附加因素 | 关闭 | 关闭 |
| PI、电机、母线、给定、负载、初态 | 相同 | 相同 |

两组都开启`功率设置.gate_on`以选择详细桥，仅`gate_us`数值不同。零死区组不是所有附加开关关闭的理想参考；运行前后仍恢复同一套完整固定参考。两组设置差异与比较契约保存在计划和结果记录中。

本轮不引入死区补偿优化、固定转速驱动、转子角强制同步或新PI。2μs是演示值，入口支持0—5μs、0.0625μs步进；这不是稳定性或硬件额定范围。当前详细桥适用于Ld=Lq，近零电流带仍是数值近似。

## 操作

```matlab
cd('D:/simulink/modern')
addpath('teaching')
open_pmsm_experiments
```

恢复固定参考，选择“死区配对”，填写死区大小，运行。脚本入口：

```matlab
pmsm_reference('restore')
r=run_pmsm_experiment('gate_deadtime_pair',2);
pmsm_experiment_verify(r.folder);
```

默认每组0.2s，仍从相同零初态启动。短时实验可显式传入第三个时长参数，但选定角周期可能处于加速阶段，不能据此声称稳态性能。

## 四张报告

“电角度电流”以真实转子电角度作横轴，叠加两组的ABC真实电流。真实电流和真实电角度均按1μs同拍记录。选择两组都已走完的同一完整电角周期，再用该周期内的局部角度0—360°显示；保留原始采样点，不按电流峰值平移，不平滑，也不插值重采样。

这样移除的是两组转子绝对位置不同对时间叠图的影响，电流相对于转子的相位偏差、幅值和纹波仍然保留。各自进入该角周期的时间可能不同，具体周期编号、时间窗口、采样点数和原始角边界保存在`alignment.json`。开关载波相对于转子的位置仍可能不同，不能把瞬时电流差全部称为某种谐波。

“闭环响应”保留速度、转矩、真实/反馈dq与时间域变化，参考组在这里指详细桥零死区组。

“因素机制”显示请求/实际门极、两管关断空白和角度对齐的A相电流。0死区时实际门极应等于请求；非零死区时关断立即，开通延后，短于死区的脉冲可能被抑制。

“启动相位”单独显示转速、转速差、累计电角度差和速度积分核对。差值均为死区组−零死区组，累计角度不折回±180°。速度积分使用50μs记录做梯形积分，因此存在离散积分残差。

启动累计角差不代表固定控制延迟。原先理想桥/详细桥对照出现约63.55°的角差，主要随启动速度差积分累计；原实验保留为桥路径总体对照，本实验用于更公平地隔离死区设置。

## 档案与复现

结果包沿用两组21路信号，增加`startup.png`与`alignment.json`并纳入完整性校验。真实角度在本场景按1μs记录，其他场景仍保持原采样率。控制记录仍是50μs，高频门极只保留尾部4000点。

`repeat_pmsm_experiment`可按此档案的参数重跑并逐点比较；`export_pmsm_experiment_examples`可读取档案重绘。此前六项默认实验已经完成逐点复现验收，新场景的检查结果单独记录在`experiment_paired_deadtime_validation.json`，不把旧六项结果当作新场景的复现证明。

图内只保留简短主题、坐标单位与必要图例，具体参数、解释和边界放在本说明及展示目录的`notes.md`。

2026-10-13验收通过：两组只差死区数值；均为62.5ns网格，真实角度/电流1μs同拍；默认0/2μs配对两次运行的42路Time/Data逐点一致；两组都为0时21路逐点一致，并与默认零死区组前50ms复现一致；30个2μs开通沿、立即关断与无重叠检查通过；角度对齐保留原始样本；启动积分末端残差约0.00385°；GUI启动页回调、旧结果清除、档案篡改拒绝和旧电流零偏回归通过。主模型、固定参考、PI和布局均保持。
