# 速度控制教学

入口：模型顶部“时域观测 → 速度控制”。复用已有Scope和已验证实验，不增加控制算法、自动仿真或PI整定。

三个按钮按用途区分：

| 按钮 | 数据来源 | 看什么 |
|---|---|---|
| 当前控制响应 | 当前模型下一次运行的原生Scope | 转速给定/真实、id及iq给定/真实/反馈、电磁转矩/负载；相关比较量同轴，四格共用时间 |
| 阶跃响应 | 已保存的20rpm小阶跃基线；菜单可选10rpm | 给定/真实/反馈转速，iq给定/真实，转矩/负载，速度误差 |
| 正弦跟踪 | 已保存的80Hz、10rpm幅值试测；菜单可选5rpm | 与阶跃相同四种观测，显示最后三个周期，便于看跟踪幅相与电流、转矩代价 |

当前Scope需打开后在模型中运行；两项档案只读，不会随当前参数变化。当前Scope不重复创建，原“控制响应”入口仍可使用。阶跃与正弦的工况不同，不是优化前后对照。

建议阅读顺序：先看转速跟踪，再看速度PI发出的iq命令与真实iq，接着看转矩变化，最后看误差。电流内环、转矩和机械运动共同构成速度响应；不能只看转速曲线评价算法优劣。原生时间缩放联动保留，图内只放简短主题、图例和单位。

固定实验使用原速度PI、原电流内环、自由转子；阶跃为零负载工作点的小幅试验，正弦为已有20/80/250Hz三点试测中的80Hz。频响实验采用周期平均电压适配，不包含开关纹波或死区，不等于实板频响验证；详见[阶跃基线](frequency/speed_loop/README.md)和[正弦试测](frequency/speed_probe/README.md)。三点试测不能用于声称已完成正式速度环带宽及裕度验收。

专题入口验收核对现有Scope复用、16条档案曲线与原始记录、时间缩放联动、当前配置及SLX保持、原档案只读；未重跑完整阶跃/正弦物理实验。验收见`speed_lesson/validation.json`，展示图为原始记录派生副本。本阶段另重新执行当前控制Scope的两组20ms物理回归，104路原日志保持，见`../layout/appearance/native_scope_validation.json`。

整体路线继续为：原FOC与电机 → 可开关的现实因素 → 按教学目的组织的观测 → 可复现实验。“电流采样”专题现已完成，见[阶段报告](核心教学观测基线_阶段报告.md)。下一步按[体验清单](核心教学观测基线_体验清单.md)反馈操作问题，暂不添加新物理因素或算法。
