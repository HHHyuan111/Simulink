## 三个开关层次

双击逆变器色域底部“功率设置”：

- **门极死区**：下降沿立即关断，上升沿等待设定时间；短于死区的指令脉冲被抑制。默认0.5µs来自固件TIM1配置，未叠加未知驱动传播误差。
- **死区补偿**：使用控制器收到的三相测量电流判断极性，采用±0.05A滞环；按母线电压和补偿死区计算相电压修正。需先开启门极死区。
- **器件导通压降**：详细模式在桥内计算Ron和二极管Vf；关闭时器件理想，仅保留门极死区。Ron/Vf仍为演示值。

旧“死区平均压降”仍保留作历史教学，但与门极死区互斥，防止重复计算。详细模式下旧平均功率压降被旁路，`drop_on`由续流桥处理。默认所有非理想开关关闭，方便回到之前的参考。

“功率观测”增加实际门极、续流通道、极点电压、abc补偿及dq补偿。原`SW`和六路门极Scope仍表示比较器指令；低侧有效窗口现读取实际门极标签`SWact`，能够识别真实两管关断区间。

## 续流桥怎样工作

约定正相电流由逆变器流向电机：

| 状态 | 相对母线中点的极点电压 |
| --- | --- |
| 上管导通 | `+Vbus/2 - Ron*i` |
| 下管导通 | `-Vbus/2 - Ron*i` |
| 两管关断且电流为正 | 下管二极管续流，`-Vbus/2 - Vf` |
| 两管关断且电流为负 | 上管二极管续流，`+Vbus/2 + Vf` |

三相极点电压减去均值得到浮置星点相电压。近零电流带内，开路相跟随反电动势及星点电位；达到母线钳位边界才进入二极管通道。±0.01A近零带是公开的数值近似，用于避免电流接近零时的符号抖动，不代表输出电容或精确二极管互补约束。当前模型要求Ld=Lq，适用于现有沉沙参数。

为避免原PMSM聚合电压/状态总线形成虚假的电流直接馈通，ia/ib/ic原公式保持不变，输入改从相同状态加占位量构成的等价向量读取。真实电流仍由电机状态决定，未从给定或控制器输出生成。

## 补偿与限压如何连接

`Δvabc = Vbus * tcomp/Tpwm * polarity(i_measured)`，去掉共模后按测量电角度变换到dq。修正量先与原PI及解耦输出相加，再进入原最终圆限幅；回算残差为“最终输出减去包含补偿的请求”。因此补偿不会绕过可用电压约束，饱和时也不会重复计入回算。

补偿使用测量电流和测量角度；只有被控桥的续流通道判断使用电机真值。滞环内保留此前极性，初始极性为0。`comp_us`独立于`gate_us`，可演示补偿不足/过度，但本轮主对照二者相等，未通过修改PI掩盖误差。

方法参考[TI死区与延迟说明](https://www.ti.com/lit/an/slvaf84/slvaf84.pdf)中的续流关系，以及[MathWorks死区补偿器](https://www.mathworks.com/help/mcb/ref/deadtimecompensator.html)的测量电流极性和过零滞环思路。TI具体DRV8316参数不套用到未知U7，本机没有Motor Control Blockset，主模型采用普通Simulink和嵌入MATLAB Function实现。普通模块展开候选已验证但尚未替换，详见[补偿逻辑展开](README_补偿逻辑展开.md)。

## 验证和适用边界

组件测试独立校验上升/下降沿、脉冲消失、无直通、正反电流续流、零电流开路电压、平均误差及补偿符号/幅值，并在31.25ns网格复核。固定电流的平均误差符合`-Vbus*td/Tpwm*sign(i)`，去共模后补偿能够抵消。闭环还检查关闭回归、与已有真实时序组合、细网格、矛盾开关拒绝及保存重载。

报告THD使用PWM周期平均的A相电流，按真实电角度拟合2—25次谐波；它表示低次畸变，不包含开关频带。转矩指标也取PWM周期平均；没有用整段启动FFT或单个开关相位采样冒充稳态THD。

编程死区不是全部有效死区。驱动传播差异、MOSFET开关时间、输出电容、反向恢复、开关损耗、最小导通脉宽规则仍未加入；短脉冲消失仅来自本轮门极延迟机制。主动过流/欠压保护尚未实现。前端和板载细节按用户要求后续完善，本轮先验证主要机理和可见效果。

新增日志：`obs_dead_requested`/`obs_dead_gates`为指令/实际六路门极；`obs_dead_bridge`依次为二极管通道ABC（-1下管、+1上管）、极点电压ABC、真实电流ABC；`obs_dead_comp`为补偿abc、dq及电流极性ABC。日志记录速率与控制执行速率分别理解。

当前主模型指纹、数值指标和发布状态见`deadtime_stage4_results.json`。补偿展开候选指纹与验证状态见`readable_compensation_results.json`。

为控制长时间仿真的日志内存，新增指令/实际门极日志默认只保留末4000点（62.5ns事件网格下约250μs）；完整电流/转矩日志及原48路记录不变。门极Scope仍可查看尾段切换，演示脚本也使用相同保留长度。日志上限修改已通过全模型差异审查和保存重载检查，仅影响记录历史，不改变控制行为。

## 本轮结果（2026-10-12）

| 指标 | 理想（死区0） | 0.5µs死区，无补偿 | 0.5µs死区，有补偿 |
| --- | ---: | ---: | ---: |
| A相2—25次THD | 0.1858% | 1.8755% | 0.7315% |
| 真实id RMS | 0.01555A | 0.09168A | 0.04526A |
| PWM周期平均转矩交流RMS | 0.0007247N·m | 0.0009000N·m | 0.0007272N·m |
| 平均转速 | 600.015rpm | 600.044rpm | 600.008rpm |

相对无补偿，低次THD降低61.0%，id RMS降低50.6%，周期平均转矩交流RMS降低19.2%。补偿没有完全恢复理想状态，过零滞环、测量和控制保持、CCR与事件网格量化仍有影响；不把这组效果外推为所有速度/负载的保证。

关闭死区时，理想参考和已有真实时序参考的48路日志均逐点相同。62.5ns与31.25ns网格的5ms补偿对照中，iq最大差0.02292A；配置死区空白及无直通检查通过。原667个模块身份保留，根层188块与九个色域不变，新增后729块。保存重载、非有限日志、开关互斥及采样窗口组合检查通过。

本轮新增开关默认关闭，用户按“门极死区→死区补偿”顺序即可直观对照；完整三组稳态图由上述脚本生成。

## 三相电流教学扩展

无参数`run_deadtime_demo`现默认使用2μs教学死区，600rpm、0.207N·m；0.5μs原验证报告保留在`report_deadtime`。新三列三相全貌与A相过零图见`report_teaching/three_phase_comparison.png`，逐相叠加与差值图见`three_phase_difference.png`；同样2μs的300rpm、0.08N·m对照见`report_low_speed`。各报告的`record.json`记录参数与指标，未通过修改PI放大差异。

补偿时间由演示脚本默认跟随输入死区；手动模式可在功率设置或统一参数窗口中独立修改。放大死区会增强畸变，也会暴露现有补偿的过零局限；不保证大死区下仍达到0.5μs工况的61%相对改善。设置和实测方法见[参数设置说明](../teaching/README_参数设置与实测.md)。
