## 开关与使用

双击SVPWM色域的“时序设置”，在运行前选择：

- **真实时序**：开启C/B/A顺序采样、JEOS控制执行、计算后CCR写入、预装载更新及CCR计数量化。
- **低侧采样窗口**：在真实时序基础上，将不可观测样本置零，演示低侧分流失去相电流观测时的影响。
- **无效时保持上次有效值**：在窗口模式下对照一种处理策略，初值为零。这不是对当前固件采样处理的声明，也不等同于电流重构。

三个新开关默认关闭，保留上一版理想参考。真实时序与旧“整周期输出延迟”“采样传递延迟”互斥；错误组合明确报错。ADC量化、偏置、模拟/数字滤波仍沿用原独立开关。窗口开关须配合真实时序；保持策略须配合窗口开关。

真实时序使用62.5ns步长，适合先运行短时间观察；默认理想模式仍使用1µs。隐藏的 `grid_divider=2` 仅用于31.25ns收敛检查。运行时间会显著增加，20ms启动局部对照不能代表完成1s启动性能验收。

## 为什么载波在真实模式反向

原比较器是“载波≥阈值”，SVPWM阈值满足 `D=1-2*Tcm/Ts`。原载波由0升到Ts/2，主输出高电平围绕计数峰值；固件PWM1主输出为CNT小于CCR时有效。真实模式将同一个载波块改为Ts/2→0→Ts/2，保留比较器和阈值算法，使有效电平围绕谷底，低侧导通窗口围绕峰值。理想模式恢复原载波，不改变旧参考的开关相位。

CCR按固件方式截断：`CCR=floor(D*4000)`，再换算回原阈值。CCR写入和UEV在同一个网格时，模型规定UEV先发生，新值等下一次UEV；这是明确的边界约定，实板近边界写入应作为需要裕量的情况验证。

## 窗口与测量值

每相分别检查其完整采样孔径内，低侧是否持续导通并满足稳定等待。三相分别采到不同时刻的电流，所以即使物理三相电流之和为零，采样结果的和也可能不为零。

窗口关闭时，依然顺序采样连续电流，并记录有效标志，用于单独观察时序误差。窗口开启后，无效样本置零是明确的教学近似：低侧关断时分流器不能代表相电流；真实输出会受开关瞬态、放大器、偏置与滤波影响，不能由“置零”完整代表。保持策略从上次有效**测量值**读取，不使用电机真值补齐。

ADC码观测按3.3V、1mΩ、20倍、零偏2048换算，并限于0…4095。即使原ADC量化开关关闭，码值仍显示对应的标称量化结果；关闭量化时控制反馈仍是浮点采样值，不把诊断码误认为已参与控制。原量化开关开启时，反馈采用原量化支路。没有加入实际零偏校准、ADC2母线顺序转换、ABZ采样、放大器动态或噪声频谱。

局部读取缓存用来解除原聚合电机总线引出的人工代数环。模拟值缓存一网格，在孔径结束的下一网格读取前一网格值，物理采样时刻仍为孔径结束；转换完成时刻不变。门极历史同样使用前一网格，窗口判断保守一个网格。CCR在计算结束时读取已稳定的指令缓存；计算时间至少为一个网格。现有Backward Euler隐式PI保留，不改成固件逐拍显式PI。

真实模式中，转矩系数的原求和与乘法在控制首拍前也计算其常量部分，避免相位偏移后初始输出为0、导致转矩除以系数时出现0/0。公式与常数不变；理想模式恢复原继承速率。新分支使用运行前选择的Variant Source，避免关闭时仍将高速事件采样周期传到旧控制链。
