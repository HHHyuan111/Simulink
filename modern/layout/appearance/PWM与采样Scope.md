# PWM与采样

入口：工作台“PWM与采样”，或双击原“时序观测”；命令行 `open_pmsm_pwm_scope`。使用白底2×2原生Scope，默认使用200μs的时间窗口，约四个20kHz周期。各图共用时间范围，可用原生缩放和游标读取先后关系。

| 位置 | 主题 | 信号 |
| --- | --- | --- |
| 左上 | 载波与A相阈值 | carrier、Tcm_req_A指令、Tcm_act_A生效值，单位μs |
| 左下 | A相门极 | AH上管、AL下管，取实际门极选择输出 |
| 右上 | ADC事件 | ADC_trig触发、JEOS整组转换完成 |
| 右下 | CCR事件 | UEV更新边界、CCR_write写预装载、CCR_latch预装载生效 |

载波及阈值采用本模型的时间阈值表达，不是直接的CCR计数。门极为模型逻辑信号，不代表实测栅极电压。

先在“时序设置”开启真实时序，再运行。关闭时，ADC和CCR事件诊断为零，这一页会忠实显示零；载波、阈值和门极仍可观察。与另一个事件重合的曲线可能被遮住，可点原生图例单独查看。CCR_latch只在有待更新内容且实际装载时出现，不能把每个UEV都当成装载。

要研究计算时间的影响，只改“JEOS至CCR写入”参数，其他参数保持；先看写入时刻，再看赶上或错过哪次UEV，最后回到“控制响应”查看影响。触发偏移、更新边界、采样窗口按同样方法逐个研究。参数仍有演示值和待实测项，此页不把它们当成实板测量值。

采样周期使用timing_h：真实时序当前为62.5ns，不用50μs电流环周期读取事件。Scope缓冲最多64000点，避免长时间运行无限累积；滚动窗口200μs在当前两种网格下均可完整容纳。完整实验数据仍由原日志及固定实验档案保存。该Scope不做滤波或平滑。

新增观测只分支原日志来源，原PI、算法、电机和SLX均不改变。显示层撤销顺序：

```matlab
pmsm_pwm_scope('remove')
pmsm_electrical_scope('remove')
pmsm_native_scope('remove')
pmsm_presentation('remove')
```

恢复时依次apply布局，再install控制、电气、PWM观测。固定实验通过pmsm_presented_call自动撤销及恢复。

验收：pwm_scope_validation.json，理想与真实时序各1ms。逐条核对原日志不变；载波、阈值、门极按原记录时间核对；事件按细网格完整核对，检查短脉冲没有丢失，以及正常/异常恢复、结构还原和SLX指纹。该检查不代替全工况或实板验证。

下一步：先体验三页原生观测，再围绕死区和采样噪声补频谱。频谱必须说明稳态区间、采样频率、窗函数及幅值口径，避免把启动瞬态或开关混叠误称为谐波。

事件与门极图固定使用0/1量程；载波图按半个PWM周期设置量程，避免自动缩放沿用其他主题的旧范围。更改PWM周期后重新打开此页以刷新量程。
