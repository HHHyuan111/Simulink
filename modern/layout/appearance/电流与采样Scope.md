# 电流与采样

入口：重新打开教学工作台后，选择 **观测 → 电流与采样**；也可运行：

```matlab
addpath('D:/simulink/modern/teaching')
open_pmsm_current_sampling_scope
```

首次打开按需建立观测页，随后重新运行模型；再次点击入口可按已有数据执行原生自动缩放。首次无数据时电流量程按当前Iq_limit初始化，避免继承转速图的坐标。原生 Scope 采用白底2×2，默认显示末尾500µs，保留缩放、图例和原生游标。横轴可能显示相对时间，绝对仿真时间需结合状态栏的偏移量。

| 位置 | 主题 | 信号来源 |
| --- | --- | --- |
| 左上 | 三相电流 | 既有真实电流日志的输入源，以时序网格观察 |
| 右上 | 控制反馈 | 既有测量电流日志的输入源，包含启用的采样链因素 |

## 怎么读

先关闭附加因素：真实电流与最终反馈可能完全重合，这是原模型旁路采样链的正常行为。中间的采样保持仍独立运行，可用于理解连续变化的电流为什么在控制器中变为阶梯值。

再开启真实时序与ADC：结合右下的触发、转换结束事件，观察采样保持及最终反馈何时更新。灰线是模型现有零阶保持块的输出，**并非ADC内部采样保持电容电压，也不是单独记录的孔径瞬间电流**。最终反馈还可能包含量化、滤波、偏置等其他已启用因素，比较时应一次只研究一个因素。

要研究旧式整周期延迟，则关闭真实时序，再开启采样链的delay_on。真实时序已经包含ADC交付和控制调度关系，模型禁止叠加旧整周期延迟，避免重复计算。

## 密度与边界

Scope以`timing_h`观察：固定理想参考当前为1µs；真实时序演示当前为62.5ns。与原“电流与电压”页的控制周期观察相区别，本页不在控制频率下抽点。密集网格不会增加电机模型本身的带宽或硬件真实性；原功率级的求解精度和建模假设仍然适用。

观测日志关闭抽点，最多保留64000点。真实时序下约保留最近4ms；默认500µs窗口可看到10个20kHz PWM周期。Scope为屏幕像素优化绘制时，放大后观察局部，不使用插值或平滑制造细节。它不改变原封存实验记录的采样率或频域指标。

## 复现与验收

独立MATLAB进程运行`validate_pmsm_current_sampling_scope`，验证理想、真实时序、量化加旧延迟三种1ms工况：原日志Time/Data逐点不变；观测源、保持值及ADC事件与原日志交叉核对；观测网格、撤销后结构、正常及异常实验恢复、固定SLX哈希保持。

结果见`current_sampling_scope_validation.json`。这属于观测框架验收，不能替代稳态/全工况测试或实板ADC标定。

新增观测位于原模型“测量观测/采样明细”，按需装载，不另建仿真模型。命令行移除顺序：

```matlab
pmsm_current_sampling_scope('remove')
pmsm_pwm_scope('remove')
pmsm_electrical_scope('remove')
pmsm_native_scope('remove')
pmsm_presentation('remove')
```

运行可重复的当前参数演示：

```matlab
[out, provenance] = preview_pmsm_current_sampling;
```

该入口执行20ms启动过程，仅在本次SimulationInput中开启真实时序和ADC、关闭旧PWM整周期保持及旧采样整周期延迟，结束后检查参数设置恢复。返回原生观测数据及当前参数、覆盖项、模型/演示源码哈希。它使用当前电机和控制器参数，属于可记录、可重做的界面教学演示；不将20ms启动图宣称为稳态算法优劣对照。固定对照仍使用既有封存实验入口。
