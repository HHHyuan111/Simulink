# 模型布局与操作入口

本轮保留原模型的计算块、参数、算法和九分区，只整理显示和操作。模型文件及 reference_v1 不覆盖。

## 日常使用

在 modern 文件夹运行：

```matlab
open_pmsm_model
addpath('framework')
open_pmsm_framework
```

打开模型自动应用配色、等距观测区和 Goto/From 布局。工作台可进入单项实验、参数与开关、整机对照以及结果查看。

原生Scope已加入同一模型的控制响应入口，详见[使用说明](原生Scope使用说明.md)。自定义动画窗口暂停；白底2×2 Scope是当前优先体验方式。

模型顶部现有“时域观测”“频域分析”两个入口。旧 Scope 也纳入统一配色和窗口尺寸；当前输出的 FFT/PSD 与归档实验分别标识。详见[观测统一与分析入口](观测统一与分析入口.md)。

- 双击采样、角度、功率或时序设置，进入大字体参数窗口。
- 参数表编辑后先点击“应用到模型”；预设只预览，未应用前不生效。
- “展开模块”显示原来的内部实现。新布局保留原先的独立小模块。
- 固定实验自动切回原计算图，执行后再显示整理后的布局；每次结果单独存档。
- 结果在可缩放的大窗口中分页查看，图内只保留主题和基本标识。

## 布局与计算参考

新的布局配置保存在 `positions.json` 和 `pmsm_presentation.m`，由入口重复应用于同一个模型。它不是另建一个仿真模型，也不改变旧 SLX 的哈希。

固定参考包含布局校验，因此实验入口在计算前移除显示层，计算后重新应用。`pmsm_presented_call` 也处理异常退出。直接调用命令行实验 API 前先执行：

```matlab
pmsm_observation_view('remove')
pmsm_current_sampling_scope('remove')
pmsm_pwm_scope('remove')
pmsm_electrical_scope('remove')
pmsm_native_scope('remove')
pmsm_presentation('remove')
% 运行原有参考、实验或严格复现 API
pmsm_presentation('apply')
pmsm_native_scope('install')
pmsm_electrical_scope('install')
pmsm_pwm_scope('install')
pmsm_observation_view('install')
```

显示层启用时阻止直接保存 SLX，避免把显示标签误写入已经冻结的计算参考。布局脚本本身已经保存，不需要点击模型保存按钮。以后修改算法时先移除显示层，再建立新的计算参考版本。

手动修改模型参数时，参数 JSON 可在“参数与开关 → 参数档案”中保存。布局应用/移除均不主动恢复这些参数；只有明确点击恢复参考或运行固定对照时才恢复固定参考，旧参数由原 API 备份。

## 本轮范围及复现记录

主图的05/06区改用电机信号标签；采样链分成模拟前端、ADC与滤波、延迟与输出、时序采样和数据记录，长距离观测线改用命名标签。主要子系统取消内容预览，使用与分区一致的纯色。数据观测与调制观测的示波器尺寸及列位置统一。

新增大字体参数编辑器和分页结果查看器，调整单项实验窗口和工作台。旧的参数 API、固定参考源文件及实验数据保留。`legacy_ui` 保存改版前的两份界面脚本快照，供旧记录要求同源码版本时核对。旧严格复跑仍会核对界面脚本指纹；新实验会记录当前脚本版本。历史已完成的复现凭据和数值数据不作重写。

本轮验证覆盖理想参考、组合采样误差、真实时序采样三种短时工况，对整理前后的原始 Time/Data 作严格比较，并检查移除布局后完整模型快照与固定参考一致。它不代替此前400ms整机验证，也不新增实板标定或保护算法。



电气观测入口见[电流与电压](电流与电压Scope.md)，沿用白底2×2原生Scope。



第三页原生观测：[PWM与采样](PWM与采样Scope.md)，观察载波、实际门极、ADC与CCR事件。


频域入口：工作台菜单‘频域 → 死区电流频谱’，使用MATLAB原生图窗；方法、复现及口径见[频域说明](../../teaching/frequency/README.md)。


噪声频域入口：工作台菜单‘频域 → 噪声与滤波频谱’，方法与复现见[噪声频域说明](../../teaching/frequency/噪声与滤波.md)。


新增按需观测：[电流与采样](电流与采样Scope.md)，比较真实电流、零阶保持输出和最终反馈，并同时观察ADC触发及JEOS。
