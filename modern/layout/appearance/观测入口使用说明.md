# 在模型里查看波形

直接双击Simulink模型顶部的按钮，无需命令行。旧会话先双击已有“时域观测”或“频域分析”，会自动刷新出六个入口；保持当前控制参数，不关闭或重载模型。

| 模型顶部入口 | 查看内容 | 数据来源 |
|---|---|---|
| 时域观测 | 控制响应、电流电压、PWM采样等原生Scope | 当前模型本次仿真 |
| 频域分析 | 全部频谱、频响入口 | 菜单中分别标明 |
| 电流频谱 | 三相电流时域、FFT和PSD | 最近一次out；没有输出时弹窗提示 |
| d轴频响 | d轴闭环及环路频响、延迟对照 | 已归档固定实验 |
| q轴频响 | 理想锁轴q轴频响、时域及机械观测 | 已归档固定实验 |
| 速度频响 | 20/80/250Hz三点试测及对应时域 | 已归档固定实验 |

日常操作：点击Simulink“运行”→双击“时域观测”选择原生Scope，或双击“电流频谱”分析最近输出。查看环路实验时，直接双击相应频响按钮，再用图窗的“时域对照”菜单选择频点。四宫格共用时间轴，缩放一幅即可同步查看同一时间的其他量。

Scope也可以提前打开后运行。固定频响按钮打开已有档案，不会启动耗时重跑；固定档案不随当前模型仿真自动更新。

“频域分析”窗口分为“本次仿真”和“教学实验”两个页签。前者只有当前输出的电流频谱；后者使用d轴电流环、q轴电流环、速度阶跃、速度频响、谐波对比和噪声频谱六个短名称，每项右侧直接说明能看什么。“固定实验/归档实验/扫频准备”等开发阶段前缀不再作为按钮名称。关闭旧窗口后，从模型重新双击即可看到新版。

导航作为可撤销显示层加载，原SLX计算基线不保存这些按钮。六个入口回调、原配置保留与结构恢复已单独检查；旧两按钮会话迁移另有兼容检查。
