# 2026-10-10 许可恢复与原模型布局整理

## 许可恢复

症状：MATLAB 初始化时提示 MathWorks Licensing Error 5201，批处理也无法启动。

只读检查发现 Windows 系统代理为 `127.0.0.1:7897`，本地代理端口正在监听。登录域名通过直连和显式代理均完成 HTTPS 连接并返回 HTTP 302；服务域名根路径两种方式均返回 HTTP 404。根路径 404 只说明收到了服务器响应，不代表许可接口认证成功。

Service Host 日志反复出现 `Found a conflicting MSH process`。这提示后台状态需要排查，并不足以单独证明根因。

确认 MATLAB 已关闭后，结束旧的 MathWorks Service Host 与 Monitor，重新启动 MATLAB。2026-10-10 22:21 的启动验证通过，版本为 R2026a Update 5，Simulink 许可测试返回 1；随后现有模型完成默认 1 秒仿真。整个过程中没有修改代理、Windows 网络或安全设置，没有重装 MATLAB，没有修改许可文件。

当前启动故障已恢复，不能据此保证以后不会复发。保存了 `restart_mathworks_service_host.ps1` 供同类故障恢复；它会在 MATLAB 仍运行时拒绝执行。官方恢复流程参考：[MathWorks Service Host](https://www.mathworks.com/matlabcentral/answers/1815365-how-do-i-uninstall-and-reinstall-the-mathworks-service-host)。
