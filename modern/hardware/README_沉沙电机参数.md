# 沉沙200W电机参数迁入

来源：AxDr_L dev提交`48d6e86814ac6657b1313b4c92ef24c88f492e07`的`User/config/motor_config.h`，当前选择`MOTOR_MODEL_CHENSHA`。本次按用户要求先对齐电机及基本运行参数，保持原小模块和九宫格布局，暂不整定PI，不改成固件PDFF结构。图纸不包含电机铭牌或辨识记录，以下是固件标称档案。

参数嵌入当前`modern/PMSM_FOC_R2026a.slx`的Model Workspace → MATLAB Code，可读副本为[chensha_model_parameters.m](chensha_model_parameters.m)。运行SLX不依赖该外部脚本；不要再运行仓库原作者的旧参数脚本覆盖工作区。

模型采用幅值不变dq变换，`Te=1.5p[phis×iq+(Ld−Lq)id×iq]`。由档案换算`Kt≈0.0424264N·m/A幅值`，对应`0.06N·m/A RMS`，因此11.5A RMS对应0.69N·m。200W、0.69N·m、3000rpm均按固件原值保存；后二者乘积约216.8W，不能把这组标称量当成严格一致的额定工作点或已测效率。

## PI与开关

原参数脚本会用Rs、Ld、J等自动重算PI。本次改为冻结迁入前的9个P/I/回算系数，避免“改电机”同时隐含整定。速度环仍为rpm误差、转矩输出PI；没有把固件单位为A/(rad/s)的PDFF系数直接复制过来。冻结仅保持增益数值，电机、负载和速度执行周期变化仍会改变闭环响应，不能由此宣称原PI适合实板。

14个非理想因素开关仍全部关闭；默认速度任务周期设为100μs。教学“速度分频”开关启用后仍按其倍率重新设置周期，用于故意放慢速度任务的教学，不影响PWM/电流周期。

## 仍未实现的档案项

上电对齐、编码器方向/零位、ABZ测速与滤波、1200rad/s²给定斜坡、10A/30V/10V保护逻辑只是档案或后续工作，未因为写入数值而生效。也未实现低侧有效采样窗口、ADC顺序转换或真实门极死区。Ron、Vf、模拟低通等继续保持演示标记。

原模型已记录的d轴参数绑定、q轴完整前馈选项、最终dq矢量限幅/抗饱和和SVPWM过调制问题仍保留在待办中。本次使用限幅内工况检查参数迁入，不把已知算法问题与参数修改混在一起修复。

## 验证与回退

迁入脚本[apply_chensha_profile.m](apply_chensha_profile.m)先在`modern/.build/motor_profile_stage/`备份原模型并生成候选，检查增益、块与布局、默认1s仿真、实际速度执行周期及保存重载结果，再替换同一个主模型。验证结果见[chensha_validation.json](chensha_validation.json)，五页波形在`report_chensha/`。这些检查是仿真运行和参数一致性检查，未完成实物性能验收。

备份文件`modern/.build/motor_profile_stage/PMSM_FOC_before_chensha.slx`和迁入前参数副本仅保存在本机。历史`teaching/observation_*`文件仍对应改电机前的模型，不能作为当前模型哈希或波形完全相同的证明。

本轮验证通过：默认0.207N·m负载、3000rpm给定，启动峰值3135.8487rpm，1s末3000.0461rpm；iq指令最高8A，实际反馈瞬态峰值8.5073A，电压指令最大比值0.733881（相对于Vdc/√3），阈值在载波范围内。保存重载后7路主日志逐点一致。速度采样、P支路保持、I支路积分的实际离散周期均100μs；连续输入的0周期元数据不当作执行周期。当前模型SHA256：`6db333bfaf2d10822562c31a51ed8941ffd5ca421edaab858295af521885cc8b`。五页波形已目视核对。
