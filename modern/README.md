## 打开与运行

现有功能已收拢到[统一框架入口与整机基线](framework/README.md)。在本目录执行`addpath('framework','teaching'); open_pmsm_framework`，可打开原模型、进入16项单项实验、查看或重跑整机对照、恢复固定参考。整机默认两组400ms，组合编码器角度/计数测速/速度滤波并验证变速与增载；66路严格复现、六个平台窗口通过，主模型及PI保持。下一步先与用户核对功能、细节和使用感受，启停与保护继续后移。

环境：MATLAB R2026a + Simulink，已在 R2026a Update 5 验证。不需要 Simscape Electrical、DSP System Toolbox 或 Motor Control Blockset。

克隆仓库后，在 MATLAB 中进入仓库的 `modern` 文件夹，运行：

```matlab
open_pmsm_model
```

也可直接双击 `PMSM_FOC_R2026a.slx`，点击“运行”。参数已嵌入 Model Workspace，不需要先运行原参数脚本。入口：Model Explorer → PMSM_FOC_R2026a → Model Workspace → MATLAB Code。

默认设置：24 V 母线、3000 rpm 转速给定、20 kHz PWM/电流任务、10 kHz速度任务、ode4 固定步长 1 μs、仿真 1 s。电机已对齐固件当前沉沙200W标称档案：5极对、Rs=0.105125Ω、Ld=Lq=103.7615μH、J=32×10⁻⁶kg·m²；尚未经过实板辨识校准。

[电机参数迁入](hardware/README_沉沙电机参数.md)区分11.5A RMS额定电流、16.2635A幅值与8A台架iq指令上限；默认负载为0.207N·m。原PI的9个增益固定不变，非理想因素开关默认关闭；算法解耦开关默认开。参数已嵌入SLX，不依赖外部参数函数。8A对应约0.339N·m，不能以这个指令上限要求电机持续输出0.69N·m额定转矩。

```matlab
pmsm_result = sim('PMSM_FOC_R2026a');
plot(pmsm_result.log_speed.Time, pmsm_result.log_speed.Data);
xlabel('Time (s)'); ylabel('Speed (rpm)'); grid on;
```

## 当前实现

旧 SPS 电机、逆变桥和坐标变换等已用普通 Simulink 块替代；电机使用连续 dq 方程，逆变器可选择原理想桥/平均压降或详细门极死区/续流桥，补偿由测量电流极性计算。速度PI输出单位为转矩，转矩换算使用Ld−Lq；电流PI之后接完整dq前馈和方向保持的电压圆限幅，最终残差与原PI轴限幅残差合并回算。SVPWM保持原扇区编码，已修正超调制顺序归一化并新增时间、占空比及边界观测。

当前门极死区版保留188个顶层块，共729个块。新增部分位于已有模块内部，原667个块身份保留；九个色域大小仍均为860×580。原9个PI增益不变。

双击“时序设置”“采样设置”“角度设置”“功率设置”选择教学因素；入口显示“开 / 关”，有启用项时文字标红。设置在运行前修改。第三行底部五个观测入口直接打开分轴总览。批量对比演示：

## 已知问题与下一步

当前可作为算法与教学仿真的开发基线。d轴参数绑定、完整dq前馈、最终限压与合并回算、SVPWM过调制边界已完成本轮修复与专项验证。后续重点：

1. 改善速度环启动、反转和饱和恢复的动态响应，定义性能验收指标。
2. 校准已接入的PWM更新事件、ADC触发及顺序转换参数，核对各任务之间的保持与延迟。
3. 完善低侧有效窗口失效处理，加入ABZ测角测速、上电对齐及主动保护。
4. 门极死区、二极管续流和极性前馈补偿已验证；后续标定有效死区、器件参数及母线测量链。
5. 对齐固件PDFF、显式积分器及数值精度；当前Backward Euler隐式PI尚非固件位级实现。

门极死区版能表示两管同时关断及按电流方向续流，并支持极性滞环电压补偿；近零续流采用明确的数值近似，不含器件输出电容、反向恢复和损耗。旧周期平均压降作为历史教学对照保留，与门极死区互斥。已有等效电流域测量误差、模拟/数字低通、角度模型，以及可选顺序ADC转换和低侧有效窗口；实际前端电路和事件参数尚待校准。Chirp为辅助观测信号，没有接入主控制给定。尚不能作为已完成开发板适配的发布基线。
