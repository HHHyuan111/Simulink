## 实现

| 文件 | 职责 |
| --- | --- |
| `sensorless_parameters.m` | 读取N0标称初值、计算离散系数及PLL增益、检查参数与离散极点；不修改电机 |
| `sensorless_smo_step.m` | αβ隐式饱和校正；无效采样只预测，不执行测量校正 |
| `sensorless_emf_step.m` | 独立一阶低通、正反转方向处理、离散估计链相位校正 |
| `sensorless_pll_step.m` | 幅值归一化、PI积分、条件抗饱和、当前角度输出与下一拍预测 |
| `sensorless_state.m` | 显式状态及初值 |
| `sensorless_observer_step.m` | 组合以上组件，执行已冻结的有效性、复位及历史准备规则 |

状态全部通过函数参数传递，无persistent或全局变量。低层算法不读取真值角度、真值速度或电机模型状态。

采用已冻结初值：Kslide=14V，边界层0.2A，EMF滤波800Hz，PLL自然频率60Hz、阻尼比0.707；没有重新调参或修改N0测试标准。

参数计算结果：a≈0.9506046382，b≈0.4698726452A/V，隐式观测局部极点≈0.0280488109；归一化PLL的Kp≈533.0654s⁻¹、Ki≈142122.3034s⁻²，离散谱半径≈0.98658336。局部极点通过不等于无感闭环全局稳定性证明。

## 时间与相位约定

在t[k]读取测量电流，并使用上一物理区间[t[k−1],t[k]]的电压。SMO校正后发布当前估计。PLL输出当前输入时刻角度，内部再预测下一采样时刻；没有把下一拍预测角当作当前角度输出。

相位处理覆盖观测递推和EMF滤波。支持两种明确区间约定：上一采样点保持值，以及RL指数加权物理区间。后一种是本地PWM电压重构的目标接口。

对于旋转EMF，加权区间相对于上一点的因子为：

`W=(exp(j*ωTs)-a)/(L*b*(R/L+j*ω))`。

物理区间模式把W的相位与Gobs、H一起校正，使用上一拍估计速度，不用真实速度。这样避免把区间平均的时间位置和观测器的一拍索引重复计入。变速、实际PWM片段与测量链误差留给N2/N3验证。
