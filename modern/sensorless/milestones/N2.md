# N2：本地模型旁路接入

日期：2026-10-16。工作树 `D:/simulink/dev`，分支 `dev`。状态：数值/结构检查与完整跨进程数据核验通过，等待用户验收；MATLAB 原生崩溃带来的运行稳定性问题仍未解决。N1 已由用户确认，N2 按“模块、代码规范，尽量使用 Goto”的要求开发，不自动进入 N3。

## 本节点交付

主模型中增加可移除的 `无感观测`，包含采样输入、区间电压、执行许可、滑模观测、反电动势、锁相环、有效判断、观测八个模块。算法核心继续调用 N1 已验证函数，MATLAB Function 只负责固定接口和本地状态。模块说明与时间、参数、信号约定见 [INTERFACE.md](../INTERFACE.md)。

35 个内部 Goto 均采用 `SLess_*` 唯一名称和 scoped 可见域。根图只增加一个观测子系统；原 729 个模块、连接、位置、分区及原算法保持。真实角度与速度仅进入观测评价。

本地适配的关键是电压来源与时间：原全局 `Tcm` 是请求值，实际输入改从既有 `log_Tcm_applied` 同源端口读取。根据实际载波、已生效阈值和控制母线重构 αβ 电压，按原生网格的 RL 权重累计到上一完整控制区间，明确记录起止和 CCR 序号。真实时序控制周期为 50 μs，偏移 28.875 μs；原生电压累计周期为 62.5 ns。原理想时序分别为 50 μs/0 和 1 μs。

观测参数独立放在新 Mask，带单位；初始化统一计算 a、b、PLL Kp、Ki 并只读显示。未修改冻结初值或验收阈值。电机参数改变后的同步规则见接口说明。

两个原生 Scope 为 2×2 总览、3×2 内部状态，配有完整 `obs_sless_*` 日志。估计角度没有接入控制反馈。原 SLX 不保存，关闭入口移除新模块、外部阈值取样点并恢复工作区和回调。

## 查看与复现

在用户自己的 MATLAB 中打开 dev 副本：

```matlab
cd('D:/simulink/dev/modern'); addpath('sensorless');
open_pmsm_sensorless;
```

双击 `无感观测` 查看模块，进入 `观测` 打开两个 Scope，按原模型运行按钮运行。查看完成执行 `close_pmsm_sensorless` 撤销旁路层。同名模型若已打开其他目录副本，入口会要求先由用户保留并关闭，避免混用。

科学验证入口 `validate_sensorless_n2` 在独立 MATLAB 进程运行。另提供独立复跑脚本，将五个工况分开到全新进程和独立编译缓存，并在第六个进程做同一套数值分析和全部原始 Time/Data 精确比较。这个执行方式在当前机器上也出现过原生崩溃，不能称为已验证的稳定替代方案：

```powershell
& 'D:/simulink/dev/modern/sensorless/repeat_sensorless_n2_isolated.ps1' `
  -OriginalFolder 'D:/simulink/dev/modern/sensorless/runs/N2_20261016_152804_679_f5ee835c-7135-4728-b908-ac286082afa6'
```

新克隆没有本地原始 MAT 时，先运行 `validate_sensorless_n2` 生成通过包，再以其目录复跑。原始全采样数据保留在本地 runs，不提交 Git；提交报告、图片、首末各 20 区间明细及数据/源码指纹。

已保存的跨进程核验可以直接复现，读取原始数据，不加载模型：

## 开发失败保留

接入调试修正了 Scope 原始模板路径、行列维度约束、MATLAB Function 非 ASCII 断言编码问题，以及请求/生效电压来源区分。原生模型的信号维度由编译结果读取并用 Signal Specification 保留，避免新分支反向改变原模型尺寸。

正式测试阶段保留了 MATLAB 原生非法指令退出、一次原模型恢复检查失败、分析报告空结构赋值错误、独立复跑进程访问异常及单独出图进程访问异常。拆分工况函数、显式保存前后状态后，正式五工况检查完整通过；分析报告结构初始化已修复。之后单独进程和独立缓存试验仍有崩溃，所以不能认为运行稳定性已修复。原生崩溃根因未确认，不能描述成已证明的 JIT 缺陷。失败摘要与来源指纹保存在 `N2/development_failures.json`，失败包及日志留在本地。
