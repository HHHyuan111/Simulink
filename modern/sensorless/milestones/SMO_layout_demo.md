`sless_closed_control_block.m` 在阶段 2 使用 `theta_if`，并通过 `id_ref=I*cos(phi)`、`iq_ref=I*sin(phi)` 将启动电流从该坐标系的 d 轴转到 q 轴，`phi` 从 0 增至 π/2。在此轻载平台，转子磁链轴接近电流矢量方向，因此 `theta_if - theta_real` 接近 −π/2。实际记录也显示该窗口的电流矢量相对转子角均值约 −1.61°，按真实转子角换算的 d/q 电流均值分别约为 5.97 A、−0.17 A。该换算仅用于离线说明当前启动方式，不参与模型控制反馈。

因此，图中接近 −90° 的控制角差不能判成 SMO 失准；至少在 I/F 平台后段，SMO 已有亚度级估计精度，但控制尚未采用估计角。0.18–0.22 s 红线下降主要是控制坐标系的混合切换，不能把它当成 SMO 此时才收敛的曲线。另一方面，该阶段电流主要落在真实 d 轴，说明当前 I/F 启动电流利用率及接管时机仍有优化空间；本次通过不代表启动过程已经优化完毕。
