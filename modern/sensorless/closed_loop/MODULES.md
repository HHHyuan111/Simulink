# 基础模块版观测器

主模型仍为 `../models/closed_loop/PMSM_SMO_ClosedLoop.slx`。本次把观测主链路展开为基础模块，参数与离散算法沿用已经验收的闭环版本。

从主页面打开「无感观测」：

| 页面 | 计算内容 |
|---|---|
| 滑模观测 → 隐式校正 | 电流预测、边界层内外分段解、有效样本选择、复位、上拍电流及注入状态 |
| 反电动势 → 滤波校正 | 反电势递推低通、离散链路相位、模拟/数字前端相位、两级矢量旋转 |
| 锁相环 → 归一化PLL | 矢量归一化、正交鉴相、条件积分抗饱和、双向限速、当前角输出和下一拍角度保存 |

这三个计算子系统内部没有 MATLAB Function、Fcn 或外部算法调用。Sum、Product、Switch、Unit Delay、比较、逻辑、三角函数和数学运算块直接实现方程。参数向量在各计算页的参数子系统中展开，图中系数使用具名的局部 Goto/From。

`Unit Delay` 与三个核心子系统均使用 `timing_control_sample`，即原 50 μs 周期及原 JEOS 偏移。SMO 输出本拍校正电流，PLL 输出当前角度并保存下拍角度；没有额外串入一个控制周期。标量出口显式整理为原日志维度，矢量保持原列向量格式。

采样校准、真实桥臂区间电压累计、发布队列、有效判断和启动切换仍保留原有实现。这些功能负责接口、时序与状态逻辑，本次没有将它们宣称为纯基础模块，也没有修改其工程假设。

主页面按工程设置、电流/电压调节、PWM/电机、无感反馈、原生观察入口排列。长距离连接使用既有作用域信号，局部方程直接连线。电流给定、坐标变换、电流调节、调制、功率电路及辅助观测整理为虚拟子系统，不新增任务边界。

构建顺序为 `build_sensorless_closed` → `build_sensorless_modules` → `style_sensorless_closed`。布局随构建脚本保存，重新构建不会恢复到旧的散乱页面。`finish_sensorless_style` 收尾整理观察入口和 PLL 方程分组。

核对标准见 `modules_acceptance.json`，结果见 `../milestones/SMO_modules.md`。核心对照工具仅在模型外创建临时的离散方程检查，不接入主仿真。完整闭环继续使用原先的 0.50 s 工况与验收门槛。
