# 无感闭环接入

`PMSM_SMO_ClosedLoop.slx` 是直接接入模型的独立闭环版本。原 `models/direct/` 旁路模型保留。没有引用模型、高频真值评价器或故障刺激平台。

基础模块整理后，原先跨主页面的直接连线使用具名作用域信号连接。`FB_smo_packet`、`FB_smo_permit` 分别传递原 13 元素已发布数据和许可，`Cmd_speed_rpm` 传递原转速给定；接收点位于 `闭环控制` 内。`PWM_requested_threshold`、`PWM_applied_threshold` 连接调制和更新链路。`Plant_*` 仅连接原功率/电机支路，`View_*` 仅连接原辅助观察支路。它们没有新增缓存、采样或数值变换，原 `CL_*`、`SLessV2_*` 及全部日志名称保持。

控制侧接管：正 Park 使用 `CL_theta_sample`，反 Park 使用 `CL_theta_pwm`，交叉解耦使用 `CL_omega`，速度 PI 使用已发布 SMO 转速；原先关闭的可选死区补偿角度输入也改为 `CL_theta_sample`，避免以后开启时混入真实角度。当前验收仍保持补偿关闭，真实桥臂死区和压降保留。实际转子角度、速度不进入起动/切换模块。真值只在原观测区和新的 `闭环结果观测` 区以控制周期采样后用于显示。

发布数据在 JEOS 后 3 μs 才可用，因此控制时刻读取的是上一帧已经完成的数据包；使用包中的当前时刻角度预测，另向预计 PWM 生效时刻推进。不会在当前 JEOS 提前读取尚未完成的本帧估计。

控制阶段：1 对齐；2 I/F 起动；3 坐标系平滑切换；4 SMO 速度环已运行、逐步去除起动 d 轴电流；5 正常无感闭环；6 无可用估计时撤销电流指令。阶段 3 保持定子电流给定矢量，速度 PI 积分跟踪当前 q 轴给定，阶段 4 再闭合速度调节。短时估计间断仅用最后有效包外推，超过 1 ms 撤销给定，不切回真值反馈。

`sless_closed_cfg` 是固定尺寸接口，单位如下；角度为电角度，速度反馈为机械 rpm，速度 PI 输出及积分为 N·m。

|索引|含义|单位|
|---|---|---|
|1–3|电流周期、JEOS 偏移、极对数|s、s、无量纲|
|4–6|对齐结束、起动电流转向时长、I/F 频率爬升结束|s|
|7–9|I/F 转速、对齐电流、I/F 电流|rpm、A、A|
|10–14|最早切换时刻、连续许可时长、角度切换时长、d 电流退出时长、闭环速度给定爬升时长|s|
|15–19|原速度 PI Kp、Ki、Ks、转矩限值、转矩常数|N·m/rpm、N·m/(rpm·s)、原回算单位、N·m、N·m/A|
|20|速度环相对电流环分频|无量纲|

`obs_closed_*` 按原 `timing_control_sample` 记录控制角、PWM 角、反馈速度、电角速度、dq 给定、实际使用的速度给定、阶段、切换权重和有效包年龄。`obs_closed_pi` 与原 `obs_pi_speed` 四列保持 P 项、积分项、限幅前转矩、实际转矩给定的格式。

当前电机为 `Ld=Lq`，q 指令沿用本地原有的转矩/电流换算路径。后续更换电机尤其是 `Ld≠Lq` 时，还需适配转矩关系、起动电流与切换动态，不能只替换 R/L 参数就沿用本节点结论。

正常负载为 0.34 s 从 0 到 0.207 N·m 的机械负载变化，不修改 ADC、发布时序或观测器状态。验收窗口和数值标准在 `acceptance.json`。演示只使用此次实际闭环运行的原生 Simulink Scope 截图。
