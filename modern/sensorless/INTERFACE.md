# N2 模块与接口

此层在本地 PMSM 模型上运行，输入来自本地控制链。安装入口为 `open_pmsm_sensorless`，移除入口为 `close_pmsm_sensorless`。安装在内存中进行，原 SLX 不保存；重复打开不会重复添加模块。

## 模块职责

|模块|职责|执行周期|
|---|---|---|
|采样输入|读取控制器收到的三相电流，Clarke 变换，读取样本有效标志|50 μs，随本地控制任务偏移|
|区间电压|读取实际生效阈值、载波、控制母线及 CCR 序号，累计上一控制区间的 RL 加权电压|原模型 1 μs；真实时序 62.5 ns|
|执行许可|首个完整电压区间就绪前保持复位；关闭旁路时持续复位|控制任务|
|滑模观测|离散电流预测与隐式边界层校正，输出电流估计、残差、滑模注入|控制任务|
|反电动势|低通滤波与离散相位校正，使用上拍 PLL 速度|控制任务|
|锁相环|归一化鉴相、PI、限幅与抗积分饱和，输出本拍角度和速度|控制任务|
|有效判断|10 ms 窗口、20 ms 锁定、5 ms 失锁计时，输出 valid/state|控制任务|
|观测|记录完整数据，提供角度/速度与内部状态 Scope；真值仅用于评价|控制任务；电压来源记录为原生速率|

新增模块之间通过 `SLess_*` scoped Goto/From 通信，可见域限定在 `无感观测` 内。跨原模型边界读取既有全局信号；唯一新增外部取样点为 `输出延迟/无感生效阈值`，读取已有 `log_Tcm_applied` 的同一个源端口，移除时一并删除。

特别注意：原模型全局 `Tcm` 是 SVPWM 请求，不能作为已施加电压的来源。

## 参数

原电机与控制器参数保持原有名称和来源。观测器参数单独放在 `无感观测` Mask 中，单位写在提示文字里。初始化时由 `sensorless_parameters` 统一推导离散系数与 PLL 增益，再通过只读显示给出 a、b、Kp、Ki。

电阻、电感默认取安装时本地电机 Rs、Ld；模型参数之后改变时，需要明确同步 Mask 中的 R_hat、L_hat，或保留其值做失配实验。不存在后台自动改写电机或 PI 的逻辑。

`sless_cfg` 是 MATLAB Function 的固定 18 项数值接口，排列由 `pmsm_sensorless_init` 生成、`sensorless_rt_config` 唯一解析：R、L、Ts、a、b、g、Kslide、边界层、观测极点、滤波极点、PLL Kp、Ki、速度限值、极对数、EMF 开启/关闭阈值、残差阈值、鉴相阈值。窗口 200/400/100 点由冻结契约决定，并在初始化检查。

## 时间与电压约定

观测器时刻 t 使用当前采样电流与明确标注的上一完整区间 `[t−Ts,t]` 电压。实际时序控制任务偏移 28.875 μs，周期 50 μs。首次部分区间丢弃，不补零拼成有效区间。

这里 t 是控制器收到测量值并执行任务的时刻；真实 ADC 各相物理采样时刻保留在原 `obs_adc_timing` 日志中，不能把发布时刻等同于各相采样时刻。N2核验收到的数据与原控制链一致；采样年龄和各相时间差对性能的影响由 N3 量化。

区间电压为原生网格每段保持电压按 `exp(−R/L·时间)` 加权后的等效输入，与 N1 的离散电流方程对应。反电动势相位校正采用相同约定。它是原生网格 ZOH 重建，不能宣称与连续 ode4 的每个中间积分阶段完全相同；这一误差是否影响精度，由 N3 实测判定。

电角度单位 rad，环绕到 `[0,2π)`；电角速度 rad/s；对外转速 rpm；电流 A；电压 V。角度误差统一为 `atan2(sin(估计−真值),cos(估计−真值))`，Scope 显示为度。

## 日志与 Scope

所有新日志统一为 `obs_sless_*`。输入、估计、中间状态、PLL 状态、有效性和来源记录分别保存；`voltage_interval` 明确记录区间起止，`applied_sequence` 在原直通模式为 −1，在真实时序为实际 active CCR 序号。

`obs_sless_voltage_native` 的 12 列顺序：原生时间、α电压、β电压、A/B/C 生效阈值、载波、控制母线、active 序号、区间边界、区间就绪、阈值或序号变化累计数。完整保留，不做科学数据抽点。

`state`：0 复位，1 捕获中，2 有效，3 样本无效或方向未知。`valid` 独立输出，估计角度数值可读不代表已锁定。

两个原生 Scope 分别采用 2×2 总览和 3×2 内部状态布局。总览显示电角度、转速、环绕角度误差、valid/state/饱和；内部显示 α/β 测量与估计电流、反电动势、鉴相误差、PLL 积分及相位校正。真值/测量灰色，估计蓝色，误差红色；多通道内部图按通道配色。

真值只进入观测与离线评价，不进入 SMO、滤波、PLL 或有效性判断。N2 是旁路接入验收，不将估计角度接入 FOC 反馈。
