# 用户确认的开发约定

- 当前正常算法开发入口是 `direct/`，工作模型在 `models/direct/`。
- 用户已明确要求以后不再出现引用模型包装、高频真值评价器和故障刺激平台。本工作区后续实现不再加入这三类结构，不恢复旧故障矩阵，也不把它作为正常 SMO 交付的前置条件。
- 保留任务相关的真实物理因素：电机参数、采样与控制周期、ADC/滤波、死区/器件压降及实际计算延迟。简化额外测试结构不能偷偷删除这些因素。
- 优先主模型内直接接入的规范子系统，内部使用作用域 Goto/From；参数与日志沿用本地名称、单位及采样时刻约定。
- 正常验证使用事先规定的短时长和稳态窗口。完整记录启动过程；只用实际新运行的原始数据报告结果，历史曲线要明确标注来源。
- 验证和结果分析放在模型之外，保持运行入口简单。旧实验与失败记录保留供追溯，不继续扩建其平台。
- 用户要求闭环演示使用实际运行的原生 Simulink Scope 截图，不用 PDF 或另绘结果图替代。闭环必须明确估计量实际接管了哪些反馈，不能把旁路观测称为无感闭环。
