# R2评价与执行接口（节点尚未完成）

R1估计链不改动。新增评价器只放在`无感观测/观测`内，每个62.5ns节拍读取实际发布包、许可、实时ADC/时序状态和仅评价用途的真实角度/速度。真实量没有通往SMO、PLL、电压预测或发布许可的回路。原47个作用域Goto保持，新增评价使用From读取现有标签。

`sensorless_r2_logging`将新观测层的大体积36列电压记录及保持标志采在JEOS；电流、SMO、PLL、真值等每个JEOS记录，发布包每次实际完成后3μs记录。原52路记录方式不改。Scope在无界面测试中关闭。当前累计器日志的`SampleTime=dt`，在短工况实际为62.5ns、共320001点；较计划的每PWM记录更密集，末值仍用于验收，不据此跳过任何原生节拍。长工况内存负担仍需注意，未以丢弃原52路数据解决。

`obs_sless_r2_native_counters`为12列：

|列|含义|单位|
|---|---|---|
|1|当前原生时间|s|
|2|最长连续误有效时间|s|
|3|总误有效时间|s|
|4|总许可时间|s|
|5|ADC/时序/复位/年龄/未来可用时间等许可违规次数|原生时刻数|
|6|真实转速绝对值≤250rpm时仍有许可的次数|原生时刻数|
|7|禁止许可时控制字段9:11未清零的次数|原生时刻数|
|8|许可时最大瞬时角差绝对值|电角度°|
|9|许可时最大相对转速误差|比例|
|10|当前是否误有效|0/1|
|11|当前连续误有效时间|s|
|12|已评价原生时刻数，含t=0|个|

误有效定义：`permit && (abs(wrap(theta_now-true_theta_now))>8° || abs(raw_rpm-true_rpm)/max(abs(true_rpm),1)>.03)`，全程包含启动、过渡和零交越。比较角度使用同一原生时刻的`theta_now`，不拿PWM预测角对比JEOS真值。动态/稳态固定窗口也不按许可删除坏样本。最长误有效的上限为2ms。

持续时间用uint64节拍数累计前一时刻状态的`[t_previous,t_current)`区间；StopTime处最后一个事件关闭区间。次数统计包含终点瞬时状态，与持续时间的端点定义区分。每次误有效/许可/原因/ADC/时序/复位状态变化、发布完成及50μs心跳保存事件；不因角差在两个心跳间跨越阈值而漏记。

`obs_sless_r2_native_events`的16列依次为：时间[s]、误有效、许可、禁止原因位、ADC有效、时序有效、数据年龄[s]、带符号角差[电角度°]、相对转速误差、估计当前角[rad]、真实当前角[rad]、原始估计机械转速[rpm]、真实机械转速[rpm]、序号、当刻发布完成、复位。布尔量在日志中以0/1表示。离线审计直接按事件区间求和，必须与原生整数累计器相同，并独立重算事件角差和转速误差。

当前执行器只支持静态转速的记录/精度诊断，尚不支持R/L、死区边界、动态、缺样、复位及调度注入。未实现的工况显式报错；不能把通用检查通过当成故障验收通过。长时3000rpm的两次编译异常已达到当前版本重试上限，禁止第三次相同执行。详见`milestones/N3R2.md`；最终候选、全矩阵及R3独立复跑尚未产生。
