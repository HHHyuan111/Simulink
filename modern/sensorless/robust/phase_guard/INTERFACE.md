# R2瞬时数据包相位许可

本地可撤销适配：R1原SMO、PLL、电压/电流重构和质量窗口保持，原`SLessV2_valid`仍表示历史质量判断。新增许可位只接入`发布许可`的数据包质量输入；不反馈估计状态或FOC。根层仍为原九个模块，瞬时判断放在`有效判断`内。新增2个作用域Goto，连同原47个共49个。

`sensorless_r2_phase_guard`仅接收本次JEOS的估计角、校正反电势矢量、原质量、采样有效、复位及名义EMF下限。点积为正且绝对叉积不超过`sin(5°)*矢量幅值`，再与质量、有效性、复位条件相与；对非有限量/零矢量关闭许可。正点积排除180°误锁。浮点边界裕量为8eps，不是可调角度裕量。没有真实角度、速度或未来输入。

5°相位门槛加3°模型误差预留，对应既有8°目标。3°是待全矩阵验证的工程假设，并非已证明的真实反电势误差上界；不得据这条几何关系宣称实板保证。参数在Mask中只读显示，代码及设计契约冻结同为5°。

该位在JEOS被原R1队列捕获，仍到JEOS+3μs才发布。旧包在新结果完成前保持原因果语义；ADC/时序的原生实时撤销独立保留。本模块只处理正常数据包相位质量，不能替代尚待实现的缺样、复位与调度故障适配/验收；3μs也仍是工程预算。

新增`obs_sless_r2_phase_guard`每个JEOS记录8列：

|列|含义|单位|
|---|---|---|
|1|校正反电势相对PLL角的带符号夹角|rad|
|2|矢量幅值|V|
|3|归一化点积|比例|
|4|归一化叉积|比例|
|5|瞬时相位符合门槛|0/1|
|6|幅值达到原名义EMF关闭下限|0/1|
|7|原历史质量许可|0/1|
|8|新数据包质量许可|0/1|

控制许可仍读取实际完成后的`obs_sless_v2_publication`及原生事件，不能拿第8列JEOS计算结果冒充已完成的控制数据包。拒绝时控制字段清零仍由原队列执行，原始估计角和速度保留供评价。

组件验证覆盖572个几何/方向/缩放组合、3个质量/采样/复位否决、4个零值/非有限输入以及1313个原生发布时刻，确认新不合格包在3μs完成后关闭许可。它不是全R2性能验证；最终仍要求固定稳态窗口、全程误有效、动态/失配/故障完整矩阵和R3复现。
