# 非理想适配核心接口（R0）

此目录为独立组件，不自动装入已打开的模型。`sensorless_robust_config`读取冻结工程假设并校验单位；所有计算核心显式传入状态和参数，无persistent或电机真值依赖。

|函数|输入|输出及约定|
|---|---|---|
|sensorless_deadtime_estimate_step|原生时间s、固件门极命令AH/AL/BH/BL/CH/CL、估计死区、显式状态|重构的估计门极与三相空白标志；关断立即、开启按ceil死区/h延后；同拍同输入幂等，跳拍/逆序/同拍变更拒绝|
|sensorless_bridge_estimate|估计门极、校准ABC电流A、历史估计ABC反电势V、测量母线V、估计Ron/Vf|αβ与ABC电压V、极点电位、续流路径及不可信标志；不使用真实桥输出或真实转子状态|
|sensorless_event_plan|PWM周期序号、非负任务发布抖动s、抢占/干扰耗时s|ABC孔径结束、JEOS、任务发布、观测可用、CCR写入、预期/实际UEV、截止期、裕量及下一帧超时；速度任务分频亦显式记录|
|sensorless_publish_step|估计数据包、包到达标志、当前时间、计划PWM生效时间、输出状态、独立实时输入/时序有效标志|采样/当前/PWM三个角度rad、机械rpm、数据年龄s、控制许可、原因位及恢复请求|

门极续流路径编码：+2上管开启，−2下管开启，+1上二极管，−1下二极管，0浮空。校准三相电流先去零序；零序异常另记并撤销电压可信度。任何两管全关且电流位于估计零流带的相，都保留ambiguous标志，即使历史反电势给出了一个数值估计，也不把它当作已知真实导通路径。

`voltage_confident`只是当前电压模型的可信标志，不能等同于ADC有效或SMO已锁定。R1需量化不确定电压持续时间/区间误差界，再决定该区间是否可用于观测；不能靠把大量零交越样本直接删除来满足精度统计。

数据包字段固定为：`sequence`、`reference_time_s`、`available_time_s`、`theta_rad`、`omega_e_rad_s`、`input_valid`、`observer_valid`、`timing_valid`。reference为待对齐的JEOS采样参考，不表示三相真实物理采样时刻相同；ADC三相时间独立保存。available为计算完成后真正可读的时间，当前不能使用未来包。

|reason位值|含义|
|---|---|
|1|尚无估计包|
|2|输入无效|
|4|观测器未有效|
|8|计算/写入截止期不满足|
|16|估计状态过期|
|32|未来包、时间不一致或目标生效时间已过去|
|64|序号逆序/跳变或相同序号内容被修改；要求外部重建状态|
|128|生效角预测跨度超出预算|
|256|估计电角速度超过限值|

reason可按位组合。live_input_valid和live_timing_valid由当前ADC/截止期监测独立提供，不等待新SMO数据包可用；即便上一有效包尚未过期，实时故障也必须立即撤销许可。control_permit=false时三个control数值输出为0，必须与许可一起消费；raw诊断量独立保留。此接口尚未接管反馈，也尚未实现完整故障回退或重新锁定状态机，不能把“有0输出”解释为已具备安全闭环。

R1适配必须保持以下边界：电机侧真实R/L、压降和采样误差只用于环境注入；不能通过修改共享工作区变量，把这些真值自动传入控制器或观测器。观察侧只使用其独立估计/标定参数。物理增益、零偏和噪声须先作用于实际测量链；ADC削顶或无效窗口不能用真值电流回填；模拟与数字滤波延迟分别计数一次；在相应补偿实现和验证前不得宣称已对齐。

预算按SMO/PLL 3 μs、包含速度任务最坏情况的FOC 5 μs、另留2 μs裕量假设。实际硬件测量缺失；编译器优化、FPU/定点、ISR抢占、DMA和总线等待的真实成本均未验证。
