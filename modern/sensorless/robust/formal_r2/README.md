# R2 冻结候选的正式全矩阵

标准先登记在 `../../contracts/nonideal_r2_final_matrix.json`。本阶段独立执行同一候选的全部 14 项，不拼接开发版本或旧成功数据。每项仅一次正式启动；任何执行、完整性或性能失败即停止，保留未完成项，不改标签再运行。

入口按以下顺序执行：

1. `candidate.py preflight`：只读已完成短检/缺帧归档，检查校验器、617 个原文件、90 个 R1 冻结文件、完整源码和配置。不运行仿真。
2. `candidate.py freeze`：只写一次 `milestones/N3R2/final_candidate.json`，固定原模型、源文件、全部合同、18/35 维参数、运行版本/命令和 14 项顺序。已经存在的候选禁止覆盖。
3. `run_sensorless_r2_final_matrix.ps1`：冻结后独立采集新正式数据，每项启动前后重新核对文件。首次为缺帧项；开发阶段的两次尝试及中断保持原状态。正式阶段不进行原生异常重试。

每个正式工况保留原始 MAT、生成的子模型、源码快照、完整指标、原图恢复证据、格式适配副本和独立 `formal_provenance.json`。正式元数据不写回原 `record.json`，不修改原始轨迹。

原验收阈值保持；正式阶段额外统一要求所有工况全程最长误有效不超过 2 ms，包括低速边界项。正常工况 96 路日志，截止期工况额外保存真实 PWM 事件，共 97 路。

冻结的是完整运行源码及构造规则；每次生成的子模型仅命名空间和预先声明的工况设置不同，生成后及运行后均校验实际模型指纹。电机、PI 和控制反馈来源保持，观测层仍为旁路。全部 14 项正式通过后才形成 R2 节点记录交用户验收，随后等待用户决定 R3；不自动接管反馈，不作实板或 MCU WCET 结论。
