# 三条教学链的观测口径

本轮统一现有入口与术语，不增加面板、控制算法或非理想因素。原生“教学对比”菜单在噪声、采样延迟、数字滤波、PWM更新、死区补偿五种归档图之间切换；已打开的主题只切回原图窗，避免重复堆积。采样教学页仍保留设置、当前Scope、教学对比三个操作，死区教学页保留原操作。

“本次仿真”读当前模型连接与运行，原生Scope通常应先打开再运行。“已保存实验”读固定档案，不会自动仿真，不随当前配置改变。所有归档图窗标题保留这个来源提示；两种数据不能混读。图内只放主题、图例、坐标与单位，详细说明留在正文和已有工况菜单。

## 对比必须放在一起，但不混用坐标

- 同一运行中的真值与反馈同轴；跨运行的q轴误差使用各自iq给定。不能把不同闭环轨迹之间的相位差全部称为测量延迟。
- 延迟/滤波/PWM闭环图中的dq来自真实状态，转矩指标是50μs控制记录的末20ms标准差；不是全带宽PWM纹波。死区指标表补充“真实iq”字样，统一这一口径。
- 死区三相电流按真实电角周期对齐，比较波形形状；转矩保留绝对时间。角度轴联动不能解释成同一时刻，也不与时间轴联动。
- 死区频谱是A相幅值谱，单位dB re 1A；低次谐波是相对基波百分比。噪声图是功率谱密度，单位A²/Hz的对数。这些不是同一量，不能直接比较纵轴数字。
- PWM更新图的微秒轴联动，闭环响应的毫秒轴另行联动。10.5和15μs计算在同一次UEV生效，已核对的物理波形一致，重合保持原样。

## 工况边界

采样与PWM例子为3000rpm，死区补偿例子为600rpm。共用菜单只统一进入方式，不代表不同主题之间共享同一工况。每个主题内部才有对应的受控比较契约，不能拿不同主题的转矩RMS作因素排名。

采样整拍延迟是可独立调节的旧等效支路；真实事件模式已经包含顺序采样、计算写入和UEV等待，两者不能机械叠加。低通幅相误差、ADC量化、模拟前端也要避免把同一个实测效应重复分配。详细桥未开启时，原生死区桥臂电压观测按已有逻辑显示无效值，不把理想桥诊断当成详细桥电压。

## 本轮验证

`navigation_validation.json`实际执行五个图窗的25条跨主题菜单路径，确认五种窗口各只有一个、参数和档案不变。原采样40条、PWM24条、噪声16条，以及死区9条电流/转矩曲线、2条频谱曲线、2组谐波数据重新核对来源。当前模型自定义转速1234与采样因素保留；原生采样Scope和死区教学按钮回归检查沿用现有验证入口。

本轮没有重新运行物理仿真，核对的是现有归档结果、绘制数据和真实菜单操作。SLX、冻结参考和已封存实验均保持。源码及报告指纹见本目录`delivery.json`；先前阶段交付索引只描述当时的菜单版本。
