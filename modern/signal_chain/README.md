# 采样与控制时序信号链检查

本阶段优化原模型的采样与PWM更新两个局部模块，不新增算法、参数面板或操作流程。原PMSM、PI、数值公式及主SLX保持；打开原模型或在原参数窗口点击“展开模块”即可看到局部整理。

## 采样链核对结果

实际连接顺序为：真实电流 → 通道增益 → 零偏 → 注入噪声 → 可旁路模拟一阶低通 → 简化/顺序采样选择 → 控制任务保持 → 可旁路量化与限幅 → 可旁路数字低通 → 可旁路整拍延迟 → 总旁路选择 → 控制反馈。

增益关闭时为1，零偏/噪声关闭时为0。所有测量因素和真实时序均关闭时，总选择直接送入真值；并行的捕获、滤波、延迟支路可以仍有状态，但没有被选择就不会进入控制器。保持支路的阶梯不等于理想旁路控制反馈存在同样延迟。模拟低通在采样前、数字低通在采样后，两者是不同位置的近似，实际校准时仍应避免把同一个实测频响重复分配给两个因素。

局部布局按模拟前端、采样处理、延迟反馈、事件采样及记录分层。保留原小模块、名称、控制连接和日志变量，用已有Goto/From缩短跨层走线；记录移到独立区域。观测专用接口使用少量同源From短链接，替代从记录区拉到远端的长线，不增加控制、采样或延迟计算。输出延迟模块将整拍等效支路与CCR事件支路分开显示。整理是可撤销显示层，固定实验正常/异常退出后都会恢复。

## 已纠正的量程与码值口径

当前模型的`adc_span`是单侧双极量程，不是全跨度：

- 可配置ADC电流步长：`ΔI=2*adc_span/2^adc_bits`。
- 实际范围：`[-adc_span, adc_span-ΔI]`。
- 默认82.5意味着±82.5A、全跨度165A。旧参数接口/历史说明曾写成“全跨度82.5A”，与计算模型不一致。

当前参数编辑窗口已更正为“ADC双极量程 ± [A]”，单位及测量说明同步更正，数值不变。封存的参数接口、参考档案和历史脚本未改写，避免破坏已有数值复现契约；实板量程仍待标定，不据这次文字修正声称完成硬件校准。

`obs_adc_codes`来自顺序采样模块的独立诊断输出，固定按12bit、165A全跨度计算参考码：`clip(round(2048+I/(165/4096)),0,4095)`。它不跟随`adc_bits`、`adc_span`或量化开关，不是可配置量化支路的实际码值。记录块现在标明“固定12 bit参考码”；量化后的电流看`log_iabc_adc`，最终控制反馈看`log_iabc_meas`。真实模式配8bit、±2A的专门检查验证了两条路径各自定义，不混为一谈。

## 时序核对结果

| 默认真实事件模式 | 周期 | 首次执行相位 |
|---|---|---|
| PWM | 50μs，20kHz | 中心对齐、默认峰谷更新机会 |
| 电流环与SVPWM | 50μs，20kHz | JEOS，28.875μs |
| 速度环，分频2 | 100μs，10kHz | 78.875μs |
| 速度环，分频4对照 | 200μs，5kHz | 178.875μs |

以上以默认触发24.375μs、三通道槽合计4.5μs为前提，已核对实际编译任务周期/偏移与事件诊断，不把日志采样周期当成任务执行周期。速度环频率与控制带宽是两回事，本轮不据此整定PI。

真实模式已包含顺序采样、JEOS执行、计算完成写入和UEV生效；旧整拍采样延迟和旧整拍输出延迟与它互斥，现有预检和InitFcn约束保留。量化、数字滤波与真实时序可以组合，但它们的作用应分别解释。

模拟缓存、门极历史、指令缓存的一个`timing_h`是事件网格读缓存，默认62.5ns，不是50μs控制周期延迟。电流读缓存配合下一格读取，使采样值仍对应原孔径结束时刻；不要在采样延迟预算里再机械加一个Ts。门极历史参与保守的孔径有效性判断，其近边沿误差仍属于事件网格近似。

计算时间并非线性地变成PWM生效延迟。以下对照均采用触发10μs、JEOS14.5μs：

| 计算时间 | 更新规则 | 写入时刻 | 首次生效 | JEOS至生效 |
|---|---|---|---|---|
| 5μs | 峰谷双更新 | 19.5μs | 25μs | 10.5μs |
| 15μs | 峰谷双更新 | 29.5μs | 50μs | 35.5μs |
| 5μs | 仅谷底 | 19.5μs | 50μs | 35.5μs |

代码记录的JEOS至生效已经包含计算和等待，不能再次相加。未跨过更新机会时，增加计算耗时可能不改变实际生效时刻；跨过边界时可能跳变。这里只是已有事件模型的教学验证，不是CPU并发调度或实板GPIO测量。

## 本阶段验证

`validation.json`：20组各2ms检查，覆盖全关、增益/零偏的中性及非零值、同种子噪声0.02/0.04A、8/10bit与±2A量程、500/2000Hz数字滤波、1/2拍延迟、模拟低通、默认真实时序、速度分频4、提前触发的不同计算时间及更新规则、真实时序加8bit量化。检查逐级方程、量程限幅、噪声精确2倍比例、滤波递推、真实控制任务周期/相位、事件写入/生效和配置冲突拒绝。

增益=1、零偏=0开启后的物理状态、转速、转矩、请求/生效调制量回归全关基线。三种代表工况在局部整理前后的156路原始日志Time/Data严格一致，撤销后原结构恢复；最终显示层另在`view_regression.json`重新核对同样156路。两次核对是重复证据，不加总为312路独立信号。

`ui_validation.json`：自定义转速1234、ADC范围3与9bit保留，编辑窗口量程显示正确，展开模块、当前原生采样Scope、旧观测重建、固定实验正常/异常恢复，以及撤销全部显示层后原结构保持通过。完整原始短时输出保存在本机`.build/signal_chain/audit_runs.mat`，不会混入或改写封存的长时实验。

这些检查确认当前方程、连接、选择和短时行为，不证明任意参数组合长期稳定、精确器件瞬态或完成实板标定。没有为了“修复”而更改已经符合定义的控制计算。
