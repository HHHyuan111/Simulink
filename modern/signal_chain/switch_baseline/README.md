## 回归结果

8种中性/旁路工况各比较真实状态、转速、转矩、请求调制和实际调制，合计40路保留记录Time/Data逐点一致。详细桥零死区的请求/实际门极保留尾段一致；零补偿的三相注入电压为0。多因素采样链独立核对`真值×增益+零偏+噪声 → 量化/限幅 → 数字低通`，8bit、±2A、700Hz组合的逐级结果与公式吻合。

12组原始输出及临时覆盖配置在本机`modern/.build/switch_baseline/runs.mat`，报告记录SHA；主SLX与冻结参考未更改。每组2ms用于核对旁路、方程、初始状态及短时回归，不证明长时稳定、所有状态下位级等价或实板精度。本轮没有整定PI、改变控制公式或保存新的模型。

合法中性值与关闭不是同一个概念：增益中性值为1；截止频率和量化步长必须为正；旧延迟拍数至少1，关闭要用对应开关。门极死区0仍启用详细桥，不能要求跨桥架构逐点等价于理想桥；零补偿、零Ron/Vf应在同一桥架构内比较。真实时序的窗口检查和无效值保持也不是靠某个数值归零就消失。

已有证据保留在`../validation.json`、原功率级/时序/教学专项报告，具体覆盖各自定义；本轮未冒充重新验证所有工况。新脚本使用临时SimulationInput覆盖，独立进程运行，不保存SLX。

## 使用时怎样理解“关闭”

| 因素 | 中性值或正确关闭方式 | 本轮/已有证据边界 |
|---|---|---|
| 电流增益、零偏、噪声 | 增益1、零偏0、噪声RMS 0；也可直接关开关 | 新增组合中性值与零噪声回归；原专项已有独立增益/零偏中性检查 |
| ADC、数字/模拟低通 | 使用对应关闭开关 | 量程、截止频率必须为正，不用0代替关闭；量化精度不是误差幅值开关 |
| 采样/角度/输出整拍延迟 | 使用对应关闭开关 | 拍数至少1，0被拒绝；全关且保留3拍等非零参数仍回归参考 |
| 角度偏置/量化 | 偏置0是中性；量化用开关关闭 | 零角度偏置短时回归；量化步长0不合法 |
| 平均死区、器件压降 | 平均死区时间0、Ron/Vf同时0 | 平均模型与理想桥侧的零幅值回归通过；详细桥零Ron/Vf在同架构内比较 |
| 门极死区、补偿 | 门极0保留详细桥；补偿时间0是不注入补偿 | 门极零值不代表切回理想桥；2μs详细桥内零补偿回归通过 |
| 真实时序与旧整拍延迟 | 按架构选择 | 真实时序与采样/输出整拍延迟互斥，避免重复计延迟 |
| 采样窗口、无效保持 | 用对应开关关闭，遵守依赖 | 窗口需要真实时序；保持还需要窗口；保护时间0不是关闭窗口 |
| 速度分频 | 关闭使用原Ts_speed，开启使用dt×分频数 | 本轮覆盖关闭参数隔离与依赖；任务周期/偏移已有专项检查，未新增分频中性值物理证明 |

当前没有发现需要改写数值算法的问题。下一步建议把这份关闭/归零口径融入已有教学说明与参数提示，再选择一个有明确学习目标的组合工况验证，避免继续扩展大量面板和自动化流程。
