# 自己运行、自己对比

入口：模型“时域观测”中的速度控制、电流采样、死区与补偿。

1. 改参数、打开当前Scope，在模型中运行。
2. 点“保留本次运行”。
3. 改参数并重新运行，再点“保留本次运行”。
4. 点“对比我的运行”，原生数据检查器同轴显示最近两次保留结果。

记录叫“电流采样1、2”等，可在数据检查器中改成“补偿前/后”等名字。蓝色第一条、红色第二条；只有一次时显示一次，重复保留同一个out不建重复记录。第三次保留后默认对比第二、三次，早期记录仍在原生列表内可选。

“内置示例”读取预先保存的固定实验；“对比我的运行”读取你亲自保留的实际out，二者分开。更改参数后若没有重新运行，out仍是上一次结果，不会被冒充成新实验。

保留目标是本次MATLAB会话中的原生数据检查器。需要长期保存时，使用数据检查器自带的“保存会话/导出”，本功能不自动生成实验目录、不自动仿真或改参数。各教学主题保留各自的记录。时间域记录按原始日志时刻显示，与当前高频Scope或频域分析的采样口径有区别。

验证见`validation.json`：实际运行全关、两种零偏三个4ms工况；操作三个面板真实按钮，核对62条导入信号记录Time/Data；检查重复保留、单次显示、滚动最近两次、原参数/模型与其他已有SDI记录保持。验证短时行为与操作链，不作控制性能结论。

原生接口依据[MathWorks数据检查器导入](https://www.mathworks.com/help/simulink/slref/simulink.sdi.createrun.html)和[同轴子图显示](https://www.mathworks.com/help/simulink/slref/simulink.sdi.signal.plotonsubplot.html)。运行结束时间取SimulationMetadata；没有将保留按钮点击时的当前参数误标为仿真时参数。
