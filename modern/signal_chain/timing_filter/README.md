## 基础核对口径

- 四组配置归一后只允许计算时间、滤波开关和滤波截止行不同。无滤波组的截止行虽保留旧默认值，但未被选择；其他配置逐项一致。
- 数字低通逐点按`a=exp(-2π·1500·50μs)`、`y[n]=(1-a)x[n]+a·y[n-1]`核对，包括初始零状态；输入使用各组实际ADC捕获支路输出，不用另一组真值替代。
- ADC尾部捕获值对齐JEOS，写入/生效按整数事件网格核对。实际生效调制量按指令序号匹配写入时的影子值，防止把新写入值当成已生效值。
- dq、电流误差和机械结果采用真实50μs控制记录，不插值成事件网格；转矩标准差不等同全带宽PWM纹波。末20ms指标不证明任意工况稳定。

## 来源与复现范围

无滤波两组复用已验证的三组200ms时序档案中的5/15μs组，未重新计算。新补跑两组开启1500Hz滤波的200ms运行，来源在`latest.json`及对应唯一目录的`record.json`；MAT文件、旧档案、模型与参考指纹均核对。

四组均另用独立短时仿真复现起始2ms的18路完整控制日志，共72路Time/Data逐点比较；高频尾部不在共同时间窗，不纳入前缀比较。这不是四组200ms的完整独立重跑。新图25条曲线直接对源记录核对，六时间轴联动、6×5指标表、现有PWM入口、窗口复用和用户自定义参数保持另行验证。结果以`validation.json`为准；源文件与报告指纹见`delivery.json`。

本步骤的目标是证明已有因素可以受控组合、观测位置正确、结果可追溯。没有通过更换PI、美化波形或关闭不利结果来制造改善。

## 当前工况结果

| 工况 | 真实iq跟踪RMS [A] | 转矩标准差 [N·m] | 转速跟踪RMS [rpm] |
|---|---:|---:|---:|
| 5μs·滤波关 | 0.1287 | 0.0035 | 0.2223 |
| 15μs·滤波关 | 0.1428 | 0.0044 | 0.2020 |
| 5μs·滤波开 | 0.2103 | 0.0073 | 0.4191 |
| 15μs·滤波开 | 0.2813 | 0.0108 | 0.5769 |

本工况中，滤波开启后的真实d轴电流偏移更明显；慢计算与滤波同时存在时，q轴跟踪和转矩标准差也较大。无滤波慢计算组的速度RMS却略低，因此不作“延迟越大，每项指标一定越差”的结论。本实验没有注入噪声，也不据此否定滤波价值或推荐最佳截止频率；滤波位置、信号电频率和控制整定都需要一起考虑。

## 运行收尾修正

首次两组200ms运行均已完整保存MAT，但最后的全工作区一致性断言失败：SimulationInput撤销参数覆盖后，事件模式的派生工作区仍需显式恢复。这发生在独立进程中，随后退出且未保存SLX，没有更改用户原会话。

保留原MAT不重写，并归档当时运行源码`runtime.m`。独立收尾工具检查文件完整性后封存记录，记录明确注明这一恢复经过；随后逐级方程及四组独立2ms前缀验证核对原数据。可复用运行入口已补上与原固定实验一致的`pmsm_reference('restore')`；短时复现后也实际执行并核对完整工作区恢复。没有把“断言失败后重新标记通过”当成数值验证，也没有声称补跑了两组完整200ms。
