# 采样因素的闭环影响

沿用原模型、原PI与既有独立开关，增加两个200ms固定实验：2拍采样延迟、500Hz数字低通。与既有1拍、1500Hz实验共用逐点严格相同的参考运行；未更改SLX、控制算法或封存参数接口。

已有“时域观测 → 电流采样 → 教学对比”打开噪声图，图窗原生“教学对比”菜单切换噪声、采样延迟、数字滤波、PWM更新和死区补偿。重复切换复用已打开的主题。图窗读取已保存实验，不随当前参数变化，不自动启动仿真；当前配置仍通过原生采样Scope观察。延迟/滤波主题六幅时域图横轴联动，比较同一组的真值与反馈，以及各组真实d轴电流、q轴跟踪误差、测量误差、转矩和转速。指标与工况放在独立菜单，图片只保留主题、坐标和图例。

## 实际结果

3000rpm、24V、0.207N·m、同一原PI、零初态、理想桥。仅开启所选因素，其余非理想因素及真实事件时序关闭。这里的“拍”是旧独立测量延迟支路的50μs控制周期，真实事件模式不与它叠加。

| 工况 | 真实iq跟踪RMS [A] | 转矩标准差 [N·m] | 转速跟踪RMS [rpm] |
|---|---:|---:|---:|
| 参考 | 0.1764 | 0.0075 | 0.4297 |
| 延迟1拍 | 0.2452 | 0.0104 | 0.4817 |
| 延迟2拍 | 0.4106 | 0.0173 | 0.8071 |
| 数字低通1500Hz | 0.2149 | 0.0091 | 0.4244 |
| 数字低通500Hz | 0.4046 | 0.0168 | 1.5201 |

指标取180～200ms的50μs控制任务瞬时记录，电流真值局部图保留1μs记录。每组iq误差使用自身给定，测量误差使用自身真实电流；不把不同闭环运行之间的相位差当成单独测量误差。转矩标准差包含这个记录窗口的变化，不能当成全带宽纹波或PWM周期平均纹波。原始曲线未美化、平滑或人为放大。

教学上可直接看到：增大延迟会让反馈落后，并影响实际dq电流和转矩；降低三相静止坐标电流低通截止频率会抑制高频成分，同时增加幅值/相位误差，可能造成真实d轴电流偏移。反馈更平滑不能单独证明控制更好。本实验没有叠加噪声，不据此给出噪声抑制收益或最佳截止频率，也不据末20ms判断所有工况的稳定性。
